## 规则

- EQUIVALENT 表示业务目标候选等价，并不表示两组验收条件相同。
- REFINEMENT 表示用 OvO 的场景、限制、异常或流程补充第一组一个或多个目标要求。
- ADDITION 为拟新增独立子需求，不直接修改既有稳定编号；需共同审议。
- CONFLICT 保留两套规则、关联既有 D-01～D-12；未经签认不能以某一组原文覆盖另一组。
- NOT_ADOPTED 本轮为 0 条，没有足够依据否定任何已发现的 OvO 条目。
