## 2. 统一术语表

以下是成员03建议的术语与对照。带“待确认”的条目及与其他模块含义不一致的条目需联合审核后才能进入共同 SRS 统一术语表。

| 术语 | 统一定义 | 不接受的写法 |
| --- | --- | --- |
| 来源记录 | 某数据源提供的一条原始记录，是治理的最小输入单位 | 原始数据行、raw 数据 |
| 规范化记录 | 通过校验与规范化、具备参与匹配条件的记录 | 清洗后数据、标准数据 |
| 成果实体 | 完成去重后代表一项成果的业务对象；全平台按实体计数 | 主记录、master 记录 |
| 出处 | 成果实体与其来源记录之间的保留关系 | 副本、镜像 |
| 稳定标识 | 由来源或权威体系分配、可唯一指向成果的标识（数字对象标识、来源自有 ID、专利申请号／公开号、项目编号等） | 唯一键、主键 |
| 候选匹配 | 存在同一可能但证据不足、需人工判定的记录组合 | 疑似重复、模糊匹配结果 |
| 异常记录 | 校验失败或无法规范化、需要人工处置的记录 | 脏数据、错误数据 |
| 待核验记录 | 规范化成功但去重或归属证据不足／冲突、需要人工判定的记录 | 待确认数据、人工队列 |
| 学者档案 | 平台中的科研人员信息实体，可先于用户账号存在 | 作者库、人员表 |
| 身份候选 | 存在可能属于同一人、尚不足以自动合并的学者档案组合 | 疑似同一人、重复学者 |
| 参与关系 | 学者与成果实体之间的关联，含角色与顺序，可带确认状态 | 作者关系、归属记录 |
| 关系证据 | 支撑一条参与关系的来源证据、本人确认或管理员审核记录 | 可信度分、置信度 |
| 归属争议 | 同一成果上出现的冲突归属主张 | 归属冲突（可混用，需在 SRS 统一为“归属争议”） |
| 字段冲突处理项 | 来源取值与已确认／已审核值不一致时产生的处理项 | 差异任务、比对任务 |

### 2.1 核心状态枚举（唯一写法，禁止同义改写）

**学者门户认领状态**（对象：学者档案）

```text
未认领 | 已认领
```

**认领申请状态**（对象：单份申请，与门户授权分开）

```text
待审核 | 待补充 | 已通过 | 已驳回
```

**学者—成果关系确认状态**（对象：参与关系）

```text
自动关联 | 本人确认 | 待核验 | 争议 | 已排除
```

**成果变更审核状态**（对象：变更申请）

```text
待审核 | 通过 | 驳回
```

**采集任务状态**（对象：采集任务；由②负责，此处仅登记为公共枚举）

```text
待执行 | 运行中 | 成功 | 失败 | 重试 | 已停止
```

**异常／待核验处理项状态**（对象：处理项；FR09-S11 定义）

```text
待处理 | 处理中 | 已处理 | 已忽略 | 已转人工复核
```

> 不得混用：认领状态 ≠ 关系确认状态 ≠ 变更审核状态 ≠ 采集任务状态（V1.9 5.2-4、5.2-8、5.4）。这四类状态**必须分别保存与分别展示**。

2. **不得静默覆盖**：任何自动更新不得覆盖人工确认或已审核值（BR-324）。

4. **不得删除全局成果**：解除个人关联、来源撤稿、外链失效均不删除成果实体（BR-359、BR-326）。
5. **不得仅凭姓名合并**：同名学者必须走候选与人工核验（BR-342、BR-346）。
6. **不得把审核当质量认证**：审核通过不代表论文已同行评审或结论可信（BR-351、V1.9 5.2-8）。
