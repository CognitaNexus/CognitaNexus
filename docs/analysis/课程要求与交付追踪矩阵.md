## 4. S01 / S02 交付边界

### S01 必交

1. 69条AC唯一基线及46/59/69映射；
2. A1c：User–UserProfile 1:1、UC-22、FR12四类/IN01论文；
3. 100万/500万/100并发统一；
4. 候选架构、分析机制、关键抽象、用例实现分配；
5. 冻结记录与实际SHA。

### S02 必交（按教材+项目规范）

1. 系统边界、参与者、22个UC及关系；关键UC详细规约；
2. BCE分析类模型（不含实现类/数据库表）；
3. 至少4张活动图（注册主页、编辑主页、检索、合作网络；认领活动复用并核对）；
4. 2张核心状态图（认领申请、采集任务；普通主页不机械画CRUD状态机）；
5. 关键分析序列：采集入库、认领审核、检索请求、注册/主页（4张）；
6. AC→FR/BR/NF→UC→分析模型→验证场景追踪；
7. 模型说明、自检与评审记录；
8. 所有 `.puml` 实际渲染SVG/PNG并检查。
