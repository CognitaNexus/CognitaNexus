> **范围边界：** 本 UC 只处理 IN01 的两项**公开只读**探索能力：**(1) 按领域/机构筛选**、**(2) 两名已消歧学者之间的最短合作路径**；二者可分别执行、也可先筛选再查路径，**不要求每次一起执行**。
> **只在论文子图上工作**：图只由 FR12 基础网络中“有合格、公开、真实、经确认可用于论文合作的共同论文证据”的边构成；**共同专利/项目/获奖边永不进入路径**，也不得用来补边（IN01-R1；`AC-IMPL-FR12-05`；BR-IMP-08/09；SPEC §2）。FR12 基础网络本身仍含四类成果，由 UC-14 负责，本 UC **不裁剪、不改写**它。
> **长度＝合作边数**：无向非加权图，最短指最少合作边数；**关系强度不是距离**，路径证据计数 k≠FR12 共同成果强度（IN01-R2；BR-518；SPEC §4）。
> **等长只返回一条并说明规则**：同图版本、同筛选条件下按学者稳定标识序列字典序返回**同一条**（`AC-IMPL-IN01-02`；IN01-R2）。
> 成果去重（UC-09）、身份与归属判定及纠正（UC-08/UC-10）、采集与增量（UC-18/19）、统计与机构排名（UC-11/12）、领域热点（UC-13）、检索与详情（UC-01/02）、门户（UC-03）、后台审计（UC-17）、规模核对（UC-16）均不在本 UC。
> 本 UC **全程只读**：不写成果、参与关系与状态、学者身份与合并、来源与许可；**不建持久“路径结果/图快照/图版本对象”**（读时投影，取向差异见 07 §5 C-01）；**不做**质量、影响力、学术水平评价或个人综合排名（SRS §2.1）；**不做**实现设计（图数据库、索引、缓存、任务、接口、DTO、BFS 代码）。
> **性能是目标不是结果**：≤1 万节点/≤10 万边与路径 P95≤2 秒（`AC-IMPL-IN01-04`；§11.2）为**验收目标**，本包 **NOT RUN**，不声称已满足。

> **对象区分（本 UC 的核心边界）：**
> - `Scholar` 是平台采集/核验的学者身份，**端点与节点标识只能取 `canonical_id`**；合并先解析到当前身份；它**不是**账号 `User`、**不是** `UserProfile`，也**不是**同名姓名串。“已消歧”是查询端点成立的前提（IN01-R1；SPEC §2；BR-IMP-03）。
> - `WorkEntity` 是**去重后的成果规范实体**；在本 UC 只提供**论文子图资格**（类型＝论文、公开生效、真实）与**筛选口径证据**（已核验发生时间、发生时适用领域分类与映射版本），以及**路径证据的公开字段**（标题/类型/时间/来源/归属状态）。一项论文对同一学者对只贡献 1 篇证据，来源数与版本数不放大（`AC-IMPL-FR12-02`；`AC-IMPL-FR16-02` 边界）。
> - `Authorship` 是**学者—论文参与关系**，携带论文合法作者角色、关系状态、公开性、角色证据与**成果发生时机构证据**；只有身份明确、可公开、状态为本人确认或具独立核验证据的已批准自动关联才进入子图（IN01-R1；`AC-IMPL-FR12-04`；§11.3；SPEC §1）。
> - `CollaborationEdge` 在本 UC 只表达**论文子图投影**：由合格共同论文与两端合格论文作者关系在本次查询内推导，边键为学者对 min/max `canonical_id`，证据集合只含论文 `canonical_id`，计数 k＝去重论文数；**k 不是 FR12 四类共同成果强度 `weight`**（BR-518；SPEC §2/§3）。
> - `PathResult` 是**读时投影**：承载有序节点序列、跳数（＝边数）、逐跳边引用、逐跳论文证据与图版本；同一图版本与筛选条件下可复现同一条路径；**不作为持久结果对象保存**（06 §8；待确认 B-08/C-01）。

## 2. 目标

让访客在**公开、可复核、不可推断**的前提下探索合作关系：在 FR12 基础网络中**只取有合格共同论文证据的边**构成论文子图，按**领域/机构**筛选（使用成果发生时的机构与领域证据，未知不命中），并对**两名已消歧学者**以 **BFS 按边数**求最短路径；同一图版本与筛选条件下**等长路径按学者稳定标识序列字典序返回同一条并说明该规则**；**每一跳展示至少一篇可点击的共同去重论文证据**；**无路径、无效端点、超规模**各给可区分反馈，不把范围内不存在的关系推断为存在；同屏披露数据图范围、筛选语义、图版本、长度定义、等长规则、证据范围与规模上限；全程只读。

## 3. 触发事件

1. 访客在合作网络视图中选择“按领域/机构筛选网络”。
2. 访客选择“查询两名学者之间的最短合作路径”并指定起点/终点学者。
3. 访客在路径结果中按需逐跳查看（或一次查看全部跳的）论文依据。
4. 访客点击论文证据进入成果详情，或点击路径中的学者节点进入学者门户。
5. 访客改变筛选条件后重新计算路径，或对同一路径要求重新查询（图版本失效/落后时）。
6. 访客提出越界请求（用非论文成果补路径、跨范围推断、同机构即合作、个人排名或质量评价）。

## 4. 前置条件

1. FR12 基础合作网络可用，且其边保留**成果类型与证据**，使论文证据边可区分（UC-14 A16/M51；`AC-IMPL-FR12-01/05`）。
2. 论文实体已由 FR09/UC-09 去重，具备类型、公开生效状态、数据类别（真实/模拟/混合）、已核验发生时间（可未知）、发生时适用领域分类与映射版本（§7.1；BR-IMP-02/07；BR-513 细化）。
3. 每篇论文的参与者以 `Authorship` 表达：角色＝论文合法作者，含角色顺序、关系状态（自动关联／本人确认／待核验／争议／已排除）、公开性、角色证据引用与**成果发生时机构证据**（FR15；§6.4；§11.3；SPEC §1/§3）。
4. 参与者身份已由 FR15/UC-10 归一到公开学者 `canonical_id`；已确认合并先解析到当前身份，环或失效目标按异常处理（SPEC §2；BR-IMP-03；BR-530）。
5. 查询端点必须是**已消歧**学者，且在当前筛选快照内可用；不可用按“不存在/未公开/已合并”分类提示（IN01-R1；SPEC §4；IN01-S07 细化）。
6. 图版本可固定：本次查询使用同一图版本，并能在结果与披露中给出该版本标识（`AC-IMPL-IN01-02`；SPEC §2）。版本对象化程度待确认（B-08/C-01）。
7. IN01 是公开只读能力，无需登录，无对象级授权分支（NF01；§8）。
8. 路径查询的规模与性能按 NF02 整体验收核对；本 UC 不主张独立性能阈值已达成（NF02；§11.2；08 §5）。

## 5. 成功与失败后置条件

### 5.1 成功（筛选）

1. 筛选只在**论文子图**上生效：结果只含“两端均有合格、公开、真实论文参与证据”的边；专利/项目/获奖边不出现（IN01-R1；`AC-IMPL-FR12-05`；BR-IMP-08/09；M5/M15）。
2. 领域筛选按**成果发生时**适用、已核验的领域分类及映射版本；机构筛选按**成果发生时**机构证据，且边的两端在该论文上均须命中；机构与领域跨维度取交集；**未知机构/领域不命中**，不用学者当前机构回填历史（§11.5；BR-513 细化；SPEC §3；M19）。
3. 筛选是“先筛论文与作者参与证据、再重建边与 k”，**不是仅隐藏部分节点**；因此边的出现与消失、k 的取值都可复算（SPEC §3；M19–M21）。
4. 披露与结果同屏：数据图范围（仅合格共同论文）、筛选条件与语义（含发生时口径与映射版本）、图版本、节点/边规模、不可推断规则（`AC-IMPL-IN01-02` 语境；BR-514 细化；IN01-S06 细化；M37/M39）。
5. 筛选后无任何合格论文边时，明确提示“当前范围没有可展示的合作关系”并保留条件，不展示空画布为正常结果（IN01-S01 E1 细化；NF01；M49）。

### 5.2 成功（最短路径）

1. 返回路径为**有序学者节点序列**，长度为**合作边数**（跳数），并在结果中标注长度与跳数定义（IN01-R2；BR-525 细化；M29/M37）。
2. 路径在**当前筛选快照**（固定图版本）上计算；两端点属于同一快照；端点相同按 0 跳处理（SPEC §4；既有 `DGM-ACTIVITY-03` 同口径；与模块 IN01-S03 A1 冲突见 C-05）。
3. 路径最短：不存在更少边数的替代路径；等长时按学者稳定标识序列**字典序**取一条，并在同屏说明该决定规则（`AC-IMPL-IN01-01/02`；IN01-R2；M29）。
4. **每一跳**返回对应边、该跳 k 与**至少一篇**合格共同去重论文证据（默认 `canonical_id` 最小一篇起），并可从证据进入论文详情（IN01-R3；BR-518 细化；M31–M35）。
5. 所有逐跳证据属于**当前筛选图与同一图版本**；不跨范围补边、不以专利/项目/获奖成果充作论文依据（IN01-R3；SPEC §2/§4；M35/M51）。
6. 路径不得穿过未公开对象、待核验/争议/已排除关系，也不得因同机构/同领域/相似姓名而增加跳数（IN01-R3；`AC-IMPL-FR12-04`；§11.3；M11/M14/M51）。
7. 结果区固定声明“路径长度与论文证据数不代表研究质量、影响力或学术水平”，并声明“范围外关系视为不存在、系统不推断”（BR-522 细化；IN01-S06 细化；M37/M39）。

### 5.3 失败（无业务写入）

1. 本 UC 无写操作：失败不改变成果、参与关系、关系状态、学者身份、合并结果、来源与许可。
2. 下列结果**必须可区分且互不冒充**：条件非法、无匹配论文边、无路径、端点不存在／未公开／已合并、超规模、计算失败／超时（NF01；IN01-R3；`AC-IMPL-IN01-03`；M3/M22/M25/M38/M49–M50）。
3. 无路径时明确提示“在当前数据范围内不存在合作路径”，同屏重复数据范围，并给出更换端点或放宽条件的引导；不以空图、报错页、静默跳转或无限加载代替（IN01-S05 细化；IN01-R3；M49）。
4. 超规模时返回可观察的超规模分支并披露实际规模与上限；**禁止任意截断后仍声称全范围最短**（`AC-IMPL-IN01-04`；SPEC §3；M22）。
5. 图版本失效或落后时：要求重新查询或标注“结果可能未反映最新变更”；不以旧版本结果冒充最新，不混用两个版本（NF05；`AC-IMPL-NF05-01/02`；M46）。
6. 越界请求被拒绝并给出可用范围说明：用非论文成果补路径、跨范围推断、同机构/同领域推断、个人综合排名与质量/影响力评价（IN01-R1/R3；BR-IMP-09；SRS §2.1；M51–M53）。

## 11. 待确认

1. **B-01 筛选维度与取值语义**：基线 IN01-R1 只写“按领域、机构筛选”，未规定是否接受年份条件、每个维度是否单值、多值是“任一命中”还是“全部命中”、跨维度是否取交集。SPEC §3 给出“年份/机构/领域＋跨维度交集＋同维度只承诺单值”，但该段自述为**整改 RC，须复审确认**；本分析按 SPEC §3 建模并把年份条件与多值语义留空。
2. **B-02 机构与领域口径**：机构取“成果发生时机构”，领域取“发生时适用分类及映射版本”，机构规范名与别名归并由谁提供（Q-4/D-04 细化未决）；是否含下级分类（IN01-S01 声明项）未冻结。本分析按 SRS §11.5 与 BR-513 细化建模，不回填当前机构。
3. **B-03 规模上限口径**：`AC-IMPL-IN01-04` 的 ≤1 万节点/≤10 万边是**测试图规模与超限分支**依据；模块 Q-6 另提“网络节点≤150、边≤400”的**展示上限**候选（未决）。两者用途不同，本 UC 只按 AC 建模，是否另有展示截断与“部分结果”标注待确认。
4. **B-04 未知机构/领域与时间未知**：未知不命中筛选为 SPEC §3 明文；但“未知未命中”的披露计数、是否影响端点可用性、模拟/混合在演示语境的展示口径属分析推导。
5. **B-05 论文作者“合格关系”的证据门槛**：本人确认 vs “已批准自动规则或独立人工核验证据的自动关联”的判定标准未冻结（SPEC §1；与 UC-14 B-06 同源）；身份未定/缺角色证据的处理为分析推导。
6. **B-06 路径证据计数 k 的展示口径**：BR-518 要求 FR12 强度与 IN01 路径论文证据数**分别声明**；是否并列展示、k 是否须等于该边 weight 中的论文部分，未冻结。
7. **B-07 图版本标识的展示与旧版本可用性**：SPEC §2 提到“旧快照仍使用旧快照 ID”，但未规定访客是否可见版本标识、是否允许指定旧版本重查。
8. **B-08 图版本对象化程度与上一版结果**：`AC-IMPL-IN01-02` 要求“固定图版本”；V2.2 未定义图快照对象、生成时机、失效与回退；BR-523 细化要求失败时展示上一版可用结果。本包按“查询内固定版本＋读时投影”建模，不建持久结果对象（C-01），保留上一版结果待定。
9. **B-09 等长路径总条数是否必须披露**：基线只要求返回一条并说明规则；模块 IN01-S08/BR-525 要求“全部列出或说明规则与总条数”。本包按基线返回一条＋说明规则，总条数披露留空（C-02）。
