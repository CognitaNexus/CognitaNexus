## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR/SPEC/冻结 S01 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作或取值规则，但 SRS 未逐句写出 |
| 待确认 | 具体规则、参数、上限、证据门槛或对象化程度未冻结，不能在本 UC 擅自决定 |

## 6. 追踪结论

- 主流程 E1–E20 均有正式来源：IN01-R1/R2/R3 与 `AC-IMPL-IN01-01～04` 直接支撑 E2–E18；NF05 支撑 E3/E20；NF02/§11.2 支撑 E13/E17 的规模与性能**目标**声明。E14 的“端点相同 0 跳”来自 SPEC §4 与既有活动图，与模块 A1 冲突，已登记 C-05。
- A1–A20 中，A3–A13、A16、A20 由 AC、SRS 正文、BR-IMP 或 SPEC 明文支持；A1/A2/A10/A15/A17/A18/A19 部分依赖模块细化（IN01-S01/S03/S04/S07、BR-528），已逐条标注；A6、A14 与筛选/端点口径相关，已标 C-05/B-02/B-04。
- 五项核心业务结论均有正式依据，不是本分析的业务创新：①论文子图限定（IN01-R1；`AC-IMPL-FR12-05`）；②长度＝边数（IN01-R2）；③等长字典序一条＋说明规则（`AC-IMPL-IN01-02`）；④每跳论文证据（IN01-R3）；⑤无路径/无效端点/超规模可区分（IN01-R3；`AC-IMPL-IN01-03/04`）。
- 筛选维度与取值语义（B-01）、机构与领域口径（B-02）、规模上限口径（B-03）、未知/时间未知处理（B-04）、作者关系证据门槛（B-05）、k 展示口径（B-06）、图版本标识与对象化（B-07/B-08）、等长总条数（B-09）、超时阈值文案（B-10）、视图归属与命名（B-11）、端点选择与提示粒度（B-12）均标 `待确认`；C-01～C-06 登记差异/冲突。
- 本表不改变 69 条 AC，不新增第 70 条 AC。
