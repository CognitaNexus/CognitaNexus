## 3. 阅读顺序

先读 01 确认业务边界（为什么只在**论文子图**上筛选与算路径、为什么专利/项目/获奖边永不进入路径、为什么路径长度是边数而不是强度、为什么等长要按字典序只返回一条并说明规则、为什么每跳必须有可点击论文证据、为什么无路径/无效端点/超规模必须分开反馈、为什么不做跨范围推断），再读 02 核对每个事件的证据等级；03 给出 7 个参与类与拒绝候选（含“论文子图投影 ≠ 基础网络强度”“路径结果是读时投影 ≠ 持久结果对象”）；04 只描述交互并标出与 UC-14 的边界；05 只从 04 提取 VOPC 与多重性理由；06 定义职责/属性/关系/机制；07 做全局比较并提出 R5 建议与冲突；08 列出实际执行结果与未决项。

## 4. 本轮的六个核心结论

1. **IN01 只做论文子图**：筛选与最短路径只在 FR12 基础网络中“有合格共同论文证据”的边上进行；共同专利/项目/获奖边不得成为路径边，也不得用来补边（IN01-R1；`AC-IMPL-FR12-05`；BR-IMP-08/09；M5/M15/M51）。基础网络本身仍是四类成果（UC-14），本 UC 不裁剪、不改写它（BR-UC15-20）。
2. **长度是边数，强度不是距离**：无向非加权图，最短＝最少合作边数；路径证据计数 k 只计本次范围内的合格共同**论文**，不等于 FR12 四类共同成果强度 `weight`（IN01-R2；BR-518；SPEC §4；M17/M18/M29/M35）。
3. **等长只返回一条但必须说明规则**：同图版本、同筛选条件下按学者稳定标识（`canonical_id`）序列字典序裁决，返回同一条并同屏说明该决定规则（`AC-IMPL-IN01-02`；IN01-R2；SPEC §4；M29）。
4. **每跳至少一篇可点击论文证据**：逐跳证据必须属于当前筛选图与同一图版本，不跨范围补边；默认从 `canonical_id` 最小的合格共同论文起展示（IN01-R3；BR-518；M31–M36）。
5. **三类失败必须可区分且不推断**：无路径 / 无效端点（不存在、未公开、已合并）/ 超规模各自可观察；筛选导致断开只在当前范围说“无路径”，不推断跨范围或同机构合作（IN01-R3；`AC-IMPL-IN01-03/04`；NF01；M22/M25/M38/M49–M53）。
6. **结果是读时投影**：`CollaborationEdge` 在本 UC 是论文子图投影，`PathResult` 是查询内读时投影；全图无写消息，不建持久路径结果/图快照/图状态机（INV-01/02；BR-IMP-10；06 §8/§11；待确认 B-08/C-01）。
