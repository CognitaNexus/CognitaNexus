# UC-01 公开成果检索

**版本：** V1.0（2026-10-21）
**对应需求：** FR01；AC-IMPL-FR01-01/02/03。
**需求基线：** [`CognitaNexus-Shared-SRS-V2.2-69AC.md`](../../../srs/CognitaNexus-Shared-SRS-V2.2-69AC.md)
**教材依据：** §5.4.1 完善用例文档；§5.4.2 识别分析类；§5.4.6 用例实现四步。

> **范围：** 本UC只处理“访客提交公开检索条件并取得当前页结果”的行为。成果详情（UC-02）、学者主页（UC-03）、统计/网络（UC-11～15）不在本UC。检索是只读操作，不创建或修改成果、学者、主页或关系。

## 1. 参与者

| 类型 | 参与者 | 说明 |
|---|---|---|
| 主要参与者 | 访客 | 未登录也可检索；不需要账号 |
| 次要参与者 | 无 | 系统是业务执行主体；原站/详情导航不在本UC |

## 2. 目标

访客按明确的查询范围、关键词、筛选和排序条件，取得**当前公开有效**的成果或学者结果页；结果不混入另一范围或待审对象，翻页保持同一查询上下文且不重不漏。

## 3. 触发事件

访客提交检索条件，或在已有查询上下文下请求下一页。

## 4. 前置条件

1. 检索入口可用；无需登录。
2. 查询范围明确为“成果”或“学者”。
3. 成果筛选只使用SRS已定义的类型、年份（两端含）、领域、发生时机构；具体排序字段的允许集合和分页大小未在正式基线冻结（Q-01/Q-02）。
4. 成果/学者必须处于当前公开且有效的状态才可进入结果。

## 5. 成功与失败后置条件

### 5.1 成功

1. 返回当前页结果；每一行都满足全部已提交条件。
2. 结果范围与请求范围一致：成果范围不返回学者，学者范围不返回成果。
3. 只包含当前公开、有效的成果/学者；待审/无权对象不进入结果。
4. 排序按选定字段，并以稳定实体ID打破并列。
5. 翻页使用同一查询上下文；页间不重不漏，筛选条件保持。
6. 只读：不改变任何业务实体。

### 5.2 失败/空结果

1. 无匹配：返回“无匹配”，不放宽条件，不当作执行失败。
2. 条件非法：拒绝本次查询，指出非法条件，不执行误导性查询。
3. 依赖失败/超时：返回可区分的执行失败，不伪装为空结果。
4. 失败不修改业务实体，不改变既有公开数据。

## 6. 基本事件流

| 步骤 | 事件 | 需求来源 |
|---:|---|---|
| 1 | 访客选择范围（成果/学者），输入关键词、筛选、排序字段和页码。 | FR01；AC-01/02；E1 |
| 2 | 系统校验范围、筛选组合、排序字段和页码是否可处理。 | FR01；AC-02；E2 |
| 3 | 系统固定本次查询上下文（条件、排序、页码；同一读取版本的机制待Q-02）。 | FR01“切页保留查询上下文”；AC-02；E3 |
| 4 | 若范围为成果：系统在当前公开有效成果中按关键词和类型/年份/领域/发生时机构交集查询。 | FR01；AC-01/02；E4 |
| 5 | 若范围为学者：系统在当前公开有效学者中按关键词查询；成果专属筛选不适用。 | FR01；AC-01；E5 |
| 6 | 系统对候选结果再次应用公开/有效与条件校验。 | FR01；AC-01/02；E6 |
| 7 | 系统按选定字段排序，以稳定实体ID打破并列，并截取当前页。 | FR01；AC-02；E7 |
| 8 | 系统返回当前页、条件回显和可复用查询上下文。 | FR01；AC-02；E8 |
| 9 | 访客请求下一页；系统使用同一上下文和稳定排序继续分页。 | FR01；AC-02；E9 |

## 7. 备选/异常流

| 编号 | 条件 | 系统行为 | 依据 | 说明 |
|---|---|---|---|---|
| A1 | 无匹配 | 返回“无匹配”，不放宽条件，不当作失败。 | AC-IMPL-FR01-03；NF01 | 与执行失败分离 |
| A2 | 范围/筛选/排序/页码非法 | 指出非法条件，不执行查询。 | FR01；AC-IMPL-FR01-02；NF01 | 具体允许的排序字段/分页大小待Q-01/Q-02 |
| A3 | 依赖失败/超时 | 返回执行失败，不显示“无结果”。 | AC-IMPL-FR01-03；NF01 | 5秒超时来自NF02，但性能未实测 |
| A4 | 学者范围携带成果专属筛选 | 视为不适用/非法组合，拒绝或提示；不把成果筛选套到学者。 | FR01只规定“成果支持类型、年份、领域、机构筛选”；分析推导 | 具体交互形式待Q-03 |

## 8. 业务规则

| 规则 | 内容 | 来源 |
|---|---|---|
| BR-UC01-01 | 只检索当前公开、有效的成果/学者；待审/无权对象不进入结果。 | FR01；BR-IMP-01；AC-01 |
| BR-UC01-02 | 范围不混排：成果范围不返回学者，学者范围不返回成果。 | AC-IMPL-FR01-01 |
| BR-UC01-03 | 成果筛选类型、年份（两端含）、领域、发生时机构；多维条件取交集。 | FR01；AC-02 |
| BR-UC01-04 | 按选定字段排序后，以稳定实体ID打破并列。 | FR01；AC-02 |
| BR-UC01-05 | 翻页保留查询上下文；页间不重不漏，筛选保留。 | FR01；AC-02 |
| BR-UC01-06 | 无匹配与执行失败必须可区分；失败不伪装空结果。 | AC-03；NF01 |
| BR-UC01-07 | 检索只读，不改变业务实体。 | FR01执行前提；分析推导 |

## 9. 关联状态

本UC没有业务对象状态迁移：检索只读。成果/学者的“公开有效”是查询过滤条件，不在本UC创建状态机。分页上下文是控制器的会话内分析状态，不是持久实体。

## 11. 待确认

1. 排序字段允许集合、相关性/匹配层级规则。
2. 分页大小、查询上下文有效期、同一读取版本的机制。
3. 学者范围是否接受任何成果专属筛选；本分析按“成果筛选不适用于学者”处理。
4. 真实/模拟数据在检索中的展示规则属于FR16/后续，不纳入本UC。
