# UC-01 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明UC-01每个事件、分支和后置条件有正式需求来源；区分已证实、分析推导和待确认。
**主证据：** SRS V2.2 FR01/NF01/NF02；69 AC权威账本；BR-IMP-01。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式SRS/AC/BR直接支持 |
| 分析推导 | 由已证实查询语义必然要求的协作或守卫，SRS未逐句写出 |
| 待确认 | 排序字段、分页大小、上下文版本等具体参数未冻结 |

## 2. 主事件

| 事件 | 内容 | 来源 | 性质 | 备注 |
|---|---|---|---|---|
| E1 | 访客提交范围、关键词、筛选、排序、页码 | FR01；AC-01/02 | 已证实 | 无需登录（NF01） |
| E2 | 系统校验范围与筛选组合 | FR01；AC-02 | 已证实 | 具体允许的排序字段/分页大小待Q-01/Q-02 |
| E3 | 固定本次查询上下文 | FR01“切页保留查询上下文”；AC-02 | 已证实业务要求；分析推导机制 | 同一读取版本的具体机制是A-01，不写成已批准要求 |
| E4 | 成果范围查询公开有效成果并应用类型/年份/领域/发生时机构交集 | FR01；AC-01/02 | 已证实 | 年份两端含；机构为发生时机构 |
| E5 | 学者范围查询公开有效学者 | FR01；AC-01 | 已证实 | 学者不是UserProfile；不做同名合并 |
| E6 | 对候选再次应用公开/有效与条件校验 | FR01；AC-01/02；BR-IMP-01 | 分析推导 | 防止待审/越权对象进入结果 |
| E7 | 按选定字段排序，以稳定实体ID破并列，截取当前页 | FR01；AC-02 | 已证实 | 排序字段集合待Q-01 |
| E8 | 返回当前页、条件回显和查询上下文 | FR01；AC-02 | 已证实 | 不要求返回总数；不虚构字段 |
| E9 | 访客用同一上下文请求下一页 | FR01；AC-02 | 已证实 | 页间不重不漏、筛选保持 |

## 3. 备选/异常

| 事件 | 条件 | 处理 | 来源 | 性质 |
|---|---|---|---|---|
| A1 | 无匹配 | 返回无匹配；不放宽条件；不当作失败 | AC-IMPL-FR01-03；NF01 | 已证实 |
| A2 | 范围/筛选/排序/页码非法 | 指出非法条件，不执行查询 | FR01；AC-02；NF01 | 已证实/分析推导 |
| A3 | 依赖失败/超时 | 返回执行失败，不显示“无结果” | AC-IMPL-FR01-03；NF01；NF02 | 已证实；性能未实测 |
| A4 | 学者范围携带成果专属筛选 | 视为不适用/非法组合，拒绝或提示 | FR01“成果支持…”；分析推导 | 待Q-03确认交互形式 |

## 4. 后置条件来源

| 后置条件 | 来源 |
|---|---|
| 所有行满足全部条件 | FR01；AC-IMPL-FR01-02 |
| 范围不混排 | AC-IMPL-FR01-01 |
| 只包含公开有效对象 | FR01；BR-IMP-01；AC-01 |
| 选定字段排序+稳定ID破并列 | FR01；AC-02 |
| 页间不重不漏、筛选保持 | FR01；AC-02 |
| 无匹配与失败分离 | AC-03；NF01 |
| 只读，不改业务实体 | FR01执行前提；分析推导 |

## 5. 不纳入本UC的事件

| 事件 | 原因 | 归属 |
|---|---|---|
| 打开成果详情/来源外链 | 详情展示和来源访问是独立目标 | UC-02 |
| 打开学者/个人主页 | 主页展示是独立目标 | UC-03 |
| 统计、排名、热点、网络 | 不是检索结果页查询 | UC-11～15 |
| 登录、个性化、推荐 | FR01公开检索无需登录；O01/O02延期 | 后续/延期 |
| 检索结果数据修复/治理 | 本UC只读；治理有独立UC | UC-09/10 |
| 真实/模拟分组展示 | FR16/BR-IMP-07范围，不是FR01核心 | UC-16/后续 |

## 6. 追踪结论

- E1–E9、A1–A4均有正式来源或明确分析推导；
- “同一读取版本”（A-01）是保障分页不重不漏的分析机制，不是已批准的性能/存储需求；
- 排序字段集合、分页大小、上下文有效期、学者范围与成果筛选的组合方式未冻结；
- 不新增AC、不修改69条基线。
