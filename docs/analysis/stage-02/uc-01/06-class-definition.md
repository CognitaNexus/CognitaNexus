# UC-01 分析类职责、属性、关系与分析机制

**版本：** V1.0（2026-10-21）
**方法：** 教材§5.5.1职责、§5.5.2属性、§5.5.3关系、§5.5.4分析机制。
**范围：** 只定义UC-01能够证实的部分；跨用例关系留给R5。

## 1. 定义原则

1. Do/Know职责来自M1–M23及事件流；
2. 属性只写检索需要的业务信息，不写数据库字段、索引或API；
3. 控制类的查询上下文是单次分析状态，不是持久实体；
4. 无消息支持的Work—Scholar关系不建立；
5. 排序字段集合、分页大小、读取版本机制未冻结，不伪装成已批准规则。

## 2. SearchUI（Boundary）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 接收范围/关键词/筛选/排序/页码；显示当前页、无匹配、非法条件、执行失败、下一页 | M1/M4/M5/M11/M12/M15–M23 |
| 候选分析操作（`/`） | `/接收查询请求`、`/显示结果页`、`/显示无匹配`、`/显示失败`、`/显示非法条件` | M1–M23 |
| Know | 当前展示状态与条件回显；不持久保存业务对象 | 分析推导 |
| 业务属性 | 无持久业务属性；查询输入是短期参数 | §5.5.2；Boundary |
| 关系 | 单向关联`SearchCoordinator`（M2/M4/M11/M15/M17/M20/M22） | 04消息表 |
| 不能承担 | 不能决定公开过滤、条件交集、稳定排序、分页上下文或空/失败分类 | FR01；AC-01/02/03 |

## 3. SearchCoordinator（Control）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 校验范围/筛选/排序/页码；固定查询上下文；按范围查询成果或学者；复核公开/有效；条件交集；稳定排序/分页；处理空/失败；返回当前页/下一页 | M2–M23 |
| 候选分析操作（`/`） | `/校验查询`、`/确定范围`、`/固定查询上下文`、`/查询成果`、`/查询学者`、`/应用公开与条件过滤`、`/稳定排序与分页`、`/处理空结果`、`/处理执行失败` | M2–M23 |
| Know | 本次查询的`scope`、关键词、筛选条件、排序字段、页码、读取版本引用、执行结果；均为单次分析状态 | FR01；AC-02；A-01 |
| 业务属性 | 无长期业务属性。分析状态：`scope`（成果/学者）、`keyword`、`filters`（类型/年份/领域/发生时机构）、`sortField`、`pageNumber`、`readVersionRef`（机制待Q-02）、`outcome` | FR01；Q-01/Q-02 |
| 关系 | 与`SearchUI`、`WorkEntity`、`Scholar`的单向关联 | M2/M4/M7/M9/M11/M15/M17/M20/M22 |
| 不能承担 | 不承载成果/学者的业务属性；不是数据库/检索引擎；不定义可检索字段的存储结构 | §5.4.2；§5.5.1 |
| 分析机制 | 公开/有效过滤；范围隔离；条件交集；稳定排序+稳定ID；分页上下文；空/失败分离；只读 | FR01；AC-01/02/03；NF01 |

## 4. WorkEntity（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 提供当前公开有效成果；按关键词及类型/年份/领域/发生时机构回答查询；提供稳定ID用于排序 | M7/M8；E4/E6/E7 |
| 候选分析操作（`/`） | `/匹配公开检索条件`、`/判断公开有效` | M7/M8/M13/M14 |
| Know | 公开/有效状态、稳定ID、类型、年份、领域、发生时机构、公开可检索文本 | FR01；AC-01/02 |
| 业务属性 | `stableId`、`publicState`、`type`、`year`、`field`、`occurredInstitution`、`searchableText`（公开字段的可检索投影；具体字段组成来自FR02/后续，不在本UC扩展） | FR01；AC-01/02；Q-01 |
| 关系 | 被`SearchCoordinator`查询（M7）；不与Scholar建立检索关系 | 04消息表；AC-01 |
| 不能混淆 | 不是SourceRecord（来源证据）、不是WorkVersion（版本证据）、不是详情页 | FR02/FR16；UC-02 |
| 分析机制 | 持久性；公开/有效过滤；稳定ID；类型/年份/领域/机构筛选 | FR01；AC-01/02 |

## 5. Scholar（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 提供当前公开有效学者；按关键词回答查询；提供稳定ID用于排序 | M9/M10；E5/E6/E7 |
| 候选分析操作（`/`） | `/匹配公开检索条件`、`/判断公开有效` | M9/M10/M13/M14 |
| Know | 公开/有效状态、稳定ID、公开可检索身份信息 | FR01；AC-01 |
| 业务属性 | `stableId`、`publicState`、`searchableIdentity`（公开姓名/别名等可检索投影；具体字段来自公开学者展示，不在本UC扩展） | FR01；FR03；Q-03 |
| 关系 | 被`SearchCoordinator`查询（M9）；不与WorkEntity建立检索关系 | 04消息表；AC-01 |
| 不能混淆 | 不是UserProfile（普通账号主页）；不按同名自动合并；不是Authorship | FR03；SRS §12；BR-IMP-03；FR12 |
| 分析机制 | 持久性；公开/有效过滤；稳定身份ID | FR01；AC-01；BR-IMP-03 |

## 6. 关系定义汇总

| 关系 | 角色/方向 | 多重性 | 来源 | 状态 |
|---|---|---|---|---|
| SearchUI → SearchCoordinator | UI请求/显示 | 不定义持久多重性 | M2/M4/M11/M15/M17/M20/M22 | 已定义（单向关联） |
| SearchCoordinator → WorkEntity | 查询/读取 | 不定义持久多重性 | M7 | 已定义（单向关联） |
| SearchCoordinator → Scholar | 查询/读取 | 不定义持久多重性 | M9 | 已定义（单向关联） |
| WorkEntity — Scholar | **不建立** | — | 无消息；范围互斥；AC-01 | 本UC不建立 |
| WorkEntity — SourceRecord/WorkVersion | **本UC不建立** | — | 详情/来源属于UC-02/16 | 留待其他UC |
| Scholar — UserProfile/Claim/Auth | **本UC不建立** | — | 公开检索不登录/不认领 | 留待其他UC/R5 |

**说明：** 查询关联不标持久多重性，因为它们表达一次检索调用，不是对象包含/持久聚合。真正需要多重性的关系本UC没有证据，故不擅自填写。

## 7. 分析机制汇总

| 机制 | 作用对象 | 业务问题 | 本UC约束 | 未决定/后续 |
|---|---|---|---|---|
| 公开/有效过滤 | WorkEntity、Scholar、Coordinator | 待审/无权对象不得进入结果 | 查询前/返回后均过滤 | 具体字段级权限 |
| 范围隔离 | Coordinator | 成果/学者不混排 | 一次查询只走一个范围 | 是否支持混合范围未在FR01定义 |
| 条件交集 | Coordinator、WorkEntity | 所有行满足全部条件 | 类型/年份/领域/发生时机构取交集 | 年份两端含已明确 |
| 稳定排序 | Coordinator | 同分页可复现 | 选定字段+稳定实体ID | 排序字段集合Q-01 |
| 分页上下文 | Coordinator | 页间不重不漏、筛选保持 | 同一查询上下文；A-01读取版本机制待定 | 分页大小/有效期Q-02 |
| 空/失败分离 | Coordinator、UI | 无匹配≠执行失败 | 独立消息/显示/返回 | 超时阈值按NF02，未实测 |
| 只读 | 全体 | 检索不修改业务实体 | 无写消息 | — |
| 性能容量 | 查询路径 | 500万/100并发目标 | 仅引用NF02；不在类图中设计索引 | NOT RUN |
