# UC-17 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-17 的每个事件、后置条件与备选流都有正式来源；把“分析推导”和“待确认”单独标出，并明确本 UC 不拥有的执行职责。
**主证据：** SRS V2.2 FR14 正文与 `AC-IMPL-FR14-01/02`、FR05-03、FR08-01、FR10-02、NF01/NF03/NF06/NF07、§3.2、§6.1～§6.4、§7.1/§7.2、§8、§12、BR-IMP-01/05/10/11；核心 SPEC §3（公共状态、INV-01/05/06/08/09/10）、§6.2、§6.3、§6.4；69 AC 权威账本；既有 [`DGM-USECASE-06`](../../../uml/admin/DGM-USECASE-06-admin.puml)、[`DGM-CLASS-01`](../../../uml/analysis/DGM-CLASS-01-analysis.puml)、[`01-BCE分析类模型`](../01-BCE分析类模型.md)；已交付的 UC-05/06/09/10 分析（只读参考其对象与状态语义）。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR/SPEC/冻结 S01 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作，但 SRS 未逐句写出 |
| 待确认 | 具体规则、参数、状态集合或责任分工未冻结，不能在本 UC 擅自决定 |

## 6. 追踪结论

- E1–E18 均有正式来源或明确标注“分析推导”；其中 E3（权限裁剪语义）、E10（只读派生投影）、E18 的“查询访问留痕”为分析推导，已在 01 §11 与 08 §6 标 `待确认`。
- A2 是本 UC 的核心负向验收（`AC-IMPL-FR14-01`）；A5/A6 覆盖 `AC-IMPL-FR14-02` 的“五要素可定位＋不可见证明原文”；A1/A3 覆盖 `AC-IMPL-NF03-01` 的“停用/未授权读取”部分。
- “入口统一但权限不统一”“不执行决定”“审计只读且追加式”“证明原件不外泄”四项均有正式依据，不是本分析的业务创新；本 UC 不新建任何 AC。
- 权限粒度（B-01）、待办载体与口径（B-02/B-06）、保留期限与遮蔽清单（B-03/B-04，D-09）、查询访问留痕与导出（B-05）、成果变更待办状态来源（B-07）、分类入口范围（B-08）标 `待确认`，未写成已批准规则。
- 本表不修改 69 条 AC，不新增第 70 条 AC；与全局模型的命名/职责差异登记于 07，由 R5 统一。
