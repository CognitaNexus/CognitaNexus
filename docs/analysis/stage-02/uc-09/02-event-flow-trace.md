**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-09 的每个事件、后置条件与备选流都有正式来源；把“分析推导”和“待确认”单独标出。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR/SPEC/冻结 S01 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作，但 SRS 未逐句写出 |
| 待确认 | 具体规则、字段清单、阈值、状态集合或责任分工未冻结，不能在本 UC 擅自决定 |

## 6. 追踪结论

- 主流程 E1–E17 均有正式来源；“字段优先级顺序”“类型细化必填项”“相似度阈值/年份窗/截断长度”“处理项状态机与待办边界”“来源失效记录责任”按待确认处理（B-01～B-08），未写成已批准规则。
- A1/A2/A3/A4/A5/A8/A9/A10/A12/A13/A15/A16 由 AC、SRS、SPEC 规则的明文要求支持；A6 的“现行不可执行”来自 DD-06 与 SPEC §5.3；A7/A11/A14 为“已证实原则 + 未冻结参数/分工”。
- “稳定标识优先且须证据相容”“标题相似不得自动合并”“重复来源不增加实体数”“原值不被改写”“时间语义不混称”“已确认值不被静默覆盖”“人工合并/拆分留痕”七项均有正式依据，不是本分析的业务创新。
- 本表不改变 69 条 AC，不新增第 70 条 AC；不把模块细化的旧验收（如 `AC-FR09-S07-02` 的“四项证据自动合并”）当作现行规则，差异见 07 §3。
