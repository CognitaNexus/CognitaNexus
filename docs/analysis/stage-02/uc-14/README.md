## 4. 本轮的五个核心结论

1. **基础网络是四类成果网络，不是论文网络**：论文、专利、项目、获奖按各自合格角色同等参与建边；论文子图限定、按机构/领域筛选与最短路径属 IN01/UC-15（FR12 明文；`AC-IMPL-FR12-01/05`；BR-IMP-08；M7/M51）。
2. **建边资格分两层，旁证永不建边**：成果须公开、生效、真实（时间未知不排除建边）；参与关系须四类角色证据、身份明确、可公开、状态为本人确认或有独立核验证据的自动关联；**仅同机构、同领域、相似姓名、同来源或账号资料不产生边**（`AC-IMPL-FR12-04`；BR-IMP-01/03/08；§11.3；M10/M13）。
3. **强度＝去重合格共同成果数，无向唯一且可回溯**：任意两名学者只有一条无向边，每项去重成果对同一学者对只贡献 1，多来源、重复角色与已确认版本都不放大；每条边至少一项证据，强度必须等于证据清单条数（`AC-IMPL-FR12-01/02/03`；BR-IMP-08；M14–M18）。
4. **不合格关系既不产生强度也不作证据**：待核验/争议/已排除关系不参与建边，仅依赖该关联的边不出现；仍有其他合格证据的边保留并按有效证据计数；管理员审核不等于本人确认（`AC-IMPL-FR12-04`；FR15；§6.4/§11.3；M10）。
5. **网络是读时投影，不是持久结果对象**：全图无写消息，不建持久“网络结果/图快照/图版本”；节点、边、强度与披露在请求内由生效事实推导，且与检索/门户/统计使用同一生效关系版本（NF05；M45/M46；05 §4；C-01 待确认）。
