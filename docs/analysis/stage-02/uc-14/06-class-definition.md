# UC-14 分析类职责、属性、关系与分析机制

**版本：** V1.0（2026-10-21）
**方法：** 教材 §5.5.1 职责、§5.5.2 属性、§5.5.3 关系、§5.5.4 分析机制。
**范围：** 只定义 UC-14 能够证实的部分；跨用例统一关系不在此擅自补齐。

## 1. 定义原则

1. “做（Do）”型职责说明对象能执行/协调什么；“知道（Know）”型职责说明对象必须知道/提供什么。
2. 属性只写业务信息，不写数据库字段、图数据库实现、主键类型、索引、物化视图或 API 参数；图构建算法、缓存与部署不在此定义。
3. 关系只写有消息或正式业务约束支持的；无依据的跨用例关系留待 R5。
4. 控制类与边界类没有长期业务属性；视图条件、节点/边、强度、披露与规模是**单次请求的分析状态**。
5. `CollaborationEdge` 是**派生实体**：有业务身份（学者对）、有业务事实（证据集合）与可观察值（强度），但本 UC 不把它作为独立事实源持久保存；结果对象化程度见 07 §5 C-01（待确认）。
6. 展示上限、时间范围与默认窗、无合作学者口径、角色证据门槛、强度排序/阈值等未冻结项不伪装成类定义，统一标 `待确认`（B-01～B-12）。
7. 本 UC 不定义任何“最短路径/图筛选/质量评分/推荐”职责：前者属 UC-15/IN01，后者被基线明文排除，不得作为候选操作出现（BR-IMP-09；BR-522 语境）。

## 9. 与其他 UC 的边界

- **UC-15（IN01 筛选与最短路径）**：本 UC 只产出四类基础网络的节点、边、强度、证据与披露；UC-15 在其上取**论文子图**做按领域/机构筛选与 BFS 路径。本 UC 不计算路径、不产出图版本、不按机构/领域过滤；只保证边保留成果类型使论文边可区分（A16；BR-UC14-15/16）。
- **UC-09（去重清洗）**：成果去重与版本确认不在本 UC；本 UC 只消费“已去重实体 + 已确认/未确认版本”状态（BR-IMP-02）。
- **UC-08/UC-10（归属与身份）**：身份消歧、合并、归属判定与排除不在本 UC；本 UC 只解析生效的 `canonicalId` 与关系状态，并把身份歧义交回（BR-IMP-03；AC-IMPL-FR15-04/05/06）。
- **UC-11/UC-12/UC-13**：统计分布、机构排名与领域热点不在本 UC；四者共用“默认只真实、披露与结果同屏、空/失败可区分、同一生效数据版本”的口径，但对象不同（成果/机构/关键词/学者对）。
- **UC-01/UC-02/UC-03**：检索、成果详情与学者门户不在本 UC；本 UC 只提供详情与门户入口，并在目标不可用时给原因（FR12-S09 细化）。
- **UC-16**：规模核对（≥100 万/≥500 万去重实体、真实数单列）不在本 UC；本 UC 只保证强度按去重实体计算（`AC-IMPL-FR16-02` 边界）。
- **UC-17/FR14**：网络失败明细、图结果运营与审计查询不在本 UC；本 UC 无受保护写入。

| 机制 | 作用对象 | 业务问题 | 本 UC 可证实的约束 | 未决定/后续 |
|---|---|---|---|---|
| 成果与关系双层资格 | Coordinator、WorkEntity、Authorship | 不合格成果或不合格关系混入网络 | 成果须公开/生效/真实（时间未知不排除）；关系须角色证据、身份明确、可公开、状态合格；两者分别判定 | 角色证据门槛（B-06） |

| 旁证不建边 | Coordinator、Scholar、Authorship | 用同机构/同领域/相似姓名推断合作 | 仅“同一合格共同成果上的两条合格关系”成边；机构/领域/姓名不构成证据 | 机构/领域筛选属 UC-15（C-03） |
| canonical 节点与合并解析 | Coordinator、Scholar | 同名合并、重复节点、自环 | 节点只用 `canonicalId`；合并解析到当前身份；环/失效为异常；无重复节点与自环 | 合并判定属 UC-10 |
| 无向唯一边键 | Coordinator、CollaborationEdge | 同一对学者出现多条边 | min/max `canonicalId` 边键；作者顺序/角色/成果不同不分裂；自环不生成 | — |
| 强度按成果去重 | Coordinator、CollaborationEdge | 来源数/版本数/重复角色放大强度 | 每成果每对 1；多来源、重复角色、已确认版本不重复；跨来源不累计 | 重复角色披露（B-11） |

| 数据类别与公开性 | Coordinator、WorkEntity、Scholar | 模拟数据冒充真实、未公开对象出现 | 默认只真实；模拟/混合仅演示并标识；缺标识不计入真实；未公开学者不成节点 | 混合/缺标识处理（B-04） |
