## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR/SPEC/冻结 S01 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作或取值规则，但 SRS 未逐句写出 |
| 待确认 | 具体规则、参数、上限、证据门槛或对象化程度未冻结，不能在本 UC 擅自决定 |

> **FR12-Sxx / BR-5xx 说明：** 文中 `FR12-Sxx`、`BR-5xx`、`AC-FR12-Sxx-nn`、`AC-FR13-Sxx-nn` 等均为模块 SRS《analytics-graph》的细化条目，不是 69 AC 正文；其效力低于 SRS V2.2/69 AC。

## 6. 追踪结论

- 主流程 E1–E20 均有正式来源；E1/E2/E13–E17 的部分细节来自模块细化（FR12-S01/S02/S03/S05/S06/S09），已逐条标注“细化”；E3 的“缺数据类别标识单列”、E7 的“已批准自动规则或独立人工核验证据”门槛细化、E10 的边键规则来自 SPEC §1/§2，均有上游明文支撑。
- A1–A20 中，A4/A6/A8–A16/A18 由 AC、SRS 正文、BR-IMP 或 SPEC 明文支持；A1–A3、A5、A7、A17、A19、A20 部分依赖模块细化或分析推导，已标注；A5、A11、A17 的取值口径列入待确认（B-02/B-04/B-06）。
- “四类共同成果建边、同机构/同领域/相似姓名不建边、每成果每对 1 强度、跨来源不重复累计、边可追溯、待核验/争议/已排除不成边、默认只真实、论文子图属 IN01”八项均有正式依据，不是本分析的业务创新。
- 展示上限（B-02）、时间范围与默认窗（B-03）、数据类别缺标识（B-04）、无合作学者口径（B-05）、角色证据门槛（B-06）、图版本与上一版结果（B-08）、已排除关系是否可视化提示（B-09）、强度是否排序/过滤（B-10）、重复角色披露（B-11）、协调者命名与合并（B-12）均标 `待确认`，未写成已批准规则。
- 模块细化 FR12-S03 A1（可不展示强度）与基线 `AC-IMPL-FR12-03` 冲突（C-02）；`DGM-USECASE-02` 图例“FR12 只接受论文证据”与基线冲突（C-04）；FR12-S06 收窄提示中的领域/机构条件超出基线 FR12 范围（C-03）；FR12-S08/`DGM-STATE-03` 的结果对象取向与本包“读时投影”不同（C-01）。
- 本表不改变 69 条 AC，不新增第 70 条 AC。
