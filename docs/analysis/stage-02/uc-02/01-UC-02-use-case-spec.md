# UC-02 查看成果详情与来源

**版本：** V1.0（2026-10-21）
**对应需求：** FR02（四类成果详情和来源访问）、FR16（四类成果与可追溯规模）。
**覆盖验收条件：** `AC-IMPL-FR02-01`、`AC-IMPL-FR02-02`、`AC-IMPL-FR16-01`、`AC-IMPL-FR16-02`、`AC-IMPL-NF01-01`；`AC-IMPL-NF02-01/02` 只作容量/超时约束引用。
**需求基线：** [`CognitaNexus-Shared-SRS-V2.2-69AC.md`](../../../srs/CognitaNexus-Shared-SRS-V2.2-69AC.md)（§4 FR02/FR16、§7.1 字段、§7.2 不变量、§8 权限、§9 NF01/NF02/NF04/NF07）
**教材依据：** §5.4.1 完善用例文档；§5.4.2 识别分析类；§5.4.3 分析交互；§5.4.4 构造 VOPC。

> **范围：** 本 UC 只处理“访客打开**一条**已收录成果的详情，读取其公共/类型适用字段、时间语义、作者/参与者角色、全部可公开来源、数据性质与更新时间，并可跳转原站外链”的行为。
> 检索与结果页（UC-01）、学者/个人主页（UC-03）、成果确认/补录/纠错（UC-08）、清洗去重与消歧（UC-09/10）、规模核对（UC-16）、认领与授权（UC-05/06/07）、统计与网络（UC-11～15）、全文托管（SRS §2.1 明确不建设）均不在本 UC。
> 本 UC 是**只读**用例：不创建、不修改、不删除 WorkEntity、SourceRecord、WorkVersion、Authorship。

## 1. 参与者

| 类型 | 参与者 | 说明 |
|---|---|---|
| 主要参与者 | 访客 | 未登录也可打开公开详情；不需要账号（NF01；SRS §8“公开检索/详情/门户/统计/网络 = 读”） |
| 次要参与者 | 原站（外部来源） | 外链跳转目标。平台只给出原站地址，不代理、不托管全文；原站可用性不由平台控制（FR02“来源外链只跳原站，不承诺全文”） |

原站是外部参与者，不是系统类；平台不向原站发送业务请求，也不因原站失效修改任何业务实体。

## 2. 目标

访客用最小可核实的方式读懂一条去重成果：**一条成果实体 + 全部可公开来源 + 四类适用字段 + 分开的时间语义 + 作者/参与者角色 + 有明示证据的版本关系**，且能跳到原站进一步查看；外链失效不影响元数据可读，也不删除成果。

## 3. 触发事件

访客在检索结果（UC-01）中选择一条成果打开详情，或凭稳定成果标识直接打开详情地址。

## 4. 前置条件

1. 详情入口可用；无需登录（NF01；SRS §8）。
2. 目标成果处于**当前公开且生效**状态；待审、未生效、非公开对象不满足（FR02 执行前提；BR-IMP-01）。
3. 成果类型属于论文/专利/项目/获奖之一；类型或名称缺失的记录不得生成公开有效成果（SPEC §3 公共契约）。
4. 该成果至少有一条满足公开/许可要求的来源；许可不明不得扩大公开范围（FR02 执行前提；BR-IMP-01；SPEC §3 `source_url、rights、provenance`）。只有无公开许可来源时是否整体隐藏成果未冻结，见第 11 节 Q-06。
5. 本 UC **不要求**原站当前可用；外链可失效是被明示接受的业务条件（`AC-IMPL-FR02-02`）。

## 5. 成功与失败后置条件

### 5.1 成功

1. 详情只呈现**一条去重成果实体**；同一成果下的多条来源以多条来源记录展示，不拆成多个成果（`AC-IMPL-FR02-01`、`AC-IMPL-FR16-02`；BR-IMP-02；INV-02）。
2. 展示公共字段与四类适用字段；不存在的专属字段标“未知”，不造默认值（SRS §7.1）。
3. 时间语义分开：类型发生时间、来源采集/导入时间、更新时间各归其位，不混称，不以采集日期代替发生时间（SRS §7.1；SPEC §3 `time_events[]`）。
4. 每条来源展示来源 ID、来源域/使用许可、采集/导入时间与数据性质（真实/模拟/混合）（FR16；SRS §7.1；BR-IMP-07）。
5. 作者/参与者角色按四类分别表达（论文作者顺序、专利发明人、项目负责人、获奖人员/团队）；待核验、争议、已排除的关系不得展示为已确认参与（FR02；SRS §6.4；FR15）。
6. 只在**有明示证据**时显示预印本/正式发表的版本关系（FR02；SPEC DD-08）。
7. 只提供原站外链，不提供、不承诺全文（FR02；SRS §2.1）。
8. 重要字段存在待审新值时，继续展示当前生效值，不展示待审值（SRS §6.4；BR-IMP-10）。
9. 只读：WorkEntity、SourceRecord、WorkVersion、Authorship 均未被修改。

### 5.2 失败/异常后置条件

1. 目标不存在/非公开/待审/无效：不展示该成果字段，返回可区分的“不可访问”状态；不修改实体。
2. 读取依赖失败或超时：返回**执行失败**，不伪装成“不存在”或“无来源”（NF01）。
3. 原站外链失效：元数据仍可读，外链失败被明示，成果不被删除或隐藏（`AC-IMPL-FR02-02`；NF07 相关“停用来源后既有公开成果仍可读”）。
4. 来源无公开许可：该来源不进入公开详情，不扩大公开范围；不删除成果和来源记录（BR-IMP-01；BR-IMP-04）。

## 6. 基本事件流

| 步骤 | 事件 | 需求来源 |
|---:|---|---|
| E1 | 访客请求打开一条成果的详情（携带稳定成果标识）。 | FR02 |
| E2 | 系统按稳定标识读取该成果当前公开有效状态与公共字段（类型、标题、公开生效状态）。 | FR02 执行前提；BR-IMP-01 |
| E3 | 系统按成果类型读取该类适用专属字段；不存在的专属字段标“未知”。 | FR02“展示…四类适用字段”；SRS §7.1；`AC-IMPL-FR16-01` |
| E4 | 系统读取数据性质（真实/模拟/混合）与时间语义：类型发生时间、来源采集/导入时间、更新时间分开。 | FR16；SRS §7.1；BR-IMP-07 |
| E5 | 系统读取该成果**全部可公开来源**记录（来源 ID、来源域、许可或使用范围、采集/导入时间、原站地址）。 | FR02“全部可公开来源ID”；FR16；`AC-IMPL-FR02-01` |
| E6 | 系统读取**有明示证据**的版本关系（预印本/正式发表）。 | FR02“预印本/正式发表须有证据才显示版本关系”；DD-08 |
| E7 | 系统读取作者/参与者角色与顺序及其关系状态。 | FR02“作者/参与者角色”；FR15；SRS §6.4 |
| E8 | 系统按公开/生效/许可要求过滤可展示字段：待审新值不展示，无许可来源不公开，私有证明不公开，只保留原站外链。 | BR-IMP-01/10/11；SRS §6.4 |
| E9 | 系统返回并展示详情：一条成果 + 多条来源 + 适用字段/未知标注 + 数据性质与更新时间 + 版本关系（如有）+ 参与角色；只给外链，不给全文。 | `AC-IMPL-FR02-01`、`AC-IMPL-FR16-01`；FR02 |
| E10 | 访客打开来源外链；系统把原站地址交给访客，由访客访问原站。 | FR02“只跳原站，不承诺全文” |
| E11 | 访客返回详情，元数据仍可读；本 UC 未对任何业务实体发出写操作。 | `AC-IMPL-FR02-02`；FR02 执行前提 |

## 7. 备选/异常流

| 编号 | 条件 | 系统行为 | 依据 | 说明 |
|---|---|---|---|---|
| A1 | 目标不存在、非当前公开、待审或无效 | 不展示成果字段，返回“不可用/不可访问”；不修改实体 | FR02 执行前提；BR-IMP-01 | 与执行失败可区分；对外是否细分“不存在/无权”待 Q-02 |
| A2 | 原站外链失效（不可达/已撤下） | 元数据仍可读；外链失败被明示；成果不被删除或隐藏 | `AC-IMPL-FR02-02`；BR-IMP-04 | 具体提示文案与重试策略待 Q-01（D-05） |
| A3 | 读取依赖失败或超时 | 返回执行失败，不伪装“不存在/无来源”；不改实体 | NF01；`AC-IMPL-NF01-01` | 5 秒超时来自 NF02，运行未实测 |
| A4 | 某类型专属字段缺失 | 该字段标“未知”，不补默认值、不推测 | SRS §7.1“不存在的专属字段标未知，不造默认值”；`AC-IMPL-FR02-01` | 是否给出“缺失原因”待 Q-08 |
| A5 | 同一成果有两条及以上许可来源 | 一条成果实体展示多条来源，各来源独立展示；不拆成多个成果、不增加成果数 | `AC-IMPL-FR02-01`；`AC-IMPL-FR16-02`；BR-IMP-02；INV-02 | 来源展示顺序/主来源未定，Q-04 |
| A6 | 来源许可或使用范围不明 | 该来源不扩大公开范围；数据性质不明显式标“未知”，不默认真实 | BR-IMP-01；SPEC §3 `data_origin` | 与 Q-06/Q-07 相关 |
| A7 | 版本关系无明示证据 | 不显示版本关系；不把疑似关系写成已确认版本 | FR02；DD-08 | 是否显示“疑似版本”待 Q-03 |
| A8 | 重要字段存在待审新值 | 继续展示当前生效值；待审值不展示 | SRS §6.4；BR-IMP-10 | 是否提示“有待审更新”待 Q-09 |
| A9 | 参与关系为待核验/争议/已排除 | 不展示为已确认参与，不冒充本人确认 | FR03-02 同类约束；SRS §6.4；FR15 | 是否展示为“疑似参与”待 Q-05 |
| A10 | 成果类型缺失或不属于四类，无法识别适用字段 | 不生成/不展示为公开有效成果；按 A1 处理 | SPEC §3“缺类型或名称不得生成公开有效成果”；`AC-IMPL-FR16-01` | 四类可识别是本 UC 的展示前提 |

## 9. 关联状态

本 UC **不产生状态迁移**，只读取四类状态/事实作为展示守卫：

| 状态 | 归属 | 本 UC 如何读用 |
|---|---|---|
| 公开生效状态（公开/有效、待审、无效） | WorkEntity（治理结论，产生于 FR09/FR14/FR07） | 决定是否可展示（A1/A8） |
| 参与关系状态（自动关联/本人确认/待核验/争议/已排除） | Authorship（FR15） | 决定是否可作为已确认参与展示（A9） |
| 来源许可/数据性质（许可可用、真实/模拟/混合） | SourceRecord | 决定是否公开该来源、如何标注数据性质（A6） |
| 版本关系是否有明示证据 | WorkVersion | 决定是否显示版本关系（A7） |

状态机的产生与迁移不属本 UC：认领与授权的 `待审核/待补充/已通过/已驳回/争议` 属 UC-05/06，成果治理与去重状态属 UC-09/10，纠错生效属 UC-08。

## 11. 待确认

1. **Q-01** 外链失效的具体提示文案、是否提供重试/替代入口（与全局 D-05 同一问题）。
2. **Q-02** 对外是否区分“不存在”与“无权/非公开”两种不可访问状态；NF01 要求页面状态可区分，但粒度未冻结。
3. **Q-03** 版本关系无明示证据时，公开详情是否呈现“疑似版本”标记、对谁呈现；FR02 只要求“有证据才显示版本关系”，SPEC DD-08/T20 已要求内部保持独立并标疑似，故问题范围是公开呈现而非是否标记。
4. **Q-04** 多来源的展示顺序、是否存在“主来源”标记；SRS 只要求全部可公开来源可追溯。
5. **Q-05** 待核验/争议参与关系是否以“疑似参与”形式展示；FR03-02 只禁止显示为已确认。
6. **Q-06** 成果若没有任何具备公开许可的来源，是否整体不可公开；FR02 执行前提未给出结论。
7. **Q-07** 来源级数据性质（真实/模拟/混合）与成果级“真实/模拟/混合”标识的聚合口径（BR-IMP-07 只规定互斥标识）。
8. **Q-08** 缺失字段是否展示“缺失原因/最后核验时间”；SRS §7.1 只要求标“未知”。
9. **Q-09** 详情出现待审新值时是否提示“有待审更新”；SRS §6.4 只要求旧值继续公开。
10. **Q-10** NF02 容量/超时在详情路径的适用方式（5 秒单请求超时是否同样约束详情读取），运行状态 NOT RUN。

13. **Q-13** 作者角色/顺序的模型归属：SRS §7.1 将其列为论文专属字段，本分析按关系事实归 `Authorship`；需在 R5 统一分析类时确认。
