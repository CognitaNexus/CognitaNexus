# UC-02 分析类职责、属性、关系与分析机制

**版本：** V1.0（2026-10-21）
**方法：** 教材 §5.5.1 职责、§5.5.2 属性、§5.5.3 关系、§5.5.4 分析机制。
**范围：** 只定义 UC-02 能证实的部分；跨用例职责与统一分析类留给 R5。

## 1. 定义原则

1. Do/Know 来自 M1–M28 与 E1–E11/A1–A9，不凭直觉补职责；
2. 业务属性只写展示与判定所需的业务信息，不写数据库字段、索引、API 或界面布局；
3. 控制器的详情组装状态是单次分析状态，不是持久实体；
4. 实体间多重性只在基线有明确计数/保留规则时填写；
5. 未冻结的展示口径（多来源顺序、疑似版本、疑似参与等）不写成已批准规则。

## 2. WorkDetailUI（Boundary）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 承接“打开详情”与“打开来源外链”；显示单条成果详情、来源列表、未知标注、数据性质与更新时间、外链；显示不可访问、执行失败、外链失败三类状态，并区分处理中/加载状态 | M1/M2/M5–M8/M20–M23/M26–M28 |
| 候选分析操作（`/`） | `/接收详情请求`、`/显示成果详情`、`/显示不可访问`、`/显示执行失败`、`/显示外链失败`、`/提供原站外链` | M1–M28 |
| Know | 当前展示的详情投影与不可访问/执行失败/外链失败三类状态标记、处理中状态；不持久保存业务对象 | 分析推导 |
| 业务属性 | 无持久业务属性；详情投影与状态是短期展示状态 | §5.5.2；Boundary |
| 关系 | 单向关联 `WorkDetailCoordinator`（M2/M5/M7/M20） | [04](04-sequence-messages.md) 消息表 |
| 不能承担 | 不能判断公开生效/许可/版本证据/参与状态，不能合并或拆分来源，不能删除或隐藏成果 | FR02；BR-IMP-01；BR-UC02-07 |

## 3. WorkDetailCoordinator（Control）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 按稳定标识取一条成果；读类型适用字段、数据性质与时间、可公开来源、明示版本关系、参与角色与状态；统一执行公开/生效/许可过滤与待审值屏蔽；区分不可访问与执行失败；只输出原站外链 | M2–M5/M7/M9/M11/M13/M15/M17/M19/M20 |
| 候选分析操作（`/`） | `/校验访问前提`、`/读取一条成果`、`/读取类型适用字段`、`/读取时间语义`、`/读取可公开来源`、`/读取版本证据`、`/读取参与关系`、`/应用公开与许可过滤`、`/组装详情视图`、`/区分不可访问与执行失败` | M2–M20、M27 |
| Know | 本次详情请求：`workStableId`、各实体返回的片段、`hasPublicSource`、`versionEvidencePresent`、`participantStates`、`outcome`（成功/不可访问/执行失败） | FR02；SRS §7.1；A1/A3 |
| 业务属性 | 无长期业务属性。分析状态：`workStableId`、`detailFragments`、`outcome` | 分析推导 |
| 关系 | 与 `WorkDetailUI`、`WorkEntity`、`SourceRecord`、`WorkVersion`、`Authorship` 的单向关联 | M2–M20 |
| 不能承担 | 不承载成果/来源/版本/参与关系自身事实；不做检索、排序、分页；不写数据；不决定状态迁移 | §5.4.2；UC-01；UC-08/09/10 |
| 分析机制 | 见第 9 节（公开过滤、聚合、未知标注、时间分离、版本门槛、参与门槛、外链边界、只读） | FR02；FR16；BR-IMP-01/02/10 |

## 4. WorkEntity（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 回答当前公开生效状态与公共字段；按类型返回适用专属字段（缺失给未知标记）；返回数据性质、发生时间、采集与更新时间 | M3/M4/M9/M10/M11/M12 |
| 候选分析操作（`/`） | `/回答公开生效状态`、`/提供类型适用字段`、`/提供类型发生时间`、`/提供数据性质与更新时间` | M3/M4/M9–M12 |
| Know | 稳定 ID、类型、标题、公开生效状态、类型适用字段、发生时间集合、数据性质、更新时间 | FR02；SRS §7.1；FR16 |
| 业务属性 | `stableId`、`type`（论文/专利/项目/获奖）、`title`、`publicState`、`occurredTimes`（按类型：论文发表年份；专利申请日/公开日；项目起止；获奖年度）、`dataOrigin`（真实/模拟/混合）、`lastUpdatedAt`；类型适用字段：论文 `doi`/`publicationYear`/`venue`，专利 `applicationNo`/`applicationDate`/`publicationDate`，项目 `projectNo`/`startDate`/`endDate`/`leadOrganization`，获奖 `awardYear`/`awardName`/`awardTeam`；**任何专属字段缺失记为“未知”，不设默认值** | FR02；SRS §7.1；`AC-IMPL-FR16-01`；BR-IMP-07 |
| 字段归属说明 | §7.1 把“作者顺序”列在论文专属字段，把“发明人/负责人/获奖人员”列在各类专属字段：本分析把**人员的角色与顺序**归 `Authorship`（关系事实），把**机构/团队**（承担单位、获奖团队）留在 `WorkEntity` 类型字段（机构事实）。理由：角色/顺序是关系状态的一部分（§7.2、§6.4），而本 UC 没有独立的机构查询消息；机构是否独立成类交 R5（见 07） | SRS §7.1；§7.2；§6.4；分析推导 |
| 关系 | 被 `WorkDetailCoordinator` 读取（M3/M9/M11）；聚合 `SourceRecord`（1:0..*）、`WorkVersion`（1:0..*）、`Authorship`（1:0..*） | M3–M17；`AC-IMPL-FR02-01`；INV-02/05 |
| 不能混淆 | 不是 `SourceRecord`（来源证据）、不是 `WorkVersion`（版本证据）、不是 `Authorship`（参与关系）、不是详情页投影 | FR02/FR16；DD-08；SRS §7.2 |
| 分析机制 | 持久性；公开生效过滤；去重实体身份；类型适用字段；未知标注；时间语义分离 | FR02；FR16；SRS §7.1 |

## 5. SourceRecord（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 回答该成果下全部来源记录及其可公开性；保留原值；提供原站地址 | M13/M14 |
| 候选分析操作（`/`） | `/提供来源事实`、`/提供原站地址`、`/判断许可是否允许公开`（分析推导，供协调器过滤） | M13/M14；M19 |
| Know | 来源 ID、来源域、许可或使用范围、采集/导入时间、逻辑出处键、原始值、数据性质、原站地址 | FR16；SRS §7.1；INV-01 |
| 业务属性 | `sourceId`、`sourceDomain`、`rightsScope`（许可或使用范围）、`arrivalAt`（采集/导入时间）、`sourceRecordKey`（逻辑出处）、`rawValues`（原值，不被清洗改写）、`dataOrigin`（该来源的数据性质）、`originalUrl`（原站外链地址） | FR16；SRS §7.1；SPEC §3；INV-01 |
| 关系 | 由 `WorkEntity` 聚合（1:0..*）；被 `WorkDetailCoordinator` 读取（M13） | `AC-IMPL-FR02-01`；BR-IMP-02 |
| 不能混淆 | 不是成果实体（来源数不增加成果数）；不是版本（版本是同一成果的发布形态）；不是采集任务 | INV-02；DD-08/DD-11；UC-18/19 |
| 分析机制 | 逐条保留；许可过滤；重复到达不新增成果；停用/失效不删除历史 | FR16；BR-IMP-02/04；NF07 |

## 6. WorkVersion（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 回答该成果是否存在有明示证据的版本关系；无证据时回答“无版本关系” | M15/M16 |
| 候选分析操作（`/`） | `/提供明示版本关系`、`/判断版本证据是否成立` | M15/M16；DD-08 |
| Know | 版本种类、明示版本指向、关联来源、可公开性 | FR02；DD-08 |
| 业务属性 | `versionKind`（SRS 举出预印本/正式发表；完整枚举未冻结）、`versionEvidence`（明示版本指向）、`linkedSourceId`、`publicOk` | FR02；DD-08；Q-03 |
| 关系 | 属于 `WorkEntity`（1:0..*）；被 `WorkDetailCoordinator` 读取（M15） | FR02；DD-08 |
| 不能混淆 | 不是成果实体（版本数不增加成果数）；不是来源记录（出处 vs 发布形态）；无证据不得建立该关系 | `AC-IMPL-FR16-02`；DD-08/DD-11 |
| 分析机制 | 证据门槛；版本数不改变实体数；无证据保持独立不合并 | FR02；DD-08；`AC-IMPL-FR16-02` |

## 7. Authorship（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 回答该成果的作者/参与者角色、顺序与关系状态；标明哪些可作公开参与、哪些不得冒充已确认 | M17/M18 |
| 候选分析操作（`/`） | `/提供参与角色与顺序`、`/提供关系状态`、`/判断是否可作公开参与` | M17/M18；A9 |
| Know | 参与者公开身份显示、角色、顺序、关系状态、可公开证据标记 | FR02；FR15；SRS §6.4/§7.2/§11.3 |
| 业务属性 | `participantDisplay`（公开身份显示名或原署名）、`role`（论文作者/专利发明人/项目负责人/获奖人员等，按类型）、`order`（顺序，适用时）、`relationState`（自动关联/本人确认/待核验/争议/已排除）、`evidencePublic` | FR02；FR15；SRS §6.4；§11.3 |
| 关系 | 关联 `WorkEntity`（0..*:1）；被 `WorkDetailCoordinator` 读取（M17） | FR02；INV-05 |
| 不能混淆 | 不是成果属性（解除不删成果）；不是合作边（FR12/IN01 的派生边）；管理员审核不等于本人确认；不等于 Scholar 档案 | INV-05；SRS §6.4；§11.3；FR12；§12 |
| 分析机制 | 关系状态门槛；不扩散确认；保留历史证据；不因详情读取改变状态 | FR15；§6.4；BR-IMP-10 |

## 8. 关系定义汇总

| 关系 | 角色/方向 | 多重性 | 来源 | 状态 |
|---|---|---|---|---|
| WorkDetailUI → WorkDetailCoordinator | UI 请求/显示 | 不定义持久多重性 | M2/M5/M7/M20 | 已定义（单向关联） |
| WorkDetailCoordinator → WorkEntity | 读取成果 | 不定义持久多重性 | M3/M9/M11 | 已定义（单向关联） |
| WorkDetailCoordinator → SourceRecord | 读取来源 | 不定义持久多重性 | M13 | 已定义（单向关联） |
| WorkDetailCoordinator → WorkVersion | 读取版本证据 | 不定义持久多重性 | M15 | 已定义（单向关联） |
| WorkDetailCoordinator → Authorship | 读取参与关系 | 不定义持久多重性 | M17 | 已定义（单向关联） |
| WorkEntity — SourceRecord | 成果聚合来源证据 | 1 : 0..* | `AC-IMPL-FR02-01`；BR-IMP-02；INV-02 | 已定义 |
| WorkEntity — WorkVersion | 明示版本证据 | 1 : 0..* | FR02；DD-08 | 已定义（无证据不建立） |
| WorkEntity — Authorship | 参与关系 | 1 : 0..* | FR02/FR15；§7.2；INV-05 | 已定义 |
| WorkEntity — Scholar | **本 UC 不建立** | — | 参与经 Authorship 表达；直接连 Scholar 会绕过状态 | 留给 R5/UC-03 |
| SourceRecord — WorkVersion | **本 UC 不建立** | — | 版本与出处是不同事实；本 UC 无消息 | 留待 UC-09/16、R5 |
| WorkDetailCoordinator — SearchCoordinator/Claim/Auth | **不建立** | — | 检索/认领/授权不属本 UC | UC-01/05/06/07 |

**说明：** 交互关联不标持久多重性，因为它们是“一次读取调用”；实体间关系的多重性来自基线对“来源保留、版本证据、参与关系”的明确规定，不是凭空补齐。

## 9. 分析机制汇总

| 机制 | 作用对象 | 业务问题 | 本 UC 约束 | 未决定/后续 |
|---|---|---|---|---|
| 公开生效过滤 | Coordinator、WorkEntity、SourceRecord | 待审/无效/无许可不得公开 | 读取前判定 + 组装前再过滤（M19） | 字段级遮蔽粒度（BR-IMP-11）交 UC-17/NF06 |
| 去重实体优先 | WorkEntity、Coordinator | 多来源/多版本不得变成多条成果 | 一条成果 + 多条来源呈现（M13/M20） | 规模核对口径归 UC-16 |
| 缺失标未知 | WorkEntity、UI | 无字段不造值 | 未知标记；不设默认值 | 是否展示缺失原因 Q-08 |
| 时间语义分离 | WorkEntity、Coordinator | 采集时间不得冒充发生时间 | 三类时间分别传递（M11/M12） | — |
| 许可与数据性质标注 | SourceRecord、UI | 出处可追溯、真实/模拟不混淆 | 逐来源来源 ID/许可/时间/数据性质 | 成果级聚合口径 Q-07 |
| 版本证据门槛 | WorkVersion、Coordinator | 无证据不得显示版本关系 | 只在有明示证据时返回关联（M15/M16） | 是否提示疑似 Q-03 |
| 参与状态门槛 | Authorship、Coordinator | 未确认关系不得冒充已确认 | 自动关联/本人确认可展示；待核验/争议/已排除不得标为已确认 | 疑似参与展示形态 Q-05 |
| 不可访问/失败三分 | Coordinator、UI | 失败不得伪装成不存在或无结果 | M5/M6、M7/M8、M27 分离 | 对外细分粒度 Q-02 |
| 外链只跳原站 | UI、访客、原站 | 平台不托管全文 | 只交出地址（M23） | 是否探测可用性 Q-01 |
| 外链失败不删成果 | UI、Coordinator | 外链失效 ≠ 成果失效 | 不发出删除/隐藏（M28）；元数据仍可读 | 提示文案/重试 Q-01 |
| 只读 | 全体 | 详情不得改数据 | 无写消息 | 确认/纠错归 UC-08 |
| 容量与超时 | 读取路径 | 500 万/100 并发、5 秒超时 | 只引用 NF02，不在类图设计索引 | NOT RUN（Q-10） |
