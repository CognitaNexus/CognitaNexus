# UC-02 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-02 每个事件、分支和后置条件都有正式需求来源；区分已证实、分析推导和待确认，不编造需求。
**主证据：** SRS V2.2 FR02、FR16、§7.1、§7.2、§8、§9（NF01/NF02/NF04/NF07）、SRS §6.4；BR-IMP-01/02/04/07/10/11；SPEC V1.0 §3 公共契约、DD-08、DD-11。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS / AC / BR-IMP / 冻结 S01 / 已评审 SPEC 直接支持 |
| 分析推导 | 由已证实语义必然要求的协作或守卫，SRS 未逐句写出 |
| 待确认 | 具体参数、文案、展示口径未冻结（见 01 第 11 节） |

## 5. 不纳入本 UC 的事件

| 事件 | 原因 | 归属 |
|---|---|---|
| 关键词检索、组合筛选、稳定分页 | 独立目标，结果页行为 | UC-01 |
| 打开学者档案/个人主页 | 独立目标；详情内是否内联学者链接待 Q-05 边界确认 | UC-03 |
| 本人确认、补录、纠错成果 | 写操作，受权限与审核约束 | UC-08 |
| 清洗、去重、消歧、候选核验 | 治理阶段，不发生在详情读取时 | UC-09/UC-10 |
| 采集/导入与任务恢复 | 数据来源侧 | UC-18/UC-19 |
| 认领申请、审核、对象授权 | 与详情读取无关的授权域 | UC-05/UC-06/UC-07 |
| 管理员审计查询 | 受保护写入与留痕 | UC-17 |
| 规模核对（按去重实体计数、真实数单列） | 核对动作本身 | UC-16（本 UC 只呈现“一条实体多来源”） |
| 统计、排名、热点、合作网络、最短路径 | 派生视图，不是单条详情 | UC-11～UC-15 |
| 全文下载/托管、第三方订阅代理 | SRS §2.1 明确不建设 | 不做 |
| 相似论文推荐（O01）、行为偏好（O02） | Optional，本期延期，不成为 FR02 依赖 | 延期 |

## 6. 追踪结论

- E1–E11、A1–A10 均有正式来源或明确标注的分析推导；
- “一条成果多来源”“缺失标未知”“外链失败不删成果”“版本需证据”四条是本 UC 的核心可观察结论，分别来自 `AC-IMPL-FR02-01`、`AC-IMPL-FR02-02`、SRS §7.1、FR02 原文；
- 未新增、未修改任何 AC/BR；Q-01～Q-10 未冻结项只在 01 第 11 节登记。
