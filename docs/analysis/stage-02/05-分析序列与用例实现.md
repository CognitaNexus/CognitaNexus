## 2 Use-Case Realization 说明

### 2.1 UC-18 / UC-19 数据采集与更新

- **Boundary：** AdminConsole 接收任务参数、显示结果/失败；SourceAdapter只负责与获准来源交换记录。
- **Control：** CollectionCoordinator维护任务状态/检查点并协调；GovernanceCoordinator决定清洗、去重、身份/归属候选。
- **Entity：** SourceRecord保留原值与逻辑出处；WorkEntity为去重成果；Authorship为参与关系；Evidence保留异常/决定。
- **关键守卫：** 范围读取结束且每条已读记录均入库/异常移交/待核验处置，任务才成功；队列交接失败不算成功；重试不增实体/唯一出处。
- **AC：** FR08-01/02、FR09-01～06、FR10-01/02、NF04-01/02。

### 2.2 UC-05 / UC-06 Scholar认领

- **Boundary：** ClaimUI提交/查询/审核界面。
- **Control：** ClaimReviewCoordinator校验证据、权限、冲突并协调对象授权。
- **Entity：** ClaimApplication记录申请；Scholar为目标；ScholarAuthorization为批准后的对象权；UserProfile仅展示已批准关联；Evidence保留决定。
- **关键守卫：** 授权事务与申请通过一致；失败保持原状态；不建第二主页；不批量确认Authorship；不自动转移原权。
- **AC：** FR05-01～04、FR15-04～06、NF03-01。

### 2.3 UC-01 / UC-02 检索与详情

- **Boundary：** SearchUI提交条件、展示结果/失败/空态。
- **Control：** SearchCoordinator校验范围、冻结公开快照、过滤无权/待审、稳定排序与分页。
- **Entity：** WorkEntity、Scholar。
- **关键守卫：** 查询失败≠无结果；待审/无权/敏感项不进入结果；翻页使用同一上下文/快照。
- **AC：** FR01-01～03、FR02-01/02、NF01-01。

### 2.4 UC-04 / UC-22 注册与主页

- **Boundary：** AccountUI/ProfileUI。
- **Control：** RegistrationCoordinator创建User与唯一UserProfile；ProfileCoordinator校验本人所有权并区分普通资料/学术事实。
- **Entity：** User、UserProfile、Scholar、ReviewEvidence。
- **关键守卫：** 注册失败回滚；重试不产生第二主页；普通编辑无需Scholar认领；他人/停用拒绝；学术事实不直接写入。
- **AC：** FR03-03/04、FR04-03/04、FR06-03/04/05。

### 2.5 UC-14 / UC-15 合作网络与路径

- **Boundary：** AnalyticsUI展示图/路径/证据。
- **Control：** AnalyticsNetworkCoordinator按四类角色建FR12基础边；IN01只取论文子图，BFS边数、等长字典序。
- **Entity：** Authorship、WorkEntity、Scholar。
- **关键守卫：** 同机构/同领域不建边；待核验/争议/已排除不合格；共同专利/项目/获奖不能进入IN01；超规模不截断。
- **AC：** FR12-01～05、IN01-01～04。

## 3 职责—证据检查

| 检查 | 结果 |
|---|---|
| 每条消息是否有业务动作/查询/守卫依据 | 是；对应UC规约、SRS、AC |
| 是否出现实现类/HTTP/DB消息 | 否 |
| 是否把管理员审核当作本人确认 | 否；Claim协调器仅授予对象权，Authorship状态独立 |
| 是否把普通主页当作Scholar | 否；ProfileCoordinator只写普通字段，学术事实转授权流程 |
| 是否把四类基础边用于IN01 | 否；路径分支明确过滤论文证据 |
| 是否把采集成功等同全部公开 | 否；成功=范围读取结束+记录处置，另报待核验数量 |
| 是否对所有异常都画成功结束 | 否；失败/无结果/超规模独立结束 |

## 4 分析模型与设计边界

- 未选择Java框架、数据库、缓存、搜索产品、消息中间件、微服务数量或部署拓扑。
- 未把Entity属性当数据库字段；未给API/REST/表名。
- 序列图中的对象是分析职责，不保证一一对应未来类或服务。
- 后续架构/构件设计阶段可在不改变69 AC业务语义前提下调整实现结构，并保留追踪。
