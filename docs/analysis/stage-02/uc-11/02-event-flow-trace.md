# UC-11 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-11 的每个事件、后置条件与备选流都有正式来源；把“分析推导”与“待确认”单独标出。
**主证据：** SRS V2.2 FR11 正文与 `AC-IMPL-FR11-01/02`、FR16（`AC-IMPL-FR16-02` 边界）、FR15 边界、NF01/NF05/NF06、BR-IMP-01/02/06/07/10/11、§2.1、§6.1、§7.1/§7.2、§8、§11.4、§12；核心 SPEC §3（INV-01/02/04/06/10）、§4.3（SR-04/SR-06）、§6.1、§7.2、Q-SPEC-03/04/08；模块细化 `analytics-graph.md` FR11-S01～S12（细化，不反向覆盖基线）；既有 `DGM-ACTIVITY-02`/`DGM-ACTIVITY-04`/`DGM-STATE-03`/`DGM-USECASE-02`（只读比对）。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR/SPEC/冻结 S01 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作，但 SRS 未逐句写出 |
| 待确认 | 具体规则、参数、阈值、分类层级或度量口径未冻结，不能在本 UC 擅自决定 |

## 6. 追踪结论

- 主流程 E1–E14 均有正式来源；E8 中“只读参与关系作为机构归属证据来源”与 E14 的“只回显条件、不复制检索”属分析推导，均有上游要求支撑（BR-IMP-06/ID-05；FR11-S11）。
- A1–A12、A14–A17、A19 由 AC、SRS 正文、BR-IMP 或 SPEC 明文支持；A13 依赖模块细化（`FR11-S07 E1/E2`）而非 69 AC 正文，已标注为“细化＋分析推导”；A18 为范围边界（分析推导）。
- “默认现实视图只真实”“模拟/混合必须标识”“去重实体计数”“发生时机构＋未知不进名次”“六项披露”“不作质量结论”六项均有正式依据，不是本分析的业务创新。
- 阈值 T、展示上限、分类层级、更新时间语义、占比分母与一致性时限标 `待确认`（B-01～B-09），未写成已批准规则。
- 本表不改变 69 条 AC，不新增第 70 条 AC；模块细化的“统计结果对象＋生效状态”与本包“读时投影”取向的差异登记于 07 §5（C-01）。
