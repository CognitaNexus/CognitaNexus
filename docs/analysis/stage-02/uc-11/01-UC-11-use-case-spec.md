> **范围边界：** 本 UC 只处理“**读侧统计**”：按去重成果实体统计类型/年度/领域分布，以及在明确条件下按“成果发生时机构”做机构计数排名，并同屏披露数据范围、计数口径、更新时间与数据性质。
> 领域热点与关键词（FR13/UC-13）、基础合作网络（FR12/UC-14）、最短路径（IN01/UC-15）不在本 UC；机构排名的**独立视图**（统一 UC 编号 UC-12）与本 UC 共用同一口径与规则，视图层分工待父 Agent/评审确认（B-08）。成果实体去重与清洗（UC-09）、来源采集与增量（UC-18/19）、归属判定与修正（UC-08/10）、检索与详情（UC-01/02）、门户（UC-03）、管理待办与审计查询（UC-17）均不在本 UC。
> 本 UC **不写**任何业务实体：不改成果共享字段、不改参与关系状态、不改机构规范名与别名、不改来源原值；**不做**质量、影响力、机构优劣或个人综合学术排名的结论（BR-522；SRS §2.1）；**不做**统计实现（聚合引擎、缓存、报表、接口、DTO）。

> **对象区分（本 UC 的核心边界）：**
> - `WorkEntity` 是**去重后的成果规范实体**，是本 UC 的**计数单位**：一项成果无论有多少来源记录、多少版本证据、多少作者，都只计一次（BR-IMP-02/06；`AC-IMPL-FR16-02`）。它承载类型、时间语义、领域、真实/模拟/混合标识、公开生效状态与“成果发生时机构归属”事实。
> - `Authorship` 是“一位参与者 × 一项成果”的**参与关系**，携带角色、顺序与**多机构原值**（ID-05）。它是机构归属证据的来源之一，**不是**计数单位：统计不按作者数展开（A17）。
> - `Institution` 是**机构身份事实**（规范名、别名、合并链、未映射标记）。它回答“两个机构写法是否同一机构”，使机构排名不出现同一机构的重复行（FR11-S08 E2；CL-05）。它与“某位学者现在的任职单位”不是同一事实：本 UC **只**用有证据的成果发生时机构，不用学者当前单位（BR-513；SR-06）。
> - **成果发生时机构归属事实**是“成果 × 机构”的一个**有证据的取值**（来自成果/参与者署名机构原值＋发生时语义）。它在本包中作为 `WorkEntity` 的结构化属性与 `WorkEntity—Institution` 关联表达，不另外建独立实体（03 §4；05 §2.3）。
> - **统计视图结果是读时投影（analysis state）**：范围、条件、计数、声明与更新时间在一次请求内由已生效事实推导，**不是**持久“统计结果/统计快照/口径版本”业务实体（05 §4；07 §5 C-01）。

## 1. 参与者

| 类型 | 参与者 | 说明 |
|---|---|---|
| 主要参与者 | 访客 | 打开统计视图、调整条件、请求机构排名、从条目下钻复核；无需登录（FR11 参与者；NF01；BR-526） |
| 系统参与者 | 系统（范围过滤、去重计数、机构归属、排名、披露、状态区分） | FR11 规范性要求“按去重实体统计…”；由 `StatisticsCoordinator` 实现，不是人类参与者，也不画成边界类 |
| 次要参与者（外部前置，图中不画） | 口径与分类映射维护方（具备对应管理权限者） | 提供**已生效**的机构规范名/别名与领域分类映射；维护能力属 FR14/FR16，本 UC 只读消费（FR11-S08 E2；C-7） |
| 触发方（外部，图外） | 治理与解析管线（UC-09/UC-18/UC-19/UC-10 的产物；UC-01/02/03 的一致性对照） | 交付“已去重成果实体、生效参与关系、生效归属与机构映射”；本 UC 不采集、不去重、不改归属 |

> 不引入“统计口径审批角色”“数据质量裁决角色”：基线只区分“是否具备对应管理权限”（FR14；NF03），且统计为公开只读能力，没有对象级授权分支。

## 2. 目标

让访客在**公开、可复核**的前提下看到平台已收录数据的真实分布：计数单位统一为去重成果实体；默认现实视图只纳入真实、公开、生效、合格的成果；模拟与混合数据只在显式演示模式下展示并显著标识；机构排名只采用**有证据的成果发生时机构**，同一成果在同一机构只计一次、在不同机构各计一次，机构未知单列且不进入已知名次；同时同屏披露数据范围、时间范围、统计条件、计数口径、更新时间与数据性质，使任一条目都能按同条件在检索中复现。

## 3. 触发事件

1. 访客打开成果统计视图（默认现实视图）。
2. 访客在统计视图内调整条件（时间范围、成果类型、研究领域、数据性质）或请求机构排名。
3. 访客从某个统计条目下钻，要求按同一条件复核计数（条件回显；检索执行属 UC-01）。

## 4. 前置条件

1. 统计范围内存在至少一条已收录且满足统计条件的成果实体（真实、公开、生效、合格；FR11 规范性要求；BR-IMP-01/07）；成果实体已由 FR09/UC-09 去重（本 UC 不判定实体唯一性）。
2. 成果实体保留类型、时间语义、领域、真实/模拟/混合标识、公开生效状态与成果发生时机构归属事实（SRS §7.1；FR16；BR-IMP-06；ID-05）。
3. 机构规范名/别名与领域分类映射取自 FR14/FR16 的已生效维护结果；未完成映射时按“未映射/待分类”披露（FR11-S04；C-7）。分类层级与映射版本未冻结（Q-SPEC-03；B-02）。
4. 统计是公开只读能力，无需登录，也没有对象级授权分支（NF01；BR-526；SRS §8）。
5. 统计视图与检索、门户使用同一生效数据版本（NF05）；更新时间语义、传播时限与一致性测量方式未冻结（B-04；NF05 已明确 60 秒目标不在本轮已批准清单）。

## 5. 成功与失败后置条件

### 5.1 成功（分布统计）

1. 类型分布：四类（论文/专利/项目/获奖）计数之和等于同条件下去重成果实体总数；某类为 0 时展示 0 并标注“本期未收录该类成果”，不隐藏该类型（FR11-S02；模块细化）。
2. 年度分布：按各类型对应的发生时间字段归年；缺可用发生年份者只进入“时间未知”分组（FR11-S03；时间字段清单待确认 B-03）。
3. 领域分布：一成果关联多领域时在各领域各计一次，因此各领域计数之和**可以大于**实体总数，该现象必须在口径声明中说明（BR-IMP-06；FR11-S04）。
4. 同屏展示六项声明：数据范围、时间范围、统计条件、计数口径、更新时间、数据集范围（真实/模拟/混合）（FR11 规范性要求；BR-514）。
5. 计数单位是去重成果实体：跨源重复、已确认版本合并、重复作者都不增加计数；未确认的版本候选按现有实体分别计数并披露待确认数量（BR-IMP-02/06；FR11-S07）。
6. 无法纳入的实体（缺稳定标识、去重冲突未决）不计入，并在声明中给出“未纳入统计的实体数”（FR11-S07 E1/E2；分析推导）。

### 5.2 成功（机构排名）

1. 机构归属只取**有证据的成果发生时机构**；缺失或无证据者进入“机构未知”，未知计数单列且**不进入已知名次**（BR-IMP-06；BR-513；`AC-IMPL-FR11-01`）。
2. 同一成果在同一机构只计一次；同一成果涉及不同机构时各计一次；因此机构维度合计可以大于平台去重成果数量（BR-IMP-06；FR11-S08）。
3. 机构按规范名归并别名后计数，不出现同一机构的重复行（FR11-S08 E2；CL-05）。
4. 排名按计数降序，计数相同者名次相同、下一名次按并列数跳号；同时给出覆盖率与“样本不足”标注（阈值 T 待确认 B-05）（FR11-S05；FR11-S10）。
5. 口径说明与结果同屏，包含归属规则、并列规则与更新时间；不出现质量、影响力或机构优劣表述（BR-522）。

### 5.3 成功（条件与数据性质）

1. 条件变更后按新条件重算，并**同步刷新**口径声明，不保留与结果不符的旧声明（FR11-S06 A1；FR11-S01 A1）。
2. 默认现实视图只纳入真实数据；模拟与混合数据只在显式演示模式下展示，并在结果区与声明中固定标识“本结果基于模拟/混合数据，不得用于描述真实世界”（BR-IMP-07；`AC-IMPL-FR11-02`）。
3. 缺数据性质标识的成果**不**计入真实数据，归“未知”并在声明中给出数量（FR11-S12 E1）。
4. 下钻复核时回显与统计条目一致的条件，检索结果总数应与条目计数一致；差异须能按口径逐项复算（FR11-S11）。

### 5.4 失败（无业务写入）

1. 本 UC 无写操作，失败不改变任何成果、关系、机构或来源事实。
2. 条件非法、命中为空、执行失败、数据未更新、规模超限、无可用结果六类结果可区分且不互相冒充（NF01；BR-523/528）。
3. 非法条件被拒绝时保留原有结果与可编辑条件，不清空页面（FR11-S06 E1）。
4. 不展示部分结果并描述为完整结果；不以过期结果冒充最新；不编造更新时间（FR11-S09/S10；BR-523/528）。
5. 拒绝质量/影响力/机构优劣/个人综合学术排名请求，并说明本 UC 只提供计数统计（BR-522；SRS §2.1）。

## 6. 基本事件流

| 步骤 | 事件 | 需求/规则来源 |
|---:|---|---|
| E1 | 访客打开成果统计视图，默认进入**现实视图**（未显式选择数据集范围时只取真实数据）。 | FR11 规范性要求；BR-IMP-07；`AC-IMPL-FR11-02`；NF01 |
| E2 | 系统判定统计范围并**只读**读取符合条件的去重成果实体及其共享字段：类型、发生时间语义、领域、真实/模拟/混合标识、公开生效状态。 | FR11；BR-IMP-01/02/07；§7.1；FR11-S07 前置 |
| E3 | 系统按去重成果实体计数：类型分布、年度分布（含“时间未知”）、领域分布（多领域重复计入）；跨源重复与已确认版本只计一次，且不按参与关系/作者数展开。 | BR-IMP-02/06；`AC-IMPL-FR11-01`；FR16-02 边界；FR11-S02/S03/S04/S07 |
| E4 | 系统生成口径声明：数据范围、时间范围、统计条件、计数口径（去重/时间未知/多领域/版本合并/未纳入数）、更新时间、数据集范围。 | FR11 规范性要求；BR-514；FR11-S01 |
| E5 | 系统同屏展示分布结果、口径声明与数据性质标识（真实数据标识；若为演示模式则标注模拟/混合）。 | FR11；`AC-IMPL-FR11-02`；NF06 |
| E6 | 访客请求机构排名，并给出条件（成果类型、研究领域、时间范围，默认全部类型）。 | FR11 规范性要求“机构类别排名”；FR11-S05；FR11-S06 |
| E7 | 系统校验条件合法性（时间范围两端含、取值在允许集合内）；非法则拒绝并保留原有结果与条件。 | FR11-S06 E1/E3；NF01 |
| E8 | 系统读取每个成果的**成果发生时机构归属**事实与证据引用，并只读取参与关系的角色/顺序/多机构原值作为证据来源。 | BR-IMP-06；BR-513；SR-06；ID-05；§7.1 |
| E9 | 系统执行机构归属守卫：只采用有证据的发生时机构；**不**以学者当前任职单位推断；缺失或无证据→机构未知；按规范名/别名把同一机构归并为一个机构。 | BR-IMP-06；BR-513；SR-06；FR11-S08 E1/E2；CL-05 |
| E10 | 系统按机构计数：同一成果同一机构计一次、不同机构各计一次；机构未知单列；随后按计数降序排名并处理并列（同计数同名次、下一名次跳号），标出覆盖率与“样本不足”。 | BR-IMP-06；`AC-IMPL-FR11-01`；FR11-S05；FR11-S10（阈值待确认 B-05） |
| E11 | 系统同屏展示排名、机构未知分组与归属/并列口径，并明确不作质量或机构优劣结论。 | FR11 规范性要求；BR-514/522 |
| E12 | 访客调整条件（时间范围、成果类型、研究领域、数据性质），系统按同一组条件重算并同步刷新声明。 | FR11-S06 主流程/A1；FR11-S01 A1 |
| E13 | 系统执行数据性质守卫：默认只纳入真实数据；模拟与混合数据仅在显式演示模式下展示，并固定标识“不得用于描述真实世界”。 | BR-IMP-07；`AC-IMPL-FR11-02`；FR11-S12 |
| E14 | 访客从统计条目下钻，系统回显该条目对应的统计条件，由检索（UC-01）按同条件复核计数。 | FR11-S11；FR01 复用 |

> 本 UC 只定义**读侧可观察结果**与业务守卫，不指定聚合方式、缓存、任务调度、接口或数据结构；阈值类参数一律标 `待确认`（B-01～B-08）。

## 7. 备选/异常流

| 编号 | 条件 | 系统行为 | 依据 | 说明 |
|---|---|---|---|---|
| A1 | 时间范围非法（起始晚于结束）或条件取值不在允许集合 | 拒绝并提示“时间范围无效/条件无效”，保留原有结果与可编辑条件，不清空页面 | FR11-S06 E1/E3；NF01 | 非法条件不产生统计结果 |

| A3 | 统计读取/计算不可用 | 明确失败提示与可用范围，**不**展示部分结果、**不**展示过期结果冒充最新、**不**编造更新时间 | FR11-S09 E1/E3；BR-523；NF01 | 失败与空结果分开表达 |

| A5 | 成果缺真实/模拟/混合标识 | 不计入真实数据，归“未知”并在声明中给出数量 | FR11-S12 E1；BR-IMP-07 | 不得默认当作真实数据 |
| A6 | 模拟或混合数据 | 默认现实视图排除；仅在显式演示模式下展示，并在结果区与声明中固定标识“不得用于描述真实世界” | `AC-IMPL-FR11-02`；BR-IMP-07；NF06 | 真实/模拟/混合互斥标识 |
| A7 | 成果机构归属缺失 | 进入“机构未知”，单列展示，不进入已知名次 | BR-IMP-06；BR-513；FR11-S08 E3 | 未知不参与排名 |

## 11. 待确认

1. **B-01 统计“更新时间”的语义与来源**：FR11 只要求“显示更新时间”。模块细化区分“数据截止时间/生成时间/口径版本”。本分析用 `dataAsOf`（纳入数据的生效截止时间）与 `computedAt`（本次计算完成时间）两个分析态字段，标 `待确认`。

4. **B-04 一致性时限与测量方式**：NF05 明确 60 秒目标不在本轮已批准清单；本 UC 只要求最终一致、落后须标注。
5. **B-05 样本不足阈值 T 与覆盖率口径**：BR-520 只要求“低于约定阈值标注”，T 未冻结（Q-1）。
6. **B-06 “上一版可用结果”是否保留**：模块细化 FR11-S09 与 `DGM-STATE-03` 要求保留历史有效结果并展示；V2.2 未要求持久统计结果。本 UC 按“读时投影＋失败明确”建模，是否需要保留上一版投影待评审（C-01）。
