# UC-11 分析类职责、属性、关系与分析机制

**版本：** V1.0（2026-10-21）
**方法：** 教材 §5.5.1 职责、§5.5.2 属性、§5.5.3 关系、§5.5.4 分析机制。
**范围：** 只定义 UC-11 能够证实的部分；跨用例统一关系不在此擅自补齐。

## 1. 定义原则

1. “做（Do）”型职责说明对象能执行/协调什么；“知道（Know）”型职责说明对象必须知道/提供什么。
2. 属性只写业务信息，不写数据库字段、主键类型、索引、物化视图或 API 参数；聚合方式、缓存与算法不在此定义。
3. 关系只写有消息或正式业务约束支持的；无依据的跨用例关系留待 R5。
4. 控制类没有长期业务属性；范围、条件、计数、声明与更新时间是**单次请求的分析状态**。
5. 阈值、分类层级、上限、更新时间语义与占比分母等未冻结项不伪装成类定义，统一标 `待确认`（B-01～B-09）。

## 8. 分析机制汇总

| 机制 | 作用对象 | 业务问题 | 本 UC 可证实的约束 | 未决定/后续 |
|---|---|---|---|---|
| 去重实体计数 | Coordinator、WorkEntity | 来源数/版本数/作者数被当作成果数 | 一个去重实体只贡献一次；未确认版本按现有实体分别计并披露 | FR11-S07 的细化口径是否进 69 AC（B-08 类似） |
| 统计资格隔离 | Coordinator | 不可判定实体被静默纳入或静默丢弃 | 缺稳定标识/去重冲突未决者不计入，且披露未纳入数 | 披露字段与阈值（B-05） |
| 数据性质守卫 | Coordinator、WorkEntity | 模拟/混合数据冒充真实、缺标识被默认真实 | 默认仅真实；模拟/混合仅显式演示并固定标识；缺标识归“未知” | 演示模式入口的界面规范（本 UC 不设计） |
| 时间未知分组 | Coordinator、WorkEntity | 缺发生年份被塞进某年 | 只进入“时间未知”，不落入任何年度 | 各类型时间字段与精度（B-03） |
| 多领域重复计入 | Coordinator、WorkEntity | 各领域计数之和大于实体数被当作错误或人为去重 | 各领域各计一次，并把原因写入口径声明 | 分类层级与待分类（B-02）；占比分母（B-09） |
| 机构发生时归属 | Coordinator、WorkEntity、Authorship | 用学者当前单位冒充成果发生单位 | 只采用有证据的发生时机构；不用当前单位推断；缺失→未知 | 参与者级原值的取舍规则（§5 待确认项） |
| 机构名归并 | Coordinator、Institution | 同一机构多写法导致重复行 | 按已生效规范名/别名归并；本 UC 不改机构事实 | 维护责任与别名批准流程（FR14/FR16） |
| 机构维度合计 | Coordinator | 机构合计与实体总数不一致被当作缺陷 | 同机构一次、跨机构各一次；合计可大于实体数并须声明 | 跨机构是否按关系合格收窄（§5 待确认项） |
| 机构未知单列 | Coordinator | 未知被分摊进已知名次 | 未知单列、不进已知名次、不分摊 | 未知与待分类的展示次序（界面规范） |
| 排名与并列 | Coordinator | 计数相同被任意排序，或排序被解读为质量 | 计数降序；同计数同名次、下一名次跳号；禁止质量表述 | 覆盖率口径与样本阈值（B-05） |
| 空/失败/未更新区分 | Coordinator、UI | 空结果、失败、过期结果互相冒充 | 四类可区分；不展示部分结果；不编造更新时间 | 一致性时限与测量（B-04）；上一版结果是否保留（B-06） |
| 声明与结果一致 | Coordinator、UI | 声明块与结果不同步 | 六项同屏；条件变更后同步刷新声明 | 更新时间语义（B-01） |
| 可复核 | Coordinator、UI | 统计计数无法在检索复现 | 条目可下钻并回显同条件；无法解释的差异按缺陷处理 | 检索侧对齐属 UC-01 |
| 只读与不建持久结果 | 全体 | 统计顺手写数据或沉淀未经评审的结果对象 | 全图无写消息；投影不建实体 | C-01 待评审 |

## 9. 与其他 UC 的边界

- **UC-01/UC-02**：检索执行、稳定分页与详情展示不在本 UC；下钻只回显条件，计数须能与检索复现（FR11-S11）。
- **UC-03**：公开主页与学者档案展示不在本 UC；本 UC 不做学者维度统计。
- **UC-09**：成果去重、清洗与版本归并在本 UC 之外；本 UC 只消费去重结果与“版本候选是否已确认”的状态。
- **UC-08/UC-10**：归属判定与纠正不在本 UC；本 UC 只读取生效关系与生效归属，不展示待审关系（NF05）。
- **UC-12**：机构排名独立视图与本 UC 共用口径；视图分工与追踪归属待确认（B-08）。
- **UC-13**：领域热点与关键词窗口属 FR13，不使用本 UC 的分布计数口径。
- **UC-14/UC-15**：合作网络与最短路径属 FR12/IN01；本 UC 不建边、不计算路径。
- **UC-16**：规模核对（≥100 万/≥500 万去重实体、真实数单列）属 FR16；本 UC 只保证计数单位一致（`AC-IMPL-FR16-02` 边界）。
- **UC-17**：统计失败明细、待办与审计查询属 FR14；本 UC 只做页面提示。
