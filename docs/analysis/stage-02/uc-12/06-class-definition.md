# UC-12 分析类职责、属性、关系与分析机制

**版本：** V1.0（2026-10-21）
**方法：** 教材 §5.5.1 职责、§5.5.2 属性、§5.5.3 关系、§5.5.4 分析机制。
**范围：** 只定义 UC-12 能够证实的部分；跨用例统一关系不在此擅自补齐。

## 1. 定义原则

1. “做（Do）”型职责说明对象能执行/协调什么；“知道（Know）”型职责说明对象必须知道/提供什么。
2. 属性只写业务信息，不写数据库字段、主键类型、索引、物化视图或 API 参数；聚合方式、缓存与算法不在此定义。
3. 关系只写有消息或正式业务约束支持的；无依据的跨用例关系留待 R5。
4. 控制类没有长期业务属性；筛选条件、计数、名次、覆盖率与声明是**单次请求的分析状态**。
5. 阈值、类别体系、并列破局键、占比分母、展示上限与更新时间语义等未冻结项不伪装成类定义，统一标 `待确认`（B-01～B-12）。

## 8. 分析机制汇总

| 机制 | 作用对象 | 业务问题 | 本 UC 可证实的约束 | 未决定/后续 |
|---|---|---|---|---|
| 排名范围与数据性质 | Coordinator、WorkEntity | 未公开/未生效/模拟数据进入“现实排名” | 默认只纳入真实、公开、生效、合格实体；模拟/混合仅显式演示并标识；缺标识归“数据性质未知” | 演示模式入口的界面规范（本 UC 不设计） |
| 去重实体计数 | Coordinator、WorkEntity | 来源数/版本数/关系数被当作成果数 | 一个去重实体只贡献一次；未确认版本按现有实体分别计并披露 | FR11-S07 细化口径是否进 69 AC |
| 统计资格隔离 | Coordinator | 不可判定实体被静默纳入或静默丢弃 | 缺稳定标识/去重冲突未决者不计入，且披露未纳入数 | 披露字段（B-05 类似） |
| 机构发生时归属 | Coordinator、WorkEntity、Authorship | 用作者当前单位冒充成果发生单位 | 只采用有证据的发生时机构；不用当前单位推断；缺失→未知 | 参与者级原值的取舍规则与核验要求（B-09；Q-SPEC-08） |
| 机构名归并 | Coordinator、Institution | 同一机构多写法导致重复行 | 按已生效规范名/别名/合并链归并为一行；本 UC 不改机构事实 | 未映射机构是否进名次（B-01）、维护责任（FR14/FR16） |
| 机构维度合计 | Coordinator | 机构合计与实体总数不一致被当作缺陷 | 同机构一次、跨机构各一次；合计可大于实体数并须声明 | 跨机构口径 Q-4 与现行基线的关系（B-08/C-02） |
| 机构未知隔离 | Coordinator、UI | 未知被分摊进已知名次或参与并列 | 未知单列、不进已知名次、不分摊、不参与并列 | 未知分组展示次序（界面规范） |
| 名次与并列 | Coordinator、UI | 计数相同被任意排序，或排序被解读为机构优劣 | 计数降序；同计数同名次、下一名次按并列数跳号；禁止质量/名望破并列 | 并列规则是否入基线、破并列键（B-03） |
| 覆盖率与分母披露 | Coordinator、UI | 占比/覆盖率无口径、不可复核 | 只按已声明分母口径给出；未声明前不输出占比数值 | 分母定义（B-04）；样本阈值 T（B-05） |
| 空/失败/未更新区分 | Coordinator、UI | 空结果、失败、过期结果互相冒充 | 四类可区分；不展示部分结果；不编造更新时间 | 一致性时限（B-07）；上一版结果保留（B-12） |
| 声明与结果一致 | Coordinator、UI | 声明块与结果不同步 | 条件/时间范围/计数单位/归属/归并/未知/并列/分母/数据性质/更新时间同屏；条件变更后同步刷新 | 更新时间语义（B-07） |
| 可复核 | Coordinator、UI | 机构计数无法在检索复现 | 行可下钻并回显同条件＋机构规范标识；无法解释差异按缺陷处理 | 检索侧对齐属 UC-01 |
| 只读与不建持久结果 | 全体 | 排名顺手写数据或沉淀未经评审的结果对象 | 全图无写消息；投影不建实体 | C-01 待评审 |

## 9. 与其他 UC 的边界

- **UC-11**：类型/年度/领域分布统计不在本 UC；本 UC 只做机构维度与名次，两 UC 共用同一套口径守卫与实体（视图是否同页、边界/协调者是否合并待 B-10/R5）。
- **UC-01/UC-02**：检索执行、稳定分页与成果详情不在本 UC；下钻只回显条件与机构规范标识，计数须能与检索复现（FR11-S05 步骤 5）。
- **UC-03/UC-07/UC-10**：公开主页、学者任职期与身份归属判定不在本 UC；本 UC 明确不用作者当前任职推断成果发生时机构（BR-513；SR-06；T35）。
- **UC-09**：成果去重、清洗与版本归并在本 UC 之外；本 UC 只消费去重结果与“版本候选是否已确认”的状态。
- **UC-08/UC-10**：归属判定与纠正不在本 UC；本 UC 只读取生效关系与生效归属，不展示待审关系（NF05）。
- **UC-13**：领域热点与关键词窗口属 FR13，不使用本 UC 的机构计数口径。
- **UC-14/UC-15**：合作网络与最短路径属 FR12/IN01；本 UC 不建边、不算路径，也不把“同机构”当合作证据。
- **UC-16**：规模核对（≥100 万/≥500 万去重实体、真实数单列）属 FR16；本 UC 只保证机构维度的计数单位一致（`AC-IMPL-FR16-02` 边界）。
- **UC-17**：机构规范名/分类映射维护、排名失败明细与审计查询属 FR14；本 UC 只做页面提示与只读消费。
