> **范围边界：** 本 UC 只处理“**机构维度的公开读侧排名**”：在明确筛选条件与数据性质范围下，按去重成果实体统计各机构的成果数并给出名次，同时同屏披露筛选条件、计数单位、归属规则、归并规则、未知处理、并列规则、分母/覆盖率与更新时间。
> 类型/年度/领域**分布**统计（FR11 的分布部分，统一 UC 编号 UC-11）、领域热点与关键词（FR13/UC-13）、基础合作网络（FR12/UC-14）、最短路径（IN01/UC-15）不在本 UC；机构规范名/别名与分类映射的**维护**属 FR14/FR16（本 UC 只读已生效结果）；成果去重与清洗（UC-09）、归属判定与纠正（UC-08/UC-10）、检索与详情（UC-01/UC-02）、门户（UC-03）、管理待办与审计查询（UC-17）均不在本 UC。
> 本 UC **不写**任何业务实体：不改成果共享字段、不改参与关系状态、不改机构规范名与别名/合并链、不改来源原值；**不做**质量、影响力、机构优劣或学者个人综合学术排名结论（BR-522；SRS §2.1）；**不做**排名实现（聚合引擎、物化结果、缓存、报表、接口、DTO）。

> **对象区分（本 UC 的核心边界）：**
> - `WorkEntity` 是**去重后的成果规范实体**，是本 UC 的**计数单位**：一项成果无论多少来源记录、多少版本证据、多少参与关系，都只贡献一次计数（BR-IMP-02/06；`AC-IMPL-FR16-02`）。它承载成果类型、研究领域、发生时间语义、真实/模拟/混合标识、公开生效状态，以及“成果发生时机构归属事实”与证据引用。
> - `Institution` 是**机构身份事实**（规范名、别名、合并链、未映射标记）。它回答“两个机构写法是否同一机构”，使排名中同一机构只出现一行（FR11-S08 E2；CL-05）。它**不是**“某位作者现在的任职单位”：后者属学者档案的任职期事实（UC-07/UC-10），本 UC 明确不用它推断成果发生时机构（BR-513；SR-06；SPEC T35）。
> - `Authorship` 是“一位参与者 × 一项成果”的**参与关系**，携带角色、顺序、独立关系状态与**多机构署名原值**（ID-05）。在本 UC 中它只是**机构归属的证据来源之一**，**不是**计数单位：排名不按作者数或关系条数展开（A18）。
> - **排名视图投影**（`rankedRows`/`unknownInstitutionCount`/`coverage`/`scopeDisclosure` 等）是一次请求内由已生效事实推导的**分析态**，**不是**持久“排名结果/排名快照/口径版本”业务实体（05 §4；07 §5 C-01）。

## 1. 参与者

| 类型 | 参与者 | 说明 |
|---|---|---|
| 主要参与者 | 访客 | 打开机构排名视图、调整筛选条件、查看口径说明、下钻复核；无需登录（FR11 参与者；NF01；BR-526） |
| 系统参与者 | 系统（范围过滤、去重计数、机构归属、规范名归并、机构维度计数与名次、披露、状态区分） | FR11 规范性要求“按去重实体统计…机构类别排名”；由 `InstitutionRankingCoordinator` 实现，不是人类参与者，也不画成边界类 |
| 次要参与者（外部前置，图中不画） | 机构规范名/别名与分类映射维护方（具备对应管理权限者） | 提供**已生效**的机构规范名、别名、合并链与领域分类映射；维护能力属 FR14/FR16，本 UC 只读消费（FR11-S05 前置 2；FR11-S08 E2；C-7） |
| 触发方（外部，图外） | 治理与解析管线（UC-09/UC-18/UC-19/UC-10 的产物；UC-01/02/03 的一致性对照） | 交付“已去重成果实体、生效参与关系、生效归属与机构映射”；本 UC 不采集、不去重、不改归属 |

> 不引入“统计口径审批角色”“数据质量裁决角色”“机构评级角色”：基线只区分“是否具备对应管理权限”（FR14；NF03），机构排名为公开只读能力，除公开数据范围外没有对象级授权分支。

## 2. 目标

让访客在**公开、可复核**的前提下看到各机构的成果数量名次：计数单位统一为去重成果实体；机构归属只取有证据的成果发生时机构，缺失或无证据者进入“机构未知”且不进入已知名次；同一成果在同一规范机构只计一次、涉及不同机构各计一次；机构别名/历史名按已生效规范名归并为一行；默认现实视图只纳入真实、公开、生效、合格数据，模拟/混合只在显式演示模式展示并标识；同屏披露筛选条件、计数单位、归属与归并规则、未知处理、并列规则、分母/覆盖率、数据性质与更新时间，使任一行都能按同一条件在检索中复现。

## 3. 触发事件

1. 访客打开机构排名视图（默认现实视图，默认筛选条件）。
2. 访客在该视图内调整筛选条件（成果类型、研究领域、时间范围、数据性质，或机构条件）。
3. 访客请求解释某一行/整体排名的计数口径。
4. 访客从某个机构行下钻，要求按同一条件复核计数（检索执行属 UC-01）。

## 4. 前置条件

1. 排名范围内存在至少一条已收录且满足条件的成果实体（真实、公开、生效、合格；FR11；BR-IMP-01/07）；成果实体已由 FR09/UC-09 去重（本 UC 不判定实体唯一性）。
2. 成果实体保留成果类型、研究领域、发生时间语义、真实/模拟/混合标识、公开生效状态，以及“成果发生时机构归属事实”与证据引用（SRS §7.1；FR16；BR-IMP-06；ID-05）。
3. 机构规范名、别名与合并链取自 FR14/FR16 的已生效维护结果；未映射机构按“未映射”披露（FR11-S05 前置 2；FR11-S08 E2；C-7）。机构类别体系是否存在/可用未冻结（Q-SPEC-03；B-02）。
4. 机构排名是公开只读能力，无需登录，也没有对象级授权分支（NF01；BR-526；SRS §8）。
5. 机构排名视图与检索、门户、其他统计视图使用同一生效数据版本（NF05）；更新时间语义、传播时限与一致性测量方式未冻结（B-07；NF05 明确 60 秒目标不在本轮已批准清单）。

## 5. 成功与失败后置条件

### 5.1 成功（排名结果）

1. 每行代表一个**规范机构**：机构别名、历史名与合并链下的写法归并为同一行，同一机构不出现重复行（FR11-S08 E2；CL-05）。
2. 每行计数单位是去重成果实体：跨源重复、已确认版本合并、重复参与关系都不增加计数；未确认的版本候选按现有实体分别计数并披露待确认数量（BR-IMP-02/06；FR11-S07 细化）。
3. 同一成果在同一规范机构只贡献 1；同一成果涉及不同规范机构时各贡献 1；因此机构维度计数合计**可以大于**平台去重成果数量，该现象必须在口径声明中说明（BR-IMP-06；FR11-S08；BR-512 细化）。
4. 机构归属缺失或无证据的成果进入“机构未知”分组：单列展示、**不进入已知名次**、不分摊到其他机构（BR-IMP-06；FR11-S08 E1；`AC-IMPL-FR11-01` 语境）。
5. 名次按计数降序生成；计数相同者名次相同、下一名次按并列数跳号；并列内次序规则未冻结时不得按机构质量、影响力或历史名望破并列（FR11-S05 A1 细化；BR-522；B-03）。
6. 同屏展示声明：筛选条件、时间范围、计数单位、机构归属规则（发生时＋有证据）、别名归并规则、机构未知处理、并列规则、分母/覆盖率口径、数据性质、更新时间（FR11 规范性要求；BR-514；FR11-S01）。
7. 任一行可复核：下钻回显同一筛选条件与机构规范标识，由检索（UC-01）按同条件复现计数；无法解释的差异按缺陷处理（FR11-S05 步骤 5；FR11-S11）。

### 5.2 成功（数据性质）

1. 默认现实视图只纳入真实数据；模拟与混合数据只在显式演示模式下展示，并在结果区与声明中固定标识“本结果基于模拟/混合数据，不得用于描述真实世界”（BR-IMP-07；`AC-IMPL-FR11-02`）。
2. 缺真实/模拟/混合标识的成果**不**计入真实数据，归“数据性质未知”并在声明中给出数量（FR11-S12 E1 细化；BR-IMP-07）。
3. 条件变更后按新条件重算，并**同步刷新**声明，不保留与结果不符的旧声明（FR11-S06 A1；FR11-S01 A1）。

### 5.3 失败（无业务写入）

1. 本 UC 无写操作：失败不改变任何成果、参与关系、机构、分类映射或来源事实。
2. 条件非法、命中为空、执行失败、数据未更新、规模超限、类别维度不可用六类结果可区分且不互相冒充（NF01；BR-523/528）。
3. 非法条件被拒绝时保留原有结果与可编辑条件，不清空页面（FR11-S06 E1/E3）。
4. 不展示部分结果并描述为完整结果；不以过期结果冒充最新；不编造更新时间（FR11-S09；BR-523/528）。
5. 拒绝质量/影响力/机构优劣/个人综合学术排名请求，也拒绝以来源数、版本数、参与关系数或作者数作为“机构成果数”（BR-522；BR-IMP-02/06；A17/A18）。

|---:|---|---|
| E1 | 访客打开机构排名视图，默认进入**现实视图**（未显式选择数据集范围时只取真实数据），默认筛选条件为“全部成果类型、全部领域、无时间窗限制”（默认时间窗待确认 B-11）。 | FR11 规范性要求；BR-IMP-07；`AC-IMPL-FR11-02`；NF01；FR11-S05 触发；FR11-S06 |

| E3 | 系统执行统计资格与去重计数守卫：缺稳定标识或去重冲突未决的实体不计入并披露未纳入数；跨源重复与已确认版本只计一次；不按来源数、版本数、参与关系数或作者数计数。 | BR-IMP-02/06；`AC-IMPL-FR11-01`；`AC-IMPL-FR16-02` 边界；FR11-S07 |

| E11 | 系统同屏展示排名、机构未知分组、未映射披露、口径声明与数据性质标识，并固定说明“按计数排序，不表示机构质量、影响力或优劣”。 | FR11；`AC-IMPL-FR11-02`；BR-514/522；NF06 |
| E12 | 访客调整筛选条件（成果类型、研究领域、时间范围、数据性质），系统校验条件合法性并按同一组条件重算、同步刷新声明。 | FR11-S06 主流程/A1；FR11-S01 A1；FR11-S05 触发 |

| E14 | 访客请求解释某一机构行或整体排名的口径，或从机构行下钻复核；系统回显同一筛选条件、机构规范标识与归属/分母口径，检索执行交 UC-01。 | FR11-S05 步骤 4/5；FR11-S11；FR01 复用 |

## 11. 待确认

1. **B-01 机构别名/规范名合并与未映射处理**：FR11 只要求“机构优先采用成果发生时有证据的机构”，V2.2 未规定别名合并链的维护责任与“未映射机构”是否进入已知名次。模块细化 FR11-S08 E2 要求“按合并后规范名计数，不出现重复行”，CL-05 要求“仅通过已审别名字典映射，未知则未映射”。本分析按“归并为一行＋未映射保留原值并披露”建模；未映射机构是否参与名次、合并历史是否影响历史排名时段，留待确认。
2. **B-02 “机构类别排名”中“类别”的含义**：V2.2 FR11 写“机构类别排名”，未定义机构类别体系（机构类型标签、分类树）。本 UC 不构造类别维度，A13 按“不可用”处理；是否提供按类别分组/筛选待确认（Q-SPEC-03）。
3. **B-03 并列规则与破并列键**：V2.2 未写并列规则；模块细化 FR11-S05 A1 给出“同计数同名次、下一名次跳号（如 1、1、3）”，属细化、不反向覆盖基线；并列**内部**次序未定义，本分析明确禁止以质量/名望破并列。并列规则是否进入基线、破并列键取什么（建议稳定标识或规范名，未批准）待确认。
4. **B-04 占比分母与数据覆盖率口径**：模块细化 FR11-S05 要求展示“占比”与“数据覆盖率（有机构归属的成果占该条件下全部成果的比例）”，但“占比”的分母（范围内实体总数／已归属计数合计／已知机构计数合计）未定义。本 UC 只要求“按已声明口径披露”，不写具体公式。
5. **B-05 样本不足阈值 T**：BR-520 只要求“低于约定阈值标注”，T 未冻结（Q-1）；本 UC 只要求标注且仍展示实际计数。
6. **B-06 单次展示规模上限**：BR-528 要求声明上限，未给数值（Q-6）；本 UC 只要求“超限提示＋已声明子集”。
7. **B-07 更新时间的语义与一致性时限**：FR11 只要求“显示更新时间”；模块细化区分“数据截止时间/生成时间/口径版本”；NF05 明确 60 秒目标不在本轮已批准清单。本分析用 `dataAsOf` 与 `computedAt` 两个分析态字段，标 `待确认`。
8. **B-08 跨机构归属口径 Q-4 与现行基线的关系**：模块细化 FR11-S08 E3/`AC-FR11-S08-02` 要求“Q-4 未联合冻结前不得发布采用候选规则的正式排名、不得预定三个机构各计一次”；现行基线 BR-IMP-06 与 `AC-IMPL-FR11-01` 已规定“多机构各一次、单机构一次、未知单列”。本 UC 以 69 AC 基线为准（BR-UC12-06），差异登记 07 §5（C-02），交负责人确认 Q-4 是否已被取代。
9. **B-09 待核验作者关系是否参与机构归属**：Q-SPEC-08 把“重复实体计数、待核验作者关系参与机构排名与合作网络资格”列为待决；本 UC 按“实体统计资格与关系资格分离”建模（关系待核验不让成果退出实体排名），但“机构归属是否要求该参与关系已核验”未冻结。
10. **B-10 与 UC-11 的视图/入口分工与追踪归属**：V2.2 FR11 同时含分布统计与机构排名；统一 UC 清单中机构排名另有 UC-12。本分析为 UC-12 建立独立边界/协调者（与 UC-11 的 `StatisticsUI`/`StatisticsCoordinator` 是否合并待 R5）；视图是否同页、追踪行如何归属留父 Agent/评审确认。
11. **B-11 默认筛选条件（尤其默认时间窗）**：模块细化默认“全部成果类型”，时间窗默认值未定义；本 UC 只要求“默认为现实视图且声明当前条件”。
