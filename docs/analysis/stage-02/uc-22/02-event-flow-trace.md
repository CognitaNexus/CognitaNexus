# UC-22 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-22 的每个事件、后置条件和备选流都有正式需求来源；把“分析推导”和“待确认”单独标出。
**主证据：** SRS V2.2 §6 FR03/FR04/FR06/FR07、§7 BR-IMP-01/03/05/10/11、§8 权限与安全、§9 NF03/NF06、§12；69 AC 权威账本；核心 SPEC §3 INV-08/INV-10。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR/SPEC/冻结 S01 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作，但 SRS 未逐句写出 |
| 待确认 | 具体规则、参数、格式或字段清单未冻结，不能在本 UC 擅自决定 |

## 4. 后置条件来源

## 5. 不纳入本 UC 的事件

| 事件 | 原因 | 归属 |
|---|---|---|
| 注册与唯一主页生成、稳定地址分配 | 本 UC 的前置，不是本 UC 行为 | UC-04（DGM-SEQ-05/VOPC-01） |
| 公开主页/学者档案的读取与展示、零成果空态展示、同名分开展示 | 读侧属公开浏览用例；本 UC 只保证写侧投影 | UC-03（DGM-SEQ-08/VOPC-04） |
| Scholar 认领申请、证据、审核与对象授权 | 需要已有 Scholar 与审核流程 | UC-05/UC-06（DGM-SEQ-02） |
| 已授权 Scholar 档案维护、重要机构/身份变更的待审版本生效 | 需要 Scholar 对象授权，不在普通编辑范围 | UC-07（DGM-ACTIVITY-06 的学术分支） |
| 成果参与关系的确认、补录、纠错、解除 | 不是主页普通字段编辑 | UC-08 |
| 受控审计的查询与保留策略 | FR14 的审计查询属管理用例 | UC-17 |
| 登录/退出与会话建立 | 会话是前置条件，不在本 UC 建立 | 账号操作/UC-04 增量 |
| 账号停用的管理动作 | 本 UC 只把账号状态当守卫 | 管理用例/后续 UC |

## 6. 追踪结论

- 主流程 E1–E6 均有正式来源；A1/A2/A3/A5/A6/A7 由 AC 或 SRS 明文要求，A4 为分析推导并已标注。
- “普通编辑无需学术审核”“他人主页不可写”“私有字段不公开”“待审不覆盖公开版”“不建第二主页/不建 Scholar”“零成果空态”六项均有正式依据，不是本分析的业务创新。
- 未冻结项集中在字段级与策略级细节：公共资料策略（B-01）、字段清单与白名单（B-02）、混合提交处置（B-03）、展示设置范围（B-04）、审计保留（B-05）、会话对象（B-06）。
- 本表不改变 69 条 AC，不新增第 70 条 AC。
