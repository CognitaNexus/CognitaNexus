# UC-22 编辑本人普通个人主页

**版本：** V1.0（2026-10-21）
**对应需求：** FR06（FR06-01～05）；相关 FR03-01～04、FR04-02/04、FR07-03、NF03-01、NF06-01。
**需求基线：** [`CognitaNexus-Shared-SRS-V2.2-69AC.md`](../../../srs/CognitaNexus-Shared-SRS-V2.2-69AC.md)
**教材依据：** §5.4.1 完善用例文档；§5.4.2 识别分析类；§5.4.6 用例实现四步。

> **范围边界：** 本 UC 只处理“已登录的 UserProfile 所有者修改本人普通公开字段并保存”的行为。公开主页/学者档案的浏览与展示属 UC-03；注册与唯一主页生成属 UC-04；Scholar 认领与审核属 UC-05/UC-06；已授权 Scholar 档案（含重要机构/身份/来源事实）的维护与待审版本属 UC-07；成果参与关系的确认与纠错属 UC-08。本 UC 只在“拒绝并转交”意义上提到后两者，不展开其流程。
>
> **对象区分（本 UC 最重要的边界）：** `User` 是账号、会话主体与对象所有权来源；`UserProfile` 是注册自动生成的唯一公开普通主页，承载昵称/头像/简介/兴趣领域/展示设置等普通公开资料；`Scholar` 是平台采集/核验的学术身份档案，本 UC **不写** 其身份、机构、归属与来源事实。三者不可合并。

## 1. 参与者

| 类型 | 参与者 | 说明 |
|---|---|---|
| 主要参与者 | 注册用户（该 UserProfile 的所有者） | 已登录、账号可用，编辑请求对象为本人唯一 UserProfile |
| 次要参与者 | 无 | 学术审核属 UC-07/UC-08；公开读取与展示属 UC-03。访客读取只作为公开结果的验证视角（`AC-IMPL-FR06-05` 读侧），不在本 UC 建立交互 |

## 2. 目标

所有者在不认领 Scholar 档案、不经过学术审核的前提下，按公共资料策略修改并公开生效本人 UserProfile 的普通字段（昵称、头像、简介、兴趣领域、展示设置），同时保证：他人/同名其他对象不能写入、私有资料不公开、学术身份与机构等事实不被本 UC 改写、不产生第二个主页。

## 3. 触发事件

注册用户打开本人主页编辑入口，提交普通公开字段的修改并保存。

## 4. 前置条件

1. 请求者为已登录且账号状态可用的注册用户（FR04-02；`AC-IMPL-NF03-01`；SRS §8“服务端每次校验账号、角色和对象授权”）。
2. 该用户已有注册时自动创建的唯一 UserProfile（FR04；`AC-IMPL-FR04-03`）；本 UC 不创建主页。
3. 请求对象为**本人** UserProfile；他人的、同名的其他用户主页与 Scholar 档案不属于本 UC 可写对象（BR-IMP-05；`AC-IMPL-FR06-04`；`AC-IMPL-FR03-04`）。
4. 不要求已认领 Scholar 档案（FR06；`AC-IMPL-FR06-03`）。
5. 不要求用户已有已确认成果（`AC-IMPL-FR07-03`；`AC-IMPL-FR03-03`）。
6. 可编辑字段限于 FR06 列举的普通公开资料与展示设置；字段级清单与字段级公开规则尚未冻结（见 08 B-02/B-04），本分析不新增强制字段。

## 5. 成功与失败后置条件

### 5.1 成功

1. 目标 UserProfile 的普通公开字段与展示设置按公共资料策略生效；具体策略口径未冻结（08 B-01）。
2. 公开投影只包含明确允许公开的字段；私人联系方式、认证材料与凭据不进入公开响应（`AC-IMPL-FR06-05`；BR-IMP-11；INV-08）。
3. User 与 UserProfile 仍为 1:1，且仍只有一个 UserProfile；不新建主页、不改变稳定公开地址（FR04；`AC-IMPL-FR04-03`）。
4. 已核验学术身份、机构、归属与来源事实未被本 UC 写入；Scholar、ScholarAuthorization、Claim 无变化（FR06；FR05；BR-IMP-05）。
5. 未创建 WorkEntity 与 Authorship；零成果用户保存后主页仍正常显示“暂无公开成果”空态（`AC-IMPL-FR07-03`；`AC-IMPL-FR03-03`）。
6. 本次受保护写入留下可追溯审计：操作者身份、被写对象、理由/结果、前后值与时间（BR-IMP-10；INV-10）；审计内容不含秘密与凭据（NF03）。
7. 同名其他用户的普通资料与 Scholar 档案不受影响（`AC-IMPL-FR03-04`）。

### 5.2 失败

1. 目标 UserProfile 的公开字段保持原值（SPEC §8；NF01；`AC-IMPL-FR06-04`）。
2. 不产生第二个 UserProfile，不产生 Scholar/Claim/Authorship/WorkEntity，不删除既有公开档案（FR04；FR06；`AC-IMPL-FR04-02`）。
3. 越权或账号不可用的请求被服务端拒绝并保留受控审计（`AC-IMPL-FR06-04`；BR-IMP-10）。
4. 系统返回可区分的结果（无权限 / 账号不可用 / 字段不允许 / 保存失败）；具体错误码与文案未冻结，本 UC 不确定。

## 6. 基本事件流

| 步骤 | 事件 | 需求/规则来源 |
|---:|---|---|
| 1 | 注册用户打开本人主页编辑入口，提交普通公开字段（昵称/头像/简介/兴趣领域/展示设置）的修改。 | FR06；UC-22；E1；字段清单见 B-02 |
| 2 | 系统校验请求者身份、账号状态与编辑对象归属，确认是本人可用账号操作本人唯一 UserProfile。 | FR04-02；BR-IMP-05；`AC-IMPL-FR06-04`；E2 |
| 3 | 系统校验提交字段是否属于本人可编辑的普通公开字段，把重要学术身份/机构/归属/来源事实排除在本 UC 之外。 | FR06；`AC-IMPL-FR06-01/02`；E3；字段级规则见 B-02 |
| 4 | 系统保存该 UserProfile 的普通公开字段与展示设置。 | FR06；`AC-IMPL-FR06-03`；E4 |
| 5 | 系统按公共资料策略生成公开投影：只含明确允许公开的字段，并保持零成果空态不变。 | FR06；`AC-IMPL-FR06-05`；`AC-IMPL-FR07-03`；BR-IMP-11；E5；策略口径见 B-01 |
| 6 | 系统记录本次受保护写入的受控审计（身份/对象/理由/前后值/时间），并向所有者返回保存成功与公开生效结果。 | BR-IMP-10；`AC-IMPL-FR06-04`；INV-10；E6 |

> 步骤2–6是同一个“普通编辑已公开生效”结果的分析级组合：不出现“字段已改但公开投影仍含私有字段”“部分字段越权写入”“写入成功但无审计留痕”的中间态。此处只定义业务约束，不指定数据库事务、锁或消息实现。

## 7. 备选/异常流

| 编号 | 条件 | 系统行为 | 依据 | 说明 |
|---|---|---|---|---|
| A1 | 请求未认证，或账号已停用/已退出 | 服务端拒绝保存，无任何写入；不删除该用户已公开的普通主页与 Scholar 档案；记录受控拒绝审计；返回与“保存失败”可区分的拒绝原因。 | FR04-02；`AC-IMPL-FR04-04`；`AC-IMPL-NF03-01`；BR-IMP-10 | 会话/凭据对象是否建模待确认（B-06）；拒绝不得只靠隐藏入口 |
| A2 | 请求者不是该 UserProfile 的所有者：直接调用修改他人主页（含同名的另一位普通用户主页） | 服务端拒绝越权写入，被编辑主页无任何变化；保留受控审计；返回越权结果。 | `AC-IMPL-FR06-04`；BR-IMP-05；`AC-IMPL-FR03-04`；SRS §8 | 前端隐藏入口不能代替拒绝；同名不是所有权依据 |
| A3 | 提交内容包含重要已核验学术身份、机构、归属或来源事实 | 本 UC 不写入这些字段，也不改变任何核验状态；说明需按 Scholar 对象授权与学术审核办理，转 UC-07/UC-08；普通字段是否在同一请求中一并保存见 B-03。 | FR06“更改已核验学术身份、机构、归属、来源事实等仍需按 Scholar 对象授权和审核规则办理”；`AC-IMPL-FR06-01/02` | 本 UC 不是学术档案维护用例；不产生“待审版本覆盖公开版” |
| A4 | 保存失败（写入或公开投影生成失败） | 公开字段保持旧值；不返回成功；不产生半完成写入；可重试。 | FR06；`AC-IMPL-FR06-02`；分析推导 | 失败与“成功零变更”必须可区分；具体失败原因分类未冻结 |
| A5 | 公共资料策略要求审核后方可公开（是否存在该情形未冻结） | 公开版保持旧值；本次修改作为待审版本登记，待审版本不覆盖公开版；申请人可查待审状态。 | FR06“待审版本不覆盖公开版”；`AC-IMPL-FR06-01`；BR-IMP-10；B-01 | 若策略规定普通字段一律即时生效，则本分支不触发；不得由本分析擅自决定 |
| A6 | 用户没有任何已确认成果，或页面存在同名 Scholar | 保存后主页仍正常打开并显示“暂无公开成果”空态；不创建 WorkEntity/Authorship；不把普通主页标记为已认证学者、不合并同名对象。 | `AC-IMPL-FR07-03`；`AC-IMPL-FR03-03/04`；BR-IMP-03 | 零成果不是错误；同名不是合并依据 |
| A7 | 用户填写/曾填写非公开账号信息、认证材料或凭据 | 这些内容不进入公开投影；访客读取公开主页时只看到明确允许公开的字段。 | `AC-IMPL-FR06-05`；BR-IMP-11；`AC-IMPL-NF06-01`；INV-08 | 本 UC 保证写侧投影排除；读侧展示由 UC-03 验证 |

## 8. 业务规则

|---|---|---|

## 11. 待确认

4. **B-04 展示设置的范围**：是否包含字段级可见性开关、兴趣领域是否可隐藏等，未冻结。
