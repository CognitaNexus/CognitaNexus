## 1. 顺序图范围

本序列只实现 UC-22 的本人普通主页编辑：主流程 E1–E6，以及 A1（未认证/停用）、A2（非本人主页）、A3（含学术事实）、A4（保存失败）、A5（策略要求审核）分支。注册属 UC-04（`DGM-SEQ-05`）；公开读取与展示属 UC-03（`DGM-SEQ-08`）；认领审核属 UC-05/06（`DGM-SEQ-02`）；已授权 Scholar 档案维护与待审生效属 UC-07。它们只作为前置、后置或不变量出现，不进入本序列。

参与对象（共 5 个）：

- `ProfileUI`（Boundary）
- `ProfileCoordinator`（Control）
- `User`（Entity）
- `UserProfile`（Entity）
- `AuditEvidence`（Entity）

注册用户只在图外作为 Actor，不画成系统类。

## 3. 关键协作说明

### 3.1 所有权校验在服务端完成，且先于任何写入

M3/M4/M5 是写入前的强制守卫：

- M3 由 `User` 提供账号标识与账号状态，判定“请求者是否为可用账号”；
- M4 由 `UserProfile` 提供所属 User，判定“被编辑对象是否为该 User 的本人主页”；
- M5 是三者的合取；不满足即进入 M6–M8（A1）或 M9–M11（A2），**不进入 M15**。

因此“直接调用接口修改他人主页”在分析层就落到 A2，而不是靠 `ProfileUI` 隐藏入口（`AC-IMPL-FR06-04`；SRS §8）。同名的另一位普通用户主页不是所有权依据（`AC-IMPL-FR03-04`）。

### 3.2 普通字段与学术事实的分离

M12 在写入前判定字段范围：

- 命中重要已核验学术身份、机构、归属或来源事实 → M13/M14：本 UC **不写入**，也不改变任何核验状态，转 UC-07/UC-08 的对象授权与学术审核；
- 仅普通公开字段 → M15 保存。

本序列没有向 `Scholar` 发送消息，也不创建 `ScholarAuthorization`/`Claim`：拒绝与转交不需要写入学术对象。同一请求中普通字段是否仍保存由 B-03 待确认，本图不预设。

### 3.3 公开投影与私有字段最小化

M18 是“普通资料在允许公开后生效”的分析级表达：

- 公开投影只包含明确允许公开的字段（`AC-IMPL-FR06-05`）；
- 私有联系方式、认证材料与凭据不进入投影，也不得经检索/排序/分页泄漏（BR-IMP-11；INV-08）；
- 主页不因编辑生成成果实体，零成果空态保持不变（`AC-IMPL-FR07-03`；`AC-IMPL-FR03-03`）。

访客读取该投影的交互属 UC-03，本序列只保证写侧结果。

### 3.4 待审版本不覆盖公开版

M19 只在“公共资料策略要求审核后方可公开”时触发（`alt…else 即时生效` 中的审核分支，B-01 待确认）：

- 公开版保持旧值；
- 本次修改作为待审版本登记，申请者可查待审状态（`AC-IMPL-FR06-01`）；
- 待审内容不得提前出现在公开投影中（FR06；BR-IMP-10）。

若策略要求审核，先走M19登记待审，M18不执行；只有即时生效分支才生成M18公开投影，随后M20/M21/M22返回成功。本分析不预设哪一种口径。

### 3.5 保存失败

M16/M17 表示保存或公开投影生成失败：

- 公开字段保持旧值，可重试；
- 不返回成功视图，不显示为“已公开”；
- 不产生半完成写入，也不产生第二主页。

失败原因分类与重试提示形式属后续设计，未冻结。

### 3.6 审计留痕

M8/M11/M20 是 `AC-IMPL-FR06-04`“保留受控审计”与 BR-IMP-10 的直接落实：

- 成功写入记录身份/对象/理由/前后值/时间；
- 拒绝与越权尝试同样留痕（否则无法区分“拒绝”与“未发生请求”）；
- 审计内容不含凭据与秘密（NF03）；审计的查询权限与保留期限属 FR14/UC-17（B-05）。
