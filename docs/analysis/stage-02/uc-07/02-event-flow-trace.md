# UC-07 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-07 的每个事件、后置条件与备选流都有正式需求来源；把“分析推导”和“待确认”单独标出。
**主证据：** SRS V2.2 §4 FR05/FR06、§4 FR15、§6.4、§7 BR-IMP-01/03/04/05/10/11、§7.2、§8 权限与安全、§9 NF03/NF06/NF05、§11.3/§11.4、§12；69 AC 权威账本；核心 SPEC §3 INV-08/INV-10、§6.2 ID-01～ID-12。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR/SPEC/冻结 S01 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作，但 SRS 未逐句写出 |
| 待确认 | 具体规则、字段清单、范围粒度或参数未冻结，不能在本 UC 擅自决定 |

## 6. 追踪结论

- 主流程 E1–E10 均有正式来源；“需审核字段清单”“可直接生效字段清单”按待确认处理（B-01/B-02），未写成已批准规则。
- A1/A2/A3/A4/A10 由 AC 或 SRS 明文要求；A5/A6/A7/A8/A9 为分析推导或部分待确认，已逐项标注。
- “授权只对目标对象”“待审不覆盖公开版”“申请人对本人待审状态可读”“不建第二主页/不建认领/不转授权/不确认成果”“原始来源事实不被覆盖”六项均有正式依据，不是本分析的业务创新。
- 本表不改变 69 条 AC，不新增第 70 条 AC。
