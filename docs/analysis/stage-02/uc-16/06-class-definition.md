# UC-16 分析类职责、属性、关系与分析机制

**版本：** V1.0（2026-10-21）
**方法：** 教材 §5.5.1 职责、§5.5.2 属性、§5.5.3 关系、§5.5.4 分析机制。
**范围：** 只定义 UC-16 能证实的部分；跨用例职责与统一分析类留给 R5。
**上游一致性：** `WorkEntity`/`SourceRecord`/`WorkVersion` 的字段语义沿用 [`uc-02/06`](../uc-02/06-class-definition.md)、计数口径沿用 [`uc-09/06`](../uc-09/06-class-definition.md)，本 UC 不重新定义其治理侧行为。

## 1. 定义原则

1. Do/Know 来自 M1–M28 与 E1–E11/A1–A12，不凭直觉补职责；
2. 业务属性只写覆盖判定、计数与披露所需的业务信息，不写数据库字段、索引、API 或界面布局；
3. 控制器的范围声明与计数中间量是单次核对的分析状态，不是持久实体；
4. 实体间多重性只在基线有明确保留规则时填写；计数规则（来源数/版本数不进分子）写在控制类，不写进多重性；
5. 未冻结的口径（范围声明方式、模拟补齐、数据性质分组、待核验是否入分子）不写成已批准规则。

## 3. CoverageCheckCoordinator（Control）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 固定本次核对的数据范围、截止时间与待核验口径；判定样例可读性；逐类核对三项合取（类型可识别＋类型适用字段可得＋≥1 条合法来源）；以去重实体为计数单位核对规模并保证来源数/版本数不入分子；按数据性质互斥分组计数并单列真实数；披露待核验数量与不确定版本口径；区分缺项/差异/执行失败；只保留原站外链；不持久化核对结论 | M3–M28 |
| 候选分析操作（`/`） | `/固定核对范围与截止时间`、`/声明待核验口径`、`/读取四类可识别事实`、`/选取公开可读样例`、`/读取类型适用字段事实`、`/读取合法来源事实`、`/判定覆盖与缺项`、`/按去重实体计数`、`/核对明示版本关联`、`/按数据性质分组计数`、`/披露目标值实测状态`、`/定位计数差异`、`/组装核对投影`、`/区分执行失败与零覆盖` | M3–M28；A1–A12 |

| 业务属性 | 无长期业务属性。分析状态如上，全部只服务本次核对 | 分析推导；BR-UC16-09 |
| 关系 | 与 `CoverageCheckUI`、`WorkEntity`、`SourceRecord`、`WorkVersion` 的单向关联（后三条为**只读**依赖） | M3–M25 |
| 不能承担 | 不承载类型字段事实/许可事实/版本证据本身；不重新判定去重（UC-09）；不做检索、排序、分页、维度聚合（UC-01/UC-11）；不写数据、不留痕 | BR-UC16-14；FR09；§5.4.2 |
| 分析机制 | 见第 8 节 | FR16；BR-IMP-01/02/07 |

## 4. WorkEntity（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 回答去重成果实体的类型、公共字段、公开生效状态；按类型返回类型适用字段事实（缺失给“未知”标记）；作为**唯一计数单位**回答去重实体总量与按类型计数；返回成果级数据性质标识 | M5/M6、M9/M10、M14/M15、M19/M20 |
| 候选分析操作（`/`） | `/回答公开可识别事实`、`/提供类型适用字段事实`、`/回答去重实体身份与类型`、`/提供数据性质标识` | M5–M20 |
| Know | 稳定实体标识（去重后 canonical id）、类型、标题/名称、公开生效状态、类型适用字段事实、数据性质标识、更新时间 | FR16；§7.1；SPEC §3；`AC-IMPL-FR16-01/02` |
| 业务属性 | `stableId`（去重后实体标识）、`type`（论文/专利/项目/获奖）、`title`、`publicState`、`dataOrigin`（真实/模拟/混合；未确认则显式未知）、`lastUpdatedAt`、`typeFieldFacts[]`（见 §4.1） | §7.1；BR-IMP-07；SPEC §3 `data_origin` |
| 关系 | 被 `CoverageCheckCoordinator` 只读读取（M5/M9/M14/M19）；聚合 `SourceRecord`（1:0..*）、`WorkVersion`（1:0..*） | FR16；INV-02；DD-08 |
| 不能混淆 | 不是 `SourceRecord`（来源数不等于成果数）；不是 `WorkVersion`（版本不是计数单位）；不是核对结论（结论是读时投影）；不是 `CleanRecord`（规范工作记录，属 UC-09） | `AC-IMPL-FR16-02`；INV-02；BR-UC16-05/09 |
| 分析机制 | 持久性；去重实体身份；类型范围字段适用；缺失标未知；数据性质互斥标识 | FR16；§7.1；BR-IMP-07 |

### 4.1 类型适用字段事实（`typeFieldFacts[]`）的边界

| 项目 | 定义 | 依据 |
|---|---|---|
| 结构 | 每条事实：`fieldSemantic`（字段语义，如“DOI/发表年份/载体”）、`typeScope`（适用类型）、`value`（值或“未知”）、`timeSemantic`（若为时间：发表/申请/公开/授权/立项/结项/获奖）、`precision`（精度，如仅年份）、`evidenceRef`（字段来源的出处引用） | §7.1；SPEC §3 `time_events[]`/`provenance`；BR-IMP-04“时间含义分开” |
| 论文 | DOI、发表年份、载体、版本证据的**证据存在性**（不在此判定版本归并） | §7.1；FR02 |
| 专利 | 申请号、申请日、公开日（可按体系分列） | §7.1；SPEC §4.1 |
| 项目 | 项目编号、起止时间、承担单位（机构事实） | §7.1 |
| 获奖 | 获奖年度、奖项、获奖人员/团队（团队事实） | §7.1 |
| 缺失处理 | 缺失字段以“未知”作为取值呈现，不造默认值、不用他类型字段替代、不用采集时间替代发生时间 | §7.1；BR-UC16-04 |
| 不在此表达 | 人员角色/顺序与确认状态（`Authorship`，沿用 UC-02）；版本归并结论（`WorkVersion`）；字段级遮蔽策略（BR-IMP-11/UC-17） | §7.2；§6.4；BR-IMP-11；Q-07 |

> 该事实集合是 `WorkEntity` 的**类型范围属性**，不设独立类：没有独立身份、生命周期或对外行为（[03](03-bce-identification.md) §4、[05](05-vopc.md) §2.4）。

## 5. SourceRecord（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 逐条回答来源 ID、采集/导入时间、许可或使用范围、数据性质、原站地址；回答“是否可作为合法来源公开”；来源停用/失效后仍保留并可追溯 | M11/M12 |
| 候选分析操作（`/`） | `/提供来源级事实`、`/判断许可是否允许公开`、`/提供数据性质`、`/提供原站地址` | M11/M12；M22 |
| Know | 来源 ID、来源域、逻辑出处键、采集/导入（到达）时间、许可或使用范围、数据性质、原站地址、原值 | FR16；§7.1；INV-01；SPEC §3 |
| 业务属性 | `sourceId`、`sourceDomain`、`sourceRecordKey`、`arrivalAt`、`rightsScope`、`dataOrigin`、`originalUrl`、`rawValues` | FR16；INV-01；SPEC §3 `source_url`/`rights` |
| 关系 | 由 `WorkEntity` 聚合（1:0..*）；被 `CoverageCheckCoordinator` 只读读取（M11） | FR16；`AC-IMPL-FR16-02`；BR-IMP-02 |
| 不能混淆 | 不是成果实体（来源数不进入分子）；不是版本；不是采集任务；来源级数据性质不替代成果级互斥标识 | INV-02；DD-08；BR-IMP-07；Q-04 |
| 分析机制 | 逐条保留；许可过滤；停用/失效不删除历史；原值不改写 | FR16；BR-IMP-01/04；INV-01 |

## 6. WorkVersion（Entity）

| 项目 | 定义 | 依据 |
|---|---|---|
| Do | 回答该成果是否存在**有明示证据**的版本关系；无证据时回答“无版本关系”；不改变实体计数 | M16/M17 |
| 候选分析操作（`/`） | `/提供明示版本关联`、`/判断版本证据是否成立` | M16/M17；DD-08 |
| Know | 版本种类、明示版本指向/证据、关联来源引用、可公开性 | FR02；DD-08；`AC-IMPL-FR16-02` |
| 业务属性 | `versionKind`（SRS 举出预印本/正式发表；完整枚举未冻结）、`versionEvidence`、`linkedSourceId`、`publicOk` | FR02；DD-08；Q-03（UC-02） |
| 关系 | 属于 `WorkEntity`（1:0..*）；被 `CoverageCheckCoordinator` 只读读取（M16） | FR02；DD-08 |
| 不能混淆 | 不是成果实体（版本数不进入分子）；不是来源记录（发布形态 vs 出处）；无明示证据不得建立该关系 | `AC-IMPL-FR16-02`；DD-08 |
| 分析机制 | 证据门槛；版本不放大计数；无证据保持独立并披露不确定口径 | FR02；DD-08；A6 |

## 7. 关系定义汇总

| 关系 | 角色/方向 | 多重性 | 来源 | 状态 |
|---|---|---|---|---|
| `CoverageCheckUI → CoverageCheckCoordinator` | UI 请求/显示 | 不定义持久多重性 | M3/M7/M23/M25 | 已定义（单向关联） |
| `CoverageCheckCoordinator ..> WorkEntity` | 只读读取 | 不定义持久多重性 | M5/M9/M14/M19 | 已定义（只读依赖） |
| `CoverageCheckCoordinator ..> SourceRecord` | 只读读取 | 不定义持久多重性 | M11 | 已定义（只读依赖） |
| `CoverageCheckCoordinator ..> WorkVersion` | 只读读取 | 不定义持久多重性 | M16 | 已定义（只读依赖） |
| `WorkEntity — SourceRecord` | 成果聚合来源证据 | `1 : 0..*` | FR16；`AC-IMPL-FR16-02`；BR-IMP-02；INV-02 | 已定义 |
| `WorkEntity — WorkVersion` | 明示版本证据 | `1 : 0..*` | FR02；DD-08；`AC-IMPL-FR16-02` | 已定义（无证据不建立） |
| `WorkEntity — Authorship` | **本 UC 不建立** | — | 覆盖判定与计数不使用参与关系 | 沿用 UC-02（1:0..*）；本 UC 无消息 |
| `SourceRecord — WorkVersion` | **本 UC 不建立** | — | 无消息；版本与出处不同层事实 | 留待 UC-09/18 与 R5 |
| `WorkEntity — Scholar` / `— Institution` | **本 UC 不建立** | — | 身份与机构维度不属 FR16 覆盖判定 | UC-03/UC-10/UC-11、R5 |
| `CoverageCheckCoordinator — Statistics/Search/Detail 协调器` | **不建立** | — | 覆盖核对与检索/统计/详情职责分离 | UC-01/UC-02/UC-11、R5 |

**说明：** 交互关联不标持久多重性，因为它们是“一次核对的读取调用”；实体间多重性来自基线对“来源保留、版本证据”的明确规定，不是凭空补齐。

## 8. 分析机制汇总

| 机制 | 作用对象 | 业务问题 | 本 UC 约束 | 未决定/后续 |
|---|---|---|---|---|
| 范围与口径声明 | Coordinator、UI | 无范围/截止时间的“达标”不可复核 | 先声明再核对（M4）；未声明不给通过结论（A10） | 声明方式/默认值 Q-01 |
| 覆盖三项合取 | Coordinator、WorkEntity、SourceRecord | 四类是否可识别且来源合法 | 类型可识别＋字段可得＋≥1 合法来源（M13） | 模拟补齐口径 Q-03 |
| 类型范围字段适用 | WorkEntity | 字段不可跨类型套用、缺失不造值 | `typeFieldFacts[]` 带 `typeScope` 与“未知”取值（M10） | 是否展示缺失原因（与 UC-02 Q-08 同源） |
| 去重实体计数 | Coordinator、WorkEntity | 来源数/版本数不得放大规模 | 分子 = `distinct(生效 canonical_id)`（M14/M15/M18） | 可检索口径 Q-11 |
| 版本证据门槛 | WorkVersion、Coordinator | 无明示证据不得并入 | 只在有明示证据时归入同一实体（M16/M17） | 不确定版本披露粒度 Q-05/Q-06 |
| 数据性质互斥分组 | WorkEntity、Coordinator、UI | 模拟/混合不得冒充真实 | 真实数单列；模拟/混合显式标注；未确认单列（M19–M21） | 第四分组口径 Q-04 |
| 目标值 vs 实测 | Coordinator、UI | 目标不等于已达标 | 1,000,000/5,000,000 标 NOT RUN（M22/M25/M26） | 验收数据范围 Q-01/Q-08 |
| 缺项与差异定位 | Coordinator、UI | 不通过必须可定位 | 缺项原因＋差异项，不宣布通过（M23/M24） | 差异维度 Q-06 |
| 执行失败三分 | Coordinator、UI | 失败不得伪装零覆盖 | M7/M8 与 M23/M24 分离 | 对外文案粒度（与 UC-02 Q-02 同源） |
| 待核验披露 | Coordinator | 治理未完成不得计入通过 | 待核验不入分子，数量单列（A11） | 是否入分母 Q-05 |
| 外链只跳原站 | UI、Coordinator | 平台不托管全文 | 只保留原站地址（M22/M27） | — |
| 只读与不持久化 | Coordinator、全体 | 核对不得改数据、不得把结论当事实 | 无写消息；投影不落库（M28） | 是否留痕 Q-09 |
| 容量与并发 | 读取路径 | 500 万/100 并发/5 秒 | 只引用 NF02，不在类图设计索引 | NOT RUN（Q-01/Q-11） |
