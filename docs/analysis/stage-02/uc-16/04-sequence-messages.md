## 1. 顺序图范围

本序列只实现 UC-16“核对四类覆盖与来源”：

- 固定本次核对的数据范围与截止时间，并声明待核验口径与“读时投影、不回写”；
- 读四类公开可识别事实，逐类取一条公开可读样例与类型适用字段（缺失标“未知”）；
- 读样例的许可来源与来源级事实（来源 ID、采集/导入时间、许可或使用范围、数据性质）；
- 逐类判定“类型可识别＋类型适用字段＋≥1 条合法来源”，输出覆盖/缺项；
- 以**去重成果实体**为单位核对规模；跨两来源且有明示版本关联仍计 1；
- 按数据性质互斥分组计数，真实数单列，模拟/混合显式标注，未确认单列；
- 只给原站外链，不取全文；
- 覆盖/计数一致时披露结果投影，缺项/不一致时披露缺项与可定位差异，读取失败时披露执行失败（与零覆盖区分）；
- 目标值 1,000,000/5,000,000 标 NOT RUN；全程无写消息。

检索与分页（UC-01）、详情展示（UC-02）、治理核验（UC-09/10）、采集与增量（UC-18/19）、统计与网络（UC-11～15）、审计查询（UC-17）不进入本序列。

## 3. 关键协作说明

### 3.1 覆盖判定的三项合取（核心之一）

- M5/M6 提供“类型可识别 + 公开生效”事实；M9/M10 提供“类型适用字段可得（缺失标未知）”；M11/M12 提供“至少一条合法来源”。
- M13 把三者在同一类内合成逐类结论：任一项不成立即该项覆盖不通过并记缺项（A1–A4）。三者不能互相替代：有字段无许可来源、有来源字段全缺、类型不属四类，都是不同的不通过原因。
- 该判定顺序不受展示顺序约束：实现阶段可按类型分页/分批核对，但结论集合必须可复核（`AC-IMPL-FR16-01`）。

### 3.2 计数单位：去重成果实体（核心之二）

- M14/M15 只以去重实体身份计数；M18 显式保证“来源数/版本数不进入分子”。
- 需要两个事实同时存在才能证明 `AC-IMPL-FR16-02`：①M16/M17 证明版本证据存在；②M18 证明该证据不放大计数。仅有版本实体而没有计数守卫，就无法区分“按版本数计”与“按实体数计”。
- 计数口径本身由 UC-09 建立（`distinct(生效 WorkEntity canonical_id)`），本 UC 只读取与核对（BR-UC16-14）。

### 3.3 数据性质分组与真实数单列

- M19/M20 取成果级互斥标识（真实/模拟/混合）；未确认时显式标未知，不默认真实（A7）。
- M21 要求“真实数单列”：真实组的数值必须能与模拟/混合/未确认组分别复核，不能只给一个总数（`AC-IMPL-FR16-02`；BR-IMP-07；INV-09；SRS §2.1“不用模拟容量数据冒充已采集的真实成果”）。

### 3.4 缺项、差异与失败的三类区分

- M23/M24：缺项（某类无样例/类型不属四类/来源不合法）与计数不一致（实体/来源/分组对不上）都只输出“不通过 + 可定位差异”，不得显示“已达标”（A8；BR-UC16-10）。
- M7/M8：读取依赖失败或超时是**执行失败**，与“零覆盖/无样例”不同（A9；NF01）。
- M25/M26 与 M23/M24 互斥：一次核对不会同时给出“一致”和“不一致”结论。

### 3.5 范围与口径声明

- M4 是本次核对的前置守卫：固定数据范围与截止时间，声明待核验口径，并声明结果不持久化。
- 未声明范围时按 A10 处理：不给通过结论（具体声明方式与默认值未冻结，Q-01）。
- 声明的口径必须在 M25 的投影中回显，使结论“可复核”而非“一个数字”（FR16-S03 主成功流程 1–3）。

### 3.6 目标值 NOT RUN

- M22 把 1,000,000（功能联调）与 5,000,000（最终容量）作为**目标值**携带，不参与“是否通过”的本地判定。
- M25/M26 必须把实测状态显示为“未运行”。本序列不包含压测、并发与分位数记录消息（NF02 的测量活动不属本 UC）。

### 3.7 原站外链与只读边界

- M22/M27：只保留并交出原站地址；平台不取、不缓存、不代理全文（FR02；SRS §2.1）。
- M28：全程无创建/修改/删除消息；核对结论不落成核对报告实体（BR-UC16-09）。措施：不合并实体、不改公开状态、不建版本关系、不删来源（BR-UC16-14）。

## 4. 消息完整性检查

| 检查 | 结果 |
|---|---|
| 每条消息有发送者/接收者 | 是，M1–M28 |
