# UC-03 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-03 的每个事件、后置条件和备选流都有正式需求来源；把“分析推导”和“待确认”单独标出。
**主证据：** SRS V2.2 FR03/FR04-04/FR15/NF01/NF06、BR-IMP-01/03/05/11、§7.2、§12；核心 SPEC V1.0 ID-01/ID-06、SR-12；UC-03 追踪行。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS 原文/AC/BR 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的读取/过滤协作，但 SRS 未逐句写出 |
| 待确认 | 具体字段、文案、展示口径或边界未冻结，不能在本 UC 擅自决定 |

## 5. 不纳入本 UC 的事件

| 事件 | 原因 | 归属 |
|---|---|---|
| 关键词/筛选检索与分页 | 检索是独立用例，本 UC 从结果链接进入 | UC-01 |
| 打开一条成果详情、来源列表、外链 | 详情与来源读取不在本 UC | UC-02 |
| 编辑昵称/头像/简介/兴趣领域 | 需要所有权与会话，属受保护写 | UC-22 |
| 设置/撤销“允许展示”的字段可见性 | 授权动作属本人编辑 | UC-22（FR06） |
| 提交认领、补证、审核、争议处理 | 认领生命周期不在本 UC；本 UC 只读取认领/核验状态标签 | UC-05/06 |
| Scholar 档案维护（机构、别名、成果归属写入） | 需要对象级授权 | UC-07 |
| 成果确认、补录、纠错 | 写操作，且需 Authorship 状态变更 | UC-08 |
| 身份核验、同人/异人判定与合并 | 本 UC 禁止自动合并，只读取结果状态 | UC-10/15 |
| 统计、合作网络、最短路径 | 派生视图，不是主页/档案读取 | UC-11～15 |
| 账号停用后的主页可读性 | SRS 未规定停用对 UserProfile 公开性的影响（Q-09） | FR04/账号管理后续确认 |

## 6. 追踪结论

- E1–E10 均有正式来源或明确的分析推导；A1–A8 都是“公开读取 + 公开最小化 + 关系状态不得冒充”的必然分支，不是新增业务能力；
- 本 UC 只读，不产生任何写消息，不改变 `Authorship` 关系状态，也不建立 `UserProfile—Scholar` 关联；
- 未冻结项集中在“公开字段集合、空态文案范围、UserProfile 成果区来源、待核验展示口径、不可访问粒度、状态标签口径”（01 §11 Q-01～Q-09），不写成已批准规则；
- 本表不改变 69 条 AC，不新增第 70 条 AC；UC-03 追踪行（`AC-IMPL-FR03-01～04`、`NF01-01`、`NF06-01`）与反向行仍由父 Agent 维护 `SEQ-08/VOPC-04` 引用。
