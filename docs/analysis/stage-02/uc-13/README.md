## 3. 阅读顺序

先读 01 确认业务边界（为什么计数源只有论文关键词与已登记主题、为什么同义词必须有凭证才合并、为什么按计数降序+规范词升序破并列、为什么稀疏数据只能显示“无数据/样本有限”、为什么不做趋势预测与质量评价），再读 02 核对每个事件的证据等级；03 给出 4 个参与类与拒绝候选（含“热点结果是投影不是实体”“不建语义主题模型类”）；04 只描述交互，05 只从 04 提取 VOPC；06 定义职责/属性/关系/机制；07 做全局比较并提出 R5 建议与冲突；08 列出实际执行结果与未决项。

## 4. 本轮的五个核心结论

1. **计数源只有两种，且都必须是公开真实数据**：论文关键词事实（`WorkEntity`，只取论文）与已登记主题（`TopicTerm`）；专利/项目/获奖不提供关键词字段，标题/摘要不用于推断主题（FR13；SPEC §4.1；M5–M9）。
2. **同义合并只有凭证才做，没有凭证就不合并**：只有已生效、可查询的同义词映射才能把不同写法计为一个规范词；无凭证或存疑时保留为不同条目并标注“可能为同一概念的候选”，**不构造词典、不做语义相似度或主题模型**（FR13 明文；CL-05；M8–M10）。
3. **计数单位是“论文 × 规范词”，排序是计数降序 + 规范词升序**：同一论文同一规范词只计一次；来源数、版本数、作者数与关键词列表内重复都不放大计数；计数相同时按规范词升序破并列（FR13 明文；“出现 3 次”的精确含义未冻结，见 B-11）（M11/M12）。
4. **披露必须与结果同屏，稀疏数据不得编造结论**：字段来源、年份窗、数据类别、范围与映射覆盖、样本量（计入/未计入）、映射凭证来源、并列规则、更新时间同屏；稀疏或无关键词时显示“无数据/样本有限”并给出实际数量，不补占位、不插值、不对外推（`AC-IMPL-FR13-01/02`；NF01；M13–M17/M29–M34）。
5. **热点是读时投影，不是持久结果，也不是趋势/质量评价**：全图无写消息，不建持久“热点结果/热点快照/口径版本”对象；不做趋势预测、语义主题模型、质量评价或按学者个人热点排名（FR13 明文；SRS §2.1）（M37/M38；05 §4）。
