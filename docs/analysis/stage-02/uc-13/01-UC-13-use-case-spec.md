> **范围边界：** 本 UC 只处理“**领域热点的公开读侧计数**”：在**明确领域、明确年份窗、明确数据类别**下，对**论文关键词或已登记主题**做出现次数计数排序，并同屏披露字段来源、范围、样本量与更新时间。
> 类型/年度/领域**分布**统计（UC-11）、机构排名（UC-12）、基础合作网络（FR12/UC-14）、最短路径（IN01/UC-15）不在本 UC；主题登记、术语映射与领域分类映射的**维护**属 FR14/FR16（本 UC 只读已生效结果）；成果去重与清洗（UC-09）、采集与增量（UC-18/19）、归属判定与纠正（UC-08/UC-10）、检索与详情（UC-01/02）、门户（UC-03）、管理待办与审计（UC-17）均不在本 UC。
> 本 UC **不写**任何业务实体：不改成果字段、不改关键词原值、不改主题登记与映射、不改领域分类；**不做**语义主题模型、趋势预测、质量/影响力评价，也**不做**按学者个人的热点排名（FR13 明文；SRS §2.1）；**不做**热点实现（索引、聚合引擎、缓存、任务、报表、接口、DTO）。

> **对象区分（本 UC 的核心边界）：**
> - `WorkEntity` 是**去重后的成果规范实体**，在本 UC 提供两类事实：①公开生效状态、数据类别（真实/模拟/混合）、时间语义与领域取值（用于范围与年份窗筛选）；②**论文关键词事实**（`keywordFacts[]`，来自来源侧论文关键词字段，保留原写法与证据引用）。它**不是**“主题”：关键词是论文自带的字段值，主题是已登记的规范词（FR13；SPEC §4.1）。
> - `TopicTerm` 是**已登记主题的规范词与有凭证的写法映射**（规范词、原始写法、同义词映射凭证来源、映射状态）。它回答“哪些写法在有凭证的前提下算同一个规范词”，**不是**词典、词向量、语义主题模型或关键词库：没有凭证就不合并（FR13 明文；CL-05；M8–M10）。
> - **领域取值**在本 UC 只作为**筛选条件与披露项**，写成 `WorkEntity.fieldRefs[]`（可含“待分类”），**不建** `Field`/`FieldTaxonomy` 类：领域层级与映射未冻结（Q-SPEC-03；B-09）。领域映射的维护属 FR14/FR16。
> - **热点结果投影**（`hotspotRows`/`sampleSize`/`excludedCounts`/`scopeDisclosure` 等）是一次请求内由已生效事实推导的**分析态**，**不是**持久“热点结果/热点快照/口径版本”业务实体（05 §4；07 §5 C-01）。

## 2. 目标

让访客在**公开、可复核**的前提下看到平台已收录论文数据中的关键词/主题出现次数排序：计数源只有“公开真实论文的关键词事实”与“已登记主题”，且必须在明确的领域、年份窗与数据类别下计算；同一论文同一规范词只计一次；同义词只在**有凭证**的映射下合并，无凭证或存疑时保留为不同条目并标注；排序按**计数降序 + 规范词升序**破并列，并同屏披露字段来源、年份窗、数据类别、范围与映射覆盖、样本量（计入/未计入）、映射凭证来源与更新时间；数据稀疏或没有关键词时显示“无数据/样本有限”并给出实际数量，使任一热点项都能按同一条件与同一披露复算。

## 3. 触发事件

1. 访客打开领域热点视图（默认现实视图，需明确领域与年份窗；默认年份窗待确认 B-04）。
2. 访客在该视图内调整条件（领域、年份窗、数据类别＝现实/演示）。
3. 访客请求查看某个热点项的术语归并明细与计数口径。
4. 访客提出越界请求（趋势/增长率、语义主题模型、质量评价、按学者个人热点排名、其他统计视图）。

## 4. 前置条件

1. 平台已收录公开生效的成果实体（某条件组合可能命中 0 条，见 A2）；成果实体已由 FR09/UC-09 去重（本 UC 不判定实体唯一性）。
2. 论文成果实体保留关键词事实（可缺）、时间语义（可缺失/未知）、领域取值（可“待分类”）、数据类别（真实/模拟/混合）、公开生效状态（SRS §7.1；SPEC §4.1/§4.4；BR-IMP-01/07）。
3. 主题登记与同义词映射（若有）取自 FR14/FR16 的**已生效**维护结果；映射凭证的来源形式与判定门槛未冻结（B-01），未登记/无凭证时按“不合并、单列并标注”处理（CL-05；A12/A13）。
4. 领域分类映射取自已生效维护结果；是否存在层级与“待分类”口径未冻结（Q-SPEC-03；B-09）。
5. 领域热点是公开只读能力，无需登录，也没有对象级授权分支（NF01；SRS §8）。
6. 领域热点视图与检索、门户、其他统计视图使用同一生效数据版本（NF05）；更新时间语义与传播时限未冻结（B-07；NF05 明确 60 秒目标不在本轮已批准清单）。
7. 热点的容量/性能只在 NF02 的整体验收下核对；本 UC 不主张独立的 P95 阈值（NF02；08 §5）。

## 5. 成功与失败后置条件

### 5.1 成功（热点结果）

1. 每个热点项代表**一个规范词**：同一规范词下的原始写法只有在**有凭证**的映射下才合并计为一个热点项；无凭证或存疑时保留为不同条目并标注“可能为同一概念的候选”，不得强行合并（FR13 明文；CL-05；M8–M10）。
2. 计数单位是“**论文 × 规范词**”：同一论文同一规范词只计一次；跨源重复、已确认版本合并、关键词列表内重复写法都不增加计数；来源数、版本数、作者数不参与计数（BR-IMP-02/06；`AC-IMPL-FR16-02` 边界；M11）。
3. 排序按**计数降序**；计数相同时按**规范词升序**破并列；名次与并列规则文字同屏可见（FR13 明文；M12）。
4. 同屏披露：字段来源（论文关键词/已登记主题）、年份窗、领域范围与映射覆盖、数据类别、样本量（参与计数的论文数、各类未纳入数）、同义词映射凭证来源、并列规则、更新时间（`AC-IMPL-FR13-01`；M15/M16）。
5. 固定声明“仅反映已收录数据中的关键词/主题出现次数，不代表研究质量、影响力或学术水平”，与结果同屏、可直接读到，不需额外点击（FR13 明文“不作质量评价”；模块细化 FR13-S06 为细化；M17）。
6. 任一热点项可复核：可查看该规范词包含的原始写法与各自次数（求和等于热点项计数）与映射凭证来源；无法解释的差异按缺陷处理（模块细化 FR13-S07 A1/AC-FR13-S07-02 为细化；M23–M28）。
7. 热点项数量少于展示条数时按实际条数展示，不用占位条目补足；超过单次展示上限时提示规模并标注“部分结果（已声明子集）”（模块细化 FR13-S08/FR13-S04 为细化；上限与条数待确认 B-06；M14/M19）。

### 5.2 成功（数据类别）

1. 默认现实视图只纳入**真实**数据；模拟与混合数据只在显式演示模式下展示，并在结果区与披露中固定标识“本结果基于模拟/混合数据，不得用于描述真实世界”（BR-IMP-07；M4/M22）。
2. 缺真实/模拟/混合标识的成果**不**计入真实数据，归“数据类别未知”并在披露中给出数量（BR-IMP-07 的互斥标识要求＋分析推导；B-08）。
3. 条件变更后按新条件重算，并**同步刷新**披露，不保留与结果不符的旧披露（模块细化 FR13-S01 A1/FR13-S03 为细化；M20/M21）。

### 5.3 失败（无业务写入）

1. 本 UC 无写操作：失败不改变任何成果、关键词原值、主题登记、术语映射或领域分类。
2. 条件非法、命中为空、执行失败、数据未更新、样本有限、映射覆盖不足六类结果可区分且不互相冒充（NF01；M29–M36）。
3. 非法条件被拒绝时保留原有结果与可编辑条件，不清空页面（模块细化 FR13-S02 E1 为细化；NF01；M3）。
4. 不展示部分结果并描述为完整结果；不以过期结果冒充最新；不编造更新时间（NF05；M31/M33）。
5. 拒绝趋势/增长率预测、语义主题模型、质量或影响力评价、按学者个人热点排名，以及按来源数/版本数/作者数当“关键词出现次数”的请求（FR13 明文；SRS §2.1；M37/M38）。
6. 稀疏或无关键词时只显示“无数据/样本有限”与**实际数量**，不补占位、不插值、不平滑、不据此给出质量/趋势结论（`AC-IMPL-FR13-02`；M13/M29）。

## 11. 待确认

1. **B-01 同义词映射的来源与判定门槛**：FR13 只要求“同义词映射有凭证才合并”，未规定凭证形式（来源字段、人工审核记录、外部词表许可）、维护责任与“存疑”的判定门槛。本分析按“只读已生效凭证映射，无凭证即不合并”建模，不构造词典（BR-UC13-04/05）。
2. **B-02 文本规范化的范围**：大小写、单复数、常见缩写、全半角、前后空白是否属于“同一规范词”的规范化（而非同义合并），基线未规定；模块细化 FR13-S07 要求覆盖（细化）。本 UC 只在已生效且可查询的规则内处理，规则状态写入披露（A13）。
3. **B-03 未登记关键词的处理**：基线写“论文关键词/已登记主题”，未说明未登记关键词是否作为热点项展示。本 UC 按“规范化为原写法单列并标注未登记”处理，需确认是否应统一纳入“未登记主题”未纳入数。
4. **B-04 默认年份窗**：基线要求“明确年份窗”，模块细化要求“未选择时使用默认窗口并声明”，默认窗起止或滚动年数未定义。本 UC 只要求“默认窗已声明且可复算”。
5. **B-05 样本有限阈值 T**：`AC-IMPL-FR13-02` 只要求显示“样本有限”，未给阈值（模块细化 BR-520 同样只要求标注）。本 UC 只要求标注并给出实际数量。
6. **B-06 展示条数与单次展示上限**：模块细化要求“前若干项”与“约定展示条数”，基线未给数值。本 UC 只要求“按实际条数、不补占位；超限声明子集”。
7. **B-07 更新时间的语义与一致性时限**：只要求“披露更新时间”；NF05 明确 60 秒目标不在本轮已批准清单。本分析用 `dataAsOf` 与 `computedAt` 两个分析态字段，标 `待确认`。
8. **B-08 混合数据与缺标识处理**：BR-IMP-07 只规定“真实/模拟/混合互斥、默认现实排名和网络仅真实合格数据”。展示混合数据是否允许进入演示视图、缺标识成果是否单列，属分析推导，需确认。
9. **B-09 领域条件必填性与映射覆盖口径**：FR13 要求“明确领域”，模块细化允许“只选领域不选机构/全部机构”。领域是否为必填、映射覆盖率（已映射/未映射）的分母口径未冻结（Q-SPEC-03）。
10. **B-10 关键词字段口径**：SPEC §4.1 只列“关键词”为论文可选证据字段，未区分作者关键词、索引词或题名词。字段口径影响计数结果，需确认；本 UC 不自行扩大字段集合。
11. **B-11 “出现次数”的计数单位**：`AC-IMPL-FR13-01` 的“出现 3 次”未说明是“3 篇论文”还是“3 次出现”。本 UC 按“同一论文同一规范词只计一次”建模（避免重复列表与多来源放大），需确认是否按出现次数计。
12. **B-12 与 UC-11/UC-12 的视图分工与追踪归属**：FR11 的分布统计（UC-11）、机构排名（UC-12）与 FR13 热点（UC-13）在模块细化中同属统计能力域，登记表预测 `StatisticsUI`/`StatisticsCoordinator` 会扩展到 UC-13。本 UC 建独立边界/协调者并注明合并候选（07 §2）；视图是否同页、边界类是否合并留 R5 与评审确认。
13. **C-01（取向差异）**：模块细化 FR13-S09、`DGM-STATE-03`、`DGM-ACTIVITY-02` 以“热点结果对象＋状态机＋上一版结果”建模；本 UC 按“读时投影、不建持久热点结果实体”建模（任务给定的分析方向；V2.2 只要求披露范围/口径/更新时间）。差异登记 07 §5。
14. **C-02（文本冲突）**：模块细化 FR13-S05 要求“展示选定窗口内的变化趋势并说明比较基线”；69 AC 基线 FR13 明文“不做语义主题模型、趋势预测或质量评价”。本 UC 以基线为准，不提供趋势/增长率，差异登记 07 §5，交评审确认 FR13-S05 是否已退出本期范围。
15. **C-03（范围差异）**：模块细化 FR13-S03 允许叠加“机构、成果类型、数据集范围（真实/模拟/全部）”条件；基线只要求“明确领域、年份窗与数据类别”。本 UC 只实现基线三条件（＋真实/演示切换），不引入机构与四类成果类型条件，差异登记 07 §5。
16. **C-04（命名差异）**：全局 `01-BCE`/`DGM-CLASS-01` 只有 `AnalyticsUI`（`..>` `GraphCtl`），模块细化无热点协调者；本 UC 用 `HotspotUI`/`HotspotCoordinator`，与 UC-11 `StatisticsUI`、UC-12 `InstitutionRankingUI` 并列。R5 建议见 07 §2。
