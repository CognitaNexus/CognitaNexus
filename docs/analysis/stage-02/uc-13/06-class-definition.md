# UC-13 分析类职责、属性、关系与分析机制

**版本：** V1.0（2026-10-21）
**方法：** 教材 §5.5.1 职责、§5.5.2 属性、§5.5.3 关系、§5.5.4 分析机制。
**范围：** 只定义 UC-13 能够证实的部分；跨用例统一关系不在此擅自补齐。

## 1. 定义原则

1. “做（Do）”型职责说明对象能执行/协调什么；“知道（Know）”型职责说明对象必须知道/提供什么。
2. 属性只写业务信息，不写数据库字段、主键类型、索引、物化视图或 API 参数；聚合方式、缓存与算法不在此定义。
3. 关系只写有消息或正式业务约束支持的；无依据的跨用例关系留待 R5。
4. 控制类没有长期业务属性；条件、热点项、计数、名次、样本量与披露是**单次请求的分析状态**。
5. 阈值、默认年份窗、映射凭证来源、规范化范围、展示条数与更新时间语义等未冻结项不伪装成类定义，统一标 `待确认`（B-01～B-12）。
6. 本 UC 不定义任何“语义相似度/主题模型/趋势预测”职责：这类职责被基线明文排除，不得作为候选操作出现（FR13 明文）。

## 7. 与其他 UC 的边界

- **UC-11/UC-12**：类型/年度/领域分布与机构排名不在本 UC；本 UC 只做关键词/主题计数与并列名次。三者共用“默认只真实、披露与结果同屏、空/失败可区分”的口径原则，但计数单位不同（成果实体、机构×成果、论文×规范词）；视图是否同页、边界/协调者是否合并待 B-12/R5。
- **UC-01/UC-02**：检索执行、稳定分页与成果详情不在本 UC；热点项明细只回显规范词、原写法、次数与凭证来源，不复制检索逻辑；两者须同版本（NF05）。
- **UC-09**：成果去重、清洗与版本归并在本 UC 之外；本 UC 只消费去重结果与“版本候选是否已确认”的状态。
- **UC-14/UC-15**：合作网络与最短路径属 FR12/IN01；本 UC 不计合作强度、不建边、不算路径。
- **UC-16**：规模核对（≥100 万/≥500 万去重实体、真实数单列）属 FR16；本 UC 只保证关键词计数的单位一致（`AC-IMPL-FR16-02` 边界）。
- **UC-17/FR14/FR16**：主题登记、术语映射与领域分类映射的维护、热点失败明细与审计查询不在本 UC；本 UC 只读已生效结果。
- **UC-03/UC-07/UC-10**：学者档案、公开主页与身份归属不在本 UC；本 UC 不使用作者身份或任职信息推断主题。

## 8. 分析机制汇总

| 机制 | 作用对象 | 业务问题 | 本 UC 可证实的约束 | 未决定/后续 |
|---|---|---|---|---|
| 范围与数据类别 | Coordinator、WorkEntity | 未公开/未生效/模拟数据进入“现实热点” | 只纳入公开、生效、真实、论文类；模拟/混合仅显式演示并标识；缺标识归“数据类别未知” | 混合数据是否可进演示视图、缺标识单列（B-08） |
| 统计资格与未纳入披露 | Coordinator、WorkEntity | 缺字段被静默当作零或不计数 | 缺关键词、时间未知、非论文、未登记主题分别计入未纳入数并披露 | 未登记关键词是否作为热点项（B-03）；关键词字段口径（B-10） |
| 有凭证归并 | Coordinator、TopicTerm | 无凭证同义合并导致概念混同 | 只有已生效、可查询的凭证映射才合并；无凭证/存疑→不合并并标注；不建词典、不做语义模型 | 凭证来源形式与判定门槛（B-01）；文本规范化范围（B-02） |
| 论文×规范词计数 | Coordinator、WorkEntity | 来源数/版本数/作者数/列表重复被当作出现次数 | 同一论文同一规范词只计一次；样本量＝参与计数的论文数 | “出现次数”精确口径（B-11） |
| 并列排序 | Coordinator、UI | 并列次序任意导致不可复核 | 计数降序；计数相同按规范词升序；名次与规则文字同屏 | 规范词升序的比较细则（大小写/全半角）随 B-02 确定 |
| 样本与规模 | Coordinator、UI | 稀疏数据被展示成结论；条数被占位补足 | 低于阈值 T 标“样本有限”并给实际数量；条数不足按实际；超上限声明子集 | 阈值 T（B-05）、条数与上限（B-06） |
| 披露与结果一致 | Coordinator、UI | 披露块与结果不同步 | 披露项齐备（字段/年份窗/领域与映射覆盖/数据类别/样本量/凭证来源/并列规则/更新时间）；条件变更后同步刷新 | 更新时间语义（B-07）、覆盖率口径（B-09） |
| 稀疏不编造 | Coordinator、UI | 用插值/平滑/补零制造结论 | 不补占位、不插值、不平滑、不补零、不外推；只显示实际数值 | 阈值与提示文案属界面规范 |
| 空/失败/未更新区分 | Coordinator、UI | 空结果、失败、过期结果互相冒充 | 四类可区分；不展示部分结果；不编造更新时间 | 一致性时限（B-07）；上一版结果保留（B-12/C-01） |
| 只读与不建持久结果 | 全体 | 热点顺手写数据或沉淀未经评审的结果对象 | 全图无写消息；投影不建实体；不新增主题登记与映射 | C-01 待评审 |
| 可复核 | Coordinator、UI | 热点计数无法复核 | 明细可查看原写法与各自次数（求和＝计数）与凭证来源；差异按缺陷处理 | 明细粒度与展示形态属界面规范 |
| 边界拒绝 | Coordinator、UI | 热点被当成趋势预测、质量评价或个人排名 | 拒绝趋势/增长率、语义主题模型、质量/影响力评价、学者个人热点排名、以来源数等替代计数 | FR13-S05 趋势展示是否已退出（C-02） |
