# UC-04 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明UC-04的每个事件、后置条件和备选流都有正式需求来源；把“分析推导”和“待确认”单独标出。
**主证据：** SRS V2.2第6、7、8、12节；69 AC权威账本；A1c。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式SRS/AC/BR/用户A1c直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作，但SRS未逐句写出 |
| 待确认 | 具体规则、参数、格式或边界未冻结，不能在本UC擅自决定 |

## 2. 事件与来源

| 事件 | 事件内容 | 来源 | 性质 | 备注 |
|---|---|---|---|---|
| E1 | 访客提交注册信息 | FR04；UC-04 | 已证实 | UC-04的目标入口 |
| E2 | 系统校验注册信息与账号资格 | FR04“注册成功时”；FR04-03 | 分析推导 | 成功/失败必须有可区分条件；具体字段规则待Q-01 |
| E3 | 创建User | FR04“一次性创建User与唯一UserProfile”；SRS §12 | 已证实 | 账号是独立对象，不是Scholar |
| E4 | 创建唯一UserProfile | FR04；AC-IMPL-FR04-03 | 已证实 | User与UserProfile为1:1 |
| E5 | 绑定稳定、可分享的公开地址 | FR04；AC-IMPL-FR04-03 | 已证实 | 地址格式/分配策略待Q-03 |
| E6 | 授予本人普通资料编辑权，不授予Scholar管理权 | FR04；BR-IMP-05；SRS §12 | 已证实 | 所有权直接来自UserProfile，不是ScholarAuthorization |
| E7 | 发布公开主页；零成果显示空态 | FR03；AC-IMPL-FR03-03；A1c；SRS §12 | 已证实 | 空态不是404 |
| E8 | 返回注册成功结果和主页地址 | FR04；AC-IMPL-FR04-03 | 已证实 | 返回形式/会话建立待Q-02/Q-07 |
| E9 | 公开读取/受保护写的权限守卫 | FR04-04；BR-IMP-01/05/11 | 已证实 | 本UC只做后置守卫，不展开UC-22 |

## 3. 备选与异常来源

| 事件 | 条件 | 处理 | 来源 | 性质 |
|---|---|---|---|---|
| A1 | 注册信息不满足注册规则 | 拒绝，不创建 | FR04成功条件 | 分析推导；字段规则待Q-01 |
| A2 | 同一注册请求重复/重试 | 不创建第二个主页，保持幂等 | FR04；AC-IMPL-FR04-03 | 已证实；识别键待Q-02 |
| A3 | 创建或地址分配失败 | 整体不生效，无无主主页，可重试 | FR04；AC-IMPL-FR04-03；SRS §12“一次性创建” | 已证实（业务结果层面）；实现方式不指定 |
| A4 | 注册成功但零成果 | 显示空态，不返回404 | AC-IMPL-FR03-03；A1c | 已证实 |
| A5 | 存在同名Scholar | 分开显示，不自动合并/认证 | AC-IMPL-FR03-04；BR-IMP-03；SRS §12 | 已证实 |
| A6 | 停用/退出后的受保护请求 | 拒绝，不删除既有公开Scholar档案 | AC-IMPL-FR04-02；BR-IMP-05/10 | 已证实 |
| A7 | 未登录公开读/受保护写 | 公开读允许；写拒绝；秘密不公开 | AC-IMPL-FR04-04；BR-IMP-01/11 | 已证实 |

## 5. 不纳入本UC的事件

| 事件 | 原因 | 归属 |
|---|---|---|
| 登录、退出 | FR04包含但UC-04本轮只做注册；登录/退出不是创建主页的必要步骤 | 后续UC-04增量或账号操作分析 |
| 编辑昵称/头像/简介/兴趣 | 注册后行为，具体字段属于FR06 | UC-22 |
| Scholar认领、审核、授权 | 需要已有Scholar与申请证据 | UC-05/UC-06 |
| Scholar档案维护 | 需要对象级授权 | UC-07 |
| 成果确认/纠错 | 需要已有Authorship/Work | UC-08 |
| 公开主页浏览的完整场景 | 本UC只验证注册后主页可读和空态 | UC-03 |
| 账号停用的完整生命周期 | 本UC只使用“停用后拒绝受保护请求”作为后置守卫 | 账号管理/后续UC |

## 6. 追踪结论

- 主流程E1–E9均有正式来源或明确的分析推导；
- A1/A2/A3/A6/A7是注册成功语义所要求的分支，不是新增业务能力；
- 具体注册字段、幂等键、URL格式、是否独立审计和默认公开字段未冻结，已登记为待评审问题，未写成已批准规则；
- 本表不改变69条AC，不新增第70条AC。
