# UC-08 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-08 的每个事件、后置条件与备选流都有正式来源；把“分析推导”和“待确认”单独标出。
**主证据：** SRS V2.2 §4 FR07/FR15/FR12、§6.4、§7 BR-IMP-01/02/03/04/05/08/10/11、§7.1/§7.2、§8 权限与安全、§9 NF03/NF05/NF06、§11.3/§11.4；69 AC 权威账本；核心 SPEC §3/§4/§6.2/§6.4；模块 SRS `scholar-disambiguation.md` FR15-S07～S12（细化，不反向覆盖基线）。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR/SPEC/冻结 S01 直接支持 |
| 分析推导 | 由已证实业务结果必然要求的对象协作，但 SRS 未逐句写出 |
| 待确认 | 具体规则、字段清单、状态集合或责任分工未冻结，不能在本 UC 擅自决定 |

## 6. 追踪结论

- 主流程 E1–E15 均有正式来源；其中“共享字段清单”“可核验最低集合”“待审请求状态集合”“确认范围表达”“归属改派入口”按待确认处理（B-01～B-08），未写成已批准规则。
- A1/A2/A3/A4/A7/A11/A13/A14 由 AC、SRS、模块细化的明文要求支持；A5/A10 为“已证实原则 + 未冻结判定口径”；A6/A8/A9 为分析推导。
- “只改自己的关系”“单次确认不扩散”“共享字段须审核”“解除不删成果与来源”“已排除不得自动恢复”“待核验/争议/已排除不建边”六项都有正式依据，不是本分析的业务创新。
- 本表不改变 69 条 AC，不新增第 70 条 AC。
