# UC-05 分析类职责、属性、关系与分析机制

**版本：** V1.0（2026-10-21）
**方法：** 教材 §5.5.1 职责、§5.5.2 属性、§5.5.3 关系、§5.5.4 分析机制。
**范围：** 只定义 UC-05 能够证实的部分；跨用例统一关系不在此擅自补齐。

## 1. 定义原则

1. “做（Do）”型职责说明对象能执行/协调什么；“知道（Know）”型职责说明必须知道/提供什么。
2. 属性只写业务信息，不写数据库字段、主键类型、索引、上传接口或 API 参数。
3. 关系只写有消息或正式业务约束支持的；无依据的跨用例关系留待 R5。
4. 控制类没有长期业务属性；请求上下文是单次用例的分析状态。
5. 证据最低集合、缺证处置策略、通知/SLA、重复提交与补证版本等未冻结项不伪装成类定义，统一标 `待确认`。

## 9. 关系定义汇总

| 关系 | 角色/方向 | 多重性 | 来源 | 状态 |
|---|---|---|---|---|
| ClaimUI → ClaimCoordinator | UI 请求/返回 | 不定义持久多重性 | M2/M26；M6/M8/M11/M15/M21/M23/M29/M31/M33/M35 | 已定义（单向关联） |
| ClaimCoordinator → ClaimApplication | 创建/读取 | 不定义持久多重性 | M13/M19/M28 | 已定义（单向关联） |
| ClaimCoordinator ⇢ ScholarAuthorization | 只读依赖 | 不定义持久多重性 | M17/M18 | 已定义（虚线只读） |
| ClaimApplication 0..* → 1 User | 申请人 | `0..*` : `1` | FR05；SRS §8；M3/M19/M28 | 已定义（业务关联） |
| ClaimApplication 0..* → 1 Scholar | 认领目标 | `0..*` : `1` | FR05“选择已有Scholar”；AC-IMPL-FR05-03 | 已定义（业务关联） |
| ClaimApplication → ReviewEvidence | 证据材料 | **未定** | M14/M20；D-06 | 已定义（业务关联，多重性待确认） |
| ScholarAuthorization → Scholar | 目标档案 | **未定** | M17；SRS §12；SPEC ID-12 | 已定义（只读使用） |
| User — ScholarAuthorization | 被授予 | **本 UC 不建立** | 无消息；授权由 UC-06 创建 | 留给 UC-06/R5 |
| ClaimApplication → Authorship / WorkEntity | — | **本 UC 不建立** | 认领不确认成果归属 | 留给 UC-08/10 |
| UserProfile — Scholar | — | **本 UC 不建立** | 认领不合并主页与学者档案 | 留给 UC-04/22、R5 |

**说明：** 控制/边界到实体的关联按消息方向表达协作，不代表持久聚合；本 UC 只有“申请→申请人”“申请→目标”两处可依正式依据标多重性。

## 10. 分析机制汇总

| 机制 | 作用对象 | 业务问题 | 本 UC 约束 | 未决定/后续 |
|---|---|---|---|---|
| 服务端强制校验 | Coordinator、User | 未登录/停用/越权提交或查询 | 每次请求校验身份、账号状态与归属；入口隐藏不代替拒绝 | 会话对象是否独立（UC-04 Q-07） |
| 目标对象类型守卫 | Coordinator、Scholar | 不能把 UserProfile 当 Scholar、不能新建学者 | 只接受已收录 Scholar 引用；A3 拒绝 | 合并迁移后的旧标识处理 |
| 必要证据校验 | Coordinator、ReviewEvidence | 缺证不得进入审核 | 齐备→待审核；缺证→拒绝或待补充（A1a/A1b） | 最低集合与“可核验”标准（B-02/D-06） |
| 不写授权 | Coordinator、ScholarAuthorization | 提交阶段不得产生/转移管理权 | 只读依赖；无创建/修改/撤销/转移消息 | 授权转移与申诉程序（SPEC ID-12） |
| 竞争认领保留原授权 | Coordinator、ClaimApplication | 竞争不得剥夺既有管理者 | 记录竞争事实；原授权不变；争议属 UC-06 | 受控待办载体（B-06） |
| 不建第二主页 | 全体 | 认领不得复制/合并主页 | 无 UserProfile 消息 | — |
| 不自动确认 Authorship | 全体 | 认领不得升级成果归属 | 无 Authorship/WorkEntity 消息 | 本人确认与归属治理属 UC-08/10 |
| 证据私有与最小化 | ReviewEvidence、UI | 材料不得公开或跨用户可见 | 仅本人与有权审核者；查询不回显他人证据 | 材料留存期限/脱敏范围（D-09） |
| 状态归属分离 | ClaimApplication | 提交不得伪造通过/驳回/争议 | 只写待审核/待补充；其余只读 | 重提与补证版本（B-04） |
| 结果可区分 | Coordinator、UI | 拒绝/失败/待补充/无申请不能混同 | 独立消息与显示 | 具体文案未冻结 |
| 重复提交与通知 | Coordinator、UI | 重复申请与决定告知 | 本 UC 不定义 | B-03/B-07/B-08 |
