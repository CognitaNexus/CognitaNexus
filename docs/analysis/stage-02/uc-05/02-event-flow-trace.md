# UC-05 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-05 每个事件、分支和后置条件都有正式来源；区分已证实、分析推导与待确认。
**主证据：** SRS V2.2 FR05（含 AC-IMPL-FR05-01～04）、FR04 服务端校验、FR15/BR-IMP-03/05/10/11、NF03/NF06；核心 SPEC §3（申请状态）与 ID-07/ID-12；[`DGM-STATE-02-claim-request.puml`](../../../uml/claim/DGM-STATE-02-claim-request.puml)、[`DGM-ACTIVITY-01-claim-review.puml`](../../../uml/claim/DGM-ACTIVITY-01-claim-review.puml)。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR-IMP/SPEC 条款直接支持 |
| 分析推导 | 由已证实语义必然要求的协作或守卫，SRS 未逐句写出（例如“拒绝与失败需分开”） |
| 待确认 | 证据最低集合、缺证处置策略、通知/SLA、重提与重复提交口径未冻结 |

## 5. 不纳入本 UC 的事件

| 事件 | 原因 | 归属 |
|---|---|---|
| 审核证据、批准/驳回、冲突判定、授权生效或失败回滚 | FR05 的审核侧决定；本 UC 只提交与查询 | UC-06 |
| 补证要求的下发与放行（`待审核→待补充`、`待补充→待审核` 的审核动作） | 由有权审核者发起 | UC-06（B-04） |
| 已授权 Scholar 档案字段维护与待审生效 | FR06 的学者维护 | UC-07 |
| 普通昵称/头像/简介编辑、普通主页公开投影 | FR06 普通资料 | UC-22 |
| 成果归属确认/纠错、Authorship 状态变更 | FR07/FR15 的归属治理 | UC-08/UC-09/UC-10 |
| 拒绝通知、决定通知、SLA 计时 | SRS 未定义通知与 SLA（B-07/B-08） | 待需求确认 |
| 认领申请的后台待办列表与审计查询 | FR14 后台待办/审计 | UC-17 |
| 账号注册、登录失败与账号状态管理 | FR04 账号生命周期 | UC-04 |

## 6. 追踪结论

- E1–E11、A1–A8 均有正式来源或明确标注的分析推导；
- “提交侧只产生待审核/待补充”“授权不在本 UC 创建/转移”“不建第二主页、不确认成果归属”是 FR05 与 SRS §12 的直接要求，不是分析偏好；
- 缺必要证据的两种处置（拒绝 / 待补充）并列存在于 AC-IMPL-FR05-01，本包两种都保留，不擅自选定；
- 不新增 AC、不修改 69 条基线。
