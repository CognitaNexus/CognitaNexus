# UC-06 事件流与需求来源表

**版本：** V1.0（2026-10-21）
**目的：** 证明 UC-06 每个事件、分支和后置条件都有正式来源；区分已证实、分析推导与待确认。
**主证据：** SRS V2.2 FR05（含 AC-IMPL-FR05-01～04）、FR04（服务端校验/账号状态）、FR14（管理待办与审计）、FR15/BR-IMP-03/05/10/11、NF03/NF06、SRS §6.3/§8/§12；核心 SPEC §3（公共状态、不变量 INV-10）、§6（ID-06/ID-07/ID-12）；[`DGM-STATE-02-claim-request.puml`](../../../uml/claim/DGM-STATE-02-claim-request.puml)、[`DGM-ACTIVITY-01-claim-review.puml`](../../../uml/claim/DGM-ACTIVITY-01-claim-review.puml)。

## 1. 证据等级

| 等级 | 含义 |
|---|---|
| 已证实 | 正式 SRS/AC/BR-IMP/SPEC/冻结状态模型条款直接支持 |
| 分析推导 | 由已证实语义必然要求的协作或守卫，SRS 未逐句写出（例如“授权失败与通过需分开返回”） |
| 待确认 | 审核权限划分、证据最低集合、SLA、授权转移/申诉、通知渠道、重试与回滚口径未冻结 |

## 6. 追踪结论

- E1–E12、A1–A9 均有正式来源或明确标注的分析推导；无编造 AC、无新增需求编号。
- “批准只在无冲突时”“授权仅对象级”“争议保留原授权、不自动转移”“决定必须留痕”均为 AC-IMPL-FR05-02/03、BR-IMP-05、FR14/BR-IMP-10 与 SPEC ID-07/ID-12、INV-10 的直接要求，不是分析偏好。
- “补证复核放行（A4）”遵循 `DGM-STATE-02` 的 `待补充 → 待审核` 边；“待补充→驳回/争议”无既有边，未擅自新增（C-06）。
- “审计失败不得报告生效（A9）”由 INV-10 推出，属分析推导；回滚机制留待实现阶段。
- 本 UC 不新增、不修改 69 条基线中的任何 AC。
