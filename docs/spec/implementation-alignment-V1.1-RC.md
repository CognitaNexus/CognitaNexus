## 交接不变量

1. 来源记录、去重成果、学者身份、学者成果关系及门户授权分别保存其语义，不以一个布尔值替代。
2. 成果实体可独立计入已公开统计；作者关系未核验不会删除该成果实体，合作网只接受两端合格的共同论文参与关系。
3. 现实统计与论文图只接受真实数据资格；模拟/混合属于显式演示，不隐式推入真实排名。
4. 版本变更只有审核生效后的值才进入公开检索、门户、统计与图；历史来源值和变更审计保留。
5. V1.0 SPEC 的尚未冻结候选阈值与第一组老模块 BR 不覆盖本文明确的 V1.1 实施边界。
