# CognitaNexus 非功能验收测量方案

版本：V1.1整改版；日期：2026-10-17；责任：测试负责人及两组负责人；文档状态：Review Candidate，非Frozen。

输入：[SRS V2.2（69 AC）](../srs/CognitaNexus-Shared-SRS-V2.2-69AC.md)、需求V2.1、69 AC权威基线。组长在本次会话明确告知双方评审通过：预热2分钟、测量5分钟、100活跃用户闭环请求、错误率≤1%、单请求超时5秒；图上限1万节点/10万边、路径P95≤2秒；RTO≤30分钟/RPO≤24小时。此为用户确认的业务参数，尚无运行达标证据，不代替其余事项签认。

## 1. 规模和适用对象

| 层级 | 数据与负载 | 证明内容 |
| --- | --- | --- |
| 正确性回归 | 3000～10000条固定样本，包含四类成果及异常 | CL/DD/ID/SR/图规则正确性；不能证明容量 |
| 功能联调 | ≥10000条去重成果，四类可查，真实/模拟分别统计 | 端到端链路与权限；不能证明最终性能 |
| 容量和查询性能 | ≥100000条去重可检索成果，100活跃用户 | 普通检索负载、容量与资源；不是100个导入任务 |
| 合作图和路径 | 当前筛选图≤10000节点、≤100000边 | 图内建边与路径查询；不代表10万成果均为论文或均参与图 |

功能联调100万、最终容量500万、固定环境100并发均为用户2026-10-20最终确认的目标；100万功能联调不等于500万容量实测。允许明确标记的模拟压力数据，真实占比不设未经批准的最低值，但必须报告真实/模拟/混合的实体数、各类型及各筛选规模；模拟数据只进入显式演示测试，不伪装现实排名或真实合作图。

## 2. NF02固定测量协议

被测操作为FR01成果关键词检索、学者关键词检索、类型/年份/领域/发生时机构合取筛选、稳定排序和下一页查询。具体URL不在需求阶段限定；测试前将以上五类操作绑定实际接口/页面、固定输入、期望结果、数据快照及实现版本，并保存查询集哈希。详情、写操作、网络路径不混入普通检索指标，路径单测见第3节。

100个同时活跃用户采用闭环：每人最多1个未完成请求，收到响应或超时立即发下一请求，无思考间隔；五类操作按固定轮询各20%，用户起点错开，查询选择固定种子，测试条件和随机种子记录在报告。正式测量前同负载预热2分钟，随后连续5分钟，预热请求不计正式样本。记录客户端发出至完整响应接收的单调时钟耗时，包含网络与服务端执行；单请求5秒截止，不包含原站外链访问。

所有发出请求进入分母。非预期状态、响应校验不符、连接失败和超时均为错误；正常空结果不算错误。错误率=错误请求/总请求，超时率=5秒未完成请求/总请求，超时已包含在错误率中，故超时率也须≤1%。失败和超时样本不从性能统计剔除；超时以5秒记截断下界并单列。P95采用最近秩法，升序第ceil(0.95×N)项；按操作分别报告P50/P95/P99及整体指标。

双方确认本方案的负载、预热、错误率和超时参数；**普通检索P95≤2秒原目标仍待明确签认**（本次用户单独确认的路径P95见下节）。在该目标签认前，普通检索最终PASS为NOT RUN，允许采集原始测量结果。所有已签认门槛与数据规模均满足、每类操作有有效样本且响应正确才可PASS；已冻结协议执行后任一项不满足为FAIL；缺签认、缺固定查询集、环境未记录或未执行为NOT RUN，不用文档检查替代压测。

## 3. IN01性能和规模门禁

经筛选后图的节点≤10000且边≤100000；任一超出则返回超规模和当前规模，不返回截断图的伪最短路径。上限在结果页披露。图快照和固定查询集保持不变；分别包含有路径、无路径、等长路径及近上限图，预热2分钟、测量5分钟，采用上述100用户闭环与错误/超时协议，路径P95≤2秒已由用户告知双组评审通过。测量边界为提交两端点和筛选至完整路径/证据响应，预先建图的时间单独记录，不能隐入查询性能结论。

## 4. NF04恢复

RTO≤30分钟：从注入故障被监测确认到受影响核心读写服务恢复且数据校验完成。RPO≤24小时：故障时间与最近可恢复、已校验业务状态时间之差，不以“备份文件存在”代替可恢复。固定故障和备份样例，核对成果、唯一出处、关系、门户授权、审计；恢复或重试不增重复实体/出处。记录备份开始/完成、故障/发现/恢复时刻、可恢复时间点及实际丢失范围。未经演练为NOT RUN。

## 5. 其他NF的测试记录

NF01检查加载/空/错误/越权/处理中及表单提示；NF03执行对象越权与秘密泄漏检查；NF05逐项核对详情、门户、检索、统计、网络和路径版本，60秒仍待签认待实测；NF06核对证明权限及清理，保留期限/备份清除例外待确认，不填造日期；NF07按部署与恢复说明复现；NF08拟选FR09、FR15、FR01分别核对≥80%行覆盖率，模块选定待双方签认，CodeArts未操作即NOT VERIFIED。

## 6. 压测报告必填字段

报告须包含：协议版本及签认出处、代码/数据/图/查询集哈希、工具和版本、硬件/操作系统/部署资源、网络边界、数据类型及真实性配比、用户/请求模型、预热与持续时长、各类请求总数及结果校验、P50/P95/P99、错误/超时率、吞吐量、CPU/内存/存储与检索索引大小、图节点/边数、异常日志、实际运行时段、执行者/复核者、PASS/FAIL/NOT RUN及理由。姓名和实测结果须由实际参与者填写。
