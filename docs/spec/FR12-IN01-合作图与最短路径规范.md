# CognitaNexus 合作图与最短路径规范

版本：V2.2；日期：2026-10-20；责任：统计网络模块；状态：S01 69 AC baseline aligned。输入：[SRS V2.2](../srs/CognitaNexus-Shared-SRS-V2.2-69AC.md) FR12/IN01、69 AC基线、BR-IMP-01/03/06～10。固定样例为人工构造，未执行软件测试。

## 1. 输入及资格

输入为固定版本的成果实体、学者canonical_id、逐条参与关系、角色证据、公开许可、真实性以及成果发生时的机构/领域映射。实体去重由FR09负责，人员身份与归属由FR15负责；本模块不得按同名重新合并节点。

FR12基础网络只采用真实、有效、公开且当前生效的论文/专利/项目/获奖共同成果；参与角色分别为合法作者、合法发明人、合法项目成员、合格获奖个人成员，缺角色证据不建边。IN01只取其中合格共同论文子图。每个参与关系须身份/归属明确、可公开，状态为本人确认或具备已批准自动规则/独立人工核验证据的自动关联；待核验、争议、已排除不合格。模拟/混合只能显式演示，不混入真实图。

## 2. 建边与稳定标识

stable_id=学者canonical_id，不是姓名、ORCID原文、来源内ID或账号ID。同一快照内canonical_id唯一；本规范按其规范ASCII字符串逐字节比较，大小写保留，不作数值比较；合并重定向先解析到当前canonical_id，环或失效目标为异常，不随意选节点。旧快照仍使用旧快照ID，查询返回图版本。

FR12：对每项去重合格成果，从对应合法参与角色canonical_id集合中去重，枚举每个不同学者无序对(u,v)，用min/max ID作为唯一边键；自环不生成。每项成果对每对学者贡献1强度单位。edge.weight=该对不同canonical去重成果ID数量；同成果的版本、出处和重复角色不重复加权。证据按成果canonical_id升序保存。仅同机构或同领域不建边。

IN01：只在上述基础图中证据为合格共同论文的边上构图；共同专利/项目/获奖边不得进入论文路径。

## 3. 筛选与规模边界

年份使用成果已核验发生时间；机构使用该成果对应学者在成果发生时的机构证据；领域使用发生时适用、已核验的领域分类及映射版本，不用当前学者主页字段回填历史。IN01只对论文子图应用。未知机构/领域不命中特定筛选。选机构时，边的两端在该论文上均须有命中所选机构集合的参与证据；机构与领域跨维度取交集，同维度本版只承诺单值筛选。先筛论文和作者参与证据，再重新建边/计算强度，不是仅隐藏图中部分节点。该细化为本次整改RC，须在复审中确认。

筛选后节点上限10000、无向边上限100000，用户已告知双方评审通过。节点包括当前范围内有合格论文参与的公开学者，允许孤立节点；FR12基础图可含四类成果，IN01节点/边只计论文子图。超过任一上限返回明确超规模，禁止任意截断后仍声称全范围最短；页面披露实际规模和上限。性能条件见[NF验收方案](NF-验收测量方案.md)。

## 4. 最短路径及字典序重建

图为无向非加权图，最短指最少合作边数，强度不作距离。验证端点属于同一筛选快照；端点有效且相同时返回0跳、无边证据；节点不可用和无路径分别反馈。

先从目标t做BFS得到到t的最短距离dist。若s不可达则无路径；否则从s开始，每步在满足dist[v]=dist[u]-1的邻居中选择canonical_id最小者，直到t。该重建保证跳数最短且整个节点序列字典序最小，不依赖数据库扫描或邻居输入顺序。每跳返回对应边强度、至少一篇（默认ID最小）合格论文及详情入口；所有证据必须属于当前筛选图，不跨范围补边。

```text
BUILD(snapshot, filters):
  select qualified real public papers and eligible authorships at snapshot
  apply work-time organization/domain filters before constructing edges
  for each distinct canonical paper p:
    authors = sorted(unique(eligible canonical scholar ids for p))
    for every unordered distinct pair (u,v): evidence[u,v].add(p.canonical_id)
  edge weight = size(evidence[u,v]); reject if node/edge limit exceeded
PATH(s,t,G):
  validate endpoints and fixed graph version
  dist = BFS_from(t,G)
  if s not in dist: return NO_PATH
  path = [s]
  while last(path) != t:
    u = last(path)
    path.append(min(v for v in G.neighbors(u) if dist[v] == dist[u]-1))
  return path, all hop evidence at same graph version
```
