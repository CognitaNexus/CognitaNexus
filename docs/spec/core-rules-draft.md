# 核心模块 SPEC 规则初稿：清洗、去重、消歧、检索排序（Draft）

**依据：** V1.9 / 成员03 FR09-S01～S12 与 FR15-S01～S13 / 成员01 FR01。**范围：** 当前是**判定规则的候选清单与边界样例**，不是架构、数据库方案或已冻结阈值。

## 1. 数据清洗与规范化（FR09）

| 规则候选 | 输入/条件 | 期望判定 | 不得发生 |
| --- | --- | --- | --- |
| 校验必要信息 | 来源身份、成果类型或名称缺失 | 标记异常、记录缺项，不公开为合法成果 | 凭空补造字段 |
| 标识归一 | 同类型 DOI/专利编号正规化前后等价，且标识有效 | 保留原值及规范值，作为后续去重的可比证据 | 不区分不同标识体系或忽略相互冲突的ID |
| 时间语义 | 论文发表年份、专利申请/授权日期等 | 按类别保留语义并标记未知 | 把采集日期当成果发生时间 |
| 重试幂等 | 同来源同记录反复读取 | 记录检查轨迹但不凭重复输入增加成果实体 | 同一输入导致不同实体总数 |

## 2. 成果去重及版本（FR09）

| 边界场景 | 候选规则/验收预期 |
| --- | --- |
| 两来源提供经有效性和类型核验后的同一稳定标识 | 形成同一成果实体的归并候选或确定匹配，保留两个出处及版本证据 |
| 仅论文标题高度相似 | 只进入候选，比较年份、参与者、类型等，不直接合并 |
| 预印本与正式发表同题但不同标识 | 记录版本候选及映射证据；证据不足时不能静默算作同一实体 |
| 不同稳定标识与作者证据矛盾 | 标记冲突并交人工核验，保留原生效版本，不根据标题自行覆盖 |

**待决：** 同一成果与跨类型标识对照的充分条件、人工合并撤销方式、冲突解决及拆分后引用来源如何迁移。具体阈值/相似度权重不得凭模型推断。

## 3. 学者消歧与成果归属（FR15）

| 样例 | 候选判定 |
| --- | --- |
| 姓名同为“张伟”，机构与外部标识相矛盾 | 不合并；记录候选/争议与证据 |
| 姓名表达不同但同一可靠外部身份及协作证据相符 | 经明确证据链可归并为同一学者档案 |
| 一篇论文的两名共同作者均完成本人确认 | 保留两条合法参与关系，不因其中一方确认覆盖另一方 |
| 管理员通过门户认领申请 | 只授予门户管理权，不自动把所有成果参与关系设为本人确认 |
| 某参与者撤除自身关系 | 只处理其参与关系，不删除成果实体或其他作者关系 |

**待决：** 证据级别、人工核验权限、归属多源冲突顺序、哪些字段必须展示来源及如何生成可审计决定。

## 4. 检索排序与回退（FR01）

| 候选业务规则 | 验收预期 |
| --- | --- |
| 关键词、成果类型、年份、机构、领域组合 | 只返回已生效且允许公开、满足筛选的结果；不能跨条件漏过滤 |
| 相同查询/筛选与固定数据范围 | 排序顺序可重复，分页无重复或遗漏；排序键与次序须可说明 |
| 排序所需字段缺失 | 按评审后统一的缺失值规则处理，不能编造数据或把缺失默认为最大 |
| 结果为空或外部原站访问失败 | 给明确状态反馈；失效外链不删除已经收录的元数据 |

**待决：** 相关度排序规则/权重、同分排序、模糊匹配范围、默认排序、字段缺失顺序；在联合评审前不得把具体权重写为既定 Must。  
**NFR：** NF02 P95 2 秒为待评审目标；没有固定查询集和实测记录不得声称已达标。
