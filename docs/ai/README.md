## 记录原则

1. **只记真实发生的事**。每一项都要能指到仓库里的文件、命令或输出。没有执行过的测试、覆盖率、压测一律写「未执行」。
2. **修正案例必须写出「怎么发现的」**。只写「AI 写错了、人改对了」没有价值；要写出发现它的那条断言、那次运行、那个数字。
3. **包含对 AI 不利的记录**。能力边界与失效模式只写优点等于没写。
4. 时间以报告日期为准，均来自本仓库现有提交与运行记录。
